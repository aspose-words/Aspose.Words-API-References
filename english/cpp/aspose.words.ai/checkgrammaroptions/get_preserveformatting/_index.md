## CheckGrammarOptions::get_PreserveFormatting method


Allows to specify either [CheckGrammar()](../../aimodel/checkgrammar/) will try to preserve layout and formatting of the original document, or not. Default value is **true**.

```cpp
_Bool Aspose::Words::AI::CheckGrammarOptions::get_PreserveFormatting() const
```

## Remarks

 When the option is set to **false**, the quality of grammar checking is higher than when this option is set to **true**. However, the original formatting of the text is not preserved in this case.
