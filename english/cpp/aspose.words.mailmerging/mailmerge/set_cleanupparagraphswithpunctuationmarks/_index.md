## MailMerge::set_CleanupParagraphsWithPunctuationMarks method


Sets a value indicating whether paragraphs with punctuation marks are considered as empty and should be removed if the [RemoveEmptyParagraphs](../../mailmergecleanupoptions/) option is specified.

```cpp
void Aspose::Words::MailMerging::MailMerge::set_CleanupParagraphsWithPunctuationMarks(bool value)
```

## Remarks

 The default value is **true**. Here is the complete list of cleanable punctuation marks: * !
* ,
* .
* :
* ;
* ?
* ¡
* ¿
