## Document::set_GlossaryDocument method


Sets the glossary document within this document or template. A glossary document is a storage for AutoText, AutoCorrect and Building Block entries defined in a document.

```cpp
void Aspose::Words::Document::set_GlossaryDocument(const System::SharedPtr<Aspose::Words::BuildingBlocks::GlossaryDocument> & value)
```

## Remarks


This property returns **null** if the document does not have a glossary document.

You can add a glossary document to a document by creating a [GlossaryDocument](../../../aspose.words.buildingblocks/glossarydocument/) object and assigning to this property.
