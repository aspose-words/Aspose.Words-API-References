## PdfSaveOptions::set_DmlEffectsRenderingMode method


Sets a value determining how DrawingML effects are rendered.

```cpp
void Aspose::Words::Saving::PdfSaveOptions::set_DmlEffectsRenderingMode(Aspose::Words::Saving::DmlEffectsRenderingMode value) override
```

## Remarks

 The default value is [Simplified](../../dmleffectsrenderingmode/). 
This property is used when the document is exported to fixed page formats.

If [Compliance](../get_compliance/) is set to [PdfA1a](../../pdfcompliance/) or [PdfA1b](../../pdfcompliance/), property always returns [None](../../dmleffectsrenderingmode/).
