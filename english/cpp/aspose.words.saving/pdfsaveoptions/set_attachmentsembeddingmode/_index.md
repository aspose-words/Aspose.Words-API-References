## PdfSaveOptions::set_AttachmentsEmbeddingMode method


Sets a value determining how attachments are embedded to the PDF document.

```cpp
void Aspose::Words::Saving::PdfSaveOptions::set_AttachmentsEmbeddingMode(Aspose::Words::Saving::PdfAttachmentsEmbeddingMode value)
```

## Remarks


Default value is [None](../../pdfattachmentsembeddingmode/) and attachments are not embedded.

 PDF/A-1, PDF/A-2 and regular PDF/A-4 (not PDF/A-4f) standards do not allow embedded files. [None](../../pdfattachmentsembeddingmode/) value will be used automatically.
