## PdfSaveOptions::set_UseBookFoldPrintingSettings method


Sets a boolean value indicating whether the document should be saved using a booklet printing layout, if it is specified via [MultiplePages](../../../aspose.words/pagesetup/get_multiplepages/).

```cpp
void Aspose::Words::Saving::PdfSaveOptions::set_UseBookFoldPrintingSettings(bool value)
```

## Remarks


 If this option is specified, [PageSet](../../fixedpagesaveoptions/get_pageset/) is ignored when saving. This behavior matches MS Word. If book fold printing settings are not specified in page setup, this option will have no effect.
