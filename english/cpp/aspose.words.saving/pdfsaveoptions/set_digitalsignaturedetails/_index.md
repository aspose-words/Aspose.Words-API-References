## PdfSaveOptions::set_DigitalSignatureDetails method


Sets the details for signing the output PDF document.

```cpp
void Aspose::Words::Saving::PdfSaveOptions::set_DigitalSignatureDetails(const System::SharedPtr<Aspose::Words::Saving::PdfDigitalSignatureDetails> & value)
```

## Remarks


The default value is **null** and the output document will not be signed. When this property is set to a valid [PdfDigitalSignatureDetails](../../pdfdigitalsignaturedetails/) object, then the output PDF document will be digitally signed.
