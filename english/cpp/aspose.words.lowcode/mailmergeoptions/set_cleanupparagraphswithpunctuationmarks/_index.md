## MailMergeOptions::set_CleanupParagraphsWithPunctuationMarks method


Sets a value indicating whether paragraphs with punctuation marks are considered as empty and should be removed if the [RemoveEmptyParagraphs](../../../aspose.words.mailmerging/mailmergecleanupoptions/) option is specified.

```cpp
void Aspose::Words::LowCode::MailMergeOptions::set_CleanupParagraphsWithPunctuationMarks(bool value)
```

## Remarks

 The default value is **true**. Here is the complete list of cleanable punctuation marks: * !
* ,
* .
* :
* ;
* ?
* ¡
* ¿
