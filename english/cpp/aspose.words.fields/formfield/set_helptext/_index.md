## FormField::set_HelpText method


Sets the text that's displayed in a message box when the form field has the focus and the user presses F1.

```cpp
void Aspose::Words::Fields::FormField::set_HelpText(const System::String & value)
```

## Remarks


If the [OwnHelp](../get_ownhelp/) property is set to **true**, [HelpText](../get_helptext/) specifies the text string value. If [OwnHelp](../get_ownhelp/) is set to **false**, [HelpText](../get_helptext/) specifies the name of an AutoText entry that contains help text for the form field.

Microsoft Word allows strings with at most 255 characters.
