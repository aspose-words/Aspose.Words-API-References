## FormField::set_StatusText method


Sets the text that's displayed in the status bar when a form field has the focus.

```cpp
void Aspose::Words::Fields::FormField::set_StatusText(const System::String & value)
```

## Remarks


If the [OwnStatus](../get_ownstatus/) property is set to **true**, the [StatusText](../get_statustext/) property specifies the status bar text. If the [OwnStatus](../get_ownstatus/) property is set to **false**, the [StatusText](../get_statustext/) property specifies the name of an AutoText entry that contains status bar text for the form field.

 Microsoft Word allows strings with at most 138 characters.
