## FieldOptions::set_UserPromptRespondent method


Sets the respondent to user prompts during field update.

```cpp
void Aspose::Words::Fields::FieldOptions::set_UserPromptRespondent(const System::SharedPtr<Aspose::Words::Fields::IFieldUserPromptRespondent> & value)
```

## Remarks


If the value of this property is set to **null**, the fields that require user response on prompting (such as [FieldAsk](../../fieldask/) or [FieldFillIn](../../fieldfillin/)) are not updated.

The default value is **null**.
