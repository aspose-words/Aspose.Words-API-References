El espacio de nombres **Aspose.Words.Settings** contiene clases y enumeraciones que se utilizan al especificar diversas configuraciones y opciones almacenadas en un documento. Estas incluyen combinación de correspondencia, protección de escritura, compatibilidad y otras configuraciones.

## Clases

| Clase | Descripción |
| --- | --- |
| [CompatibilityOptions](./compatibilityoptions/) | Contiene opciones de compatibilidad (es decir, las preferencias del usuario ingresadas en la pestaña **Compatibility** del cuadro de diálogo **Options** en Microsoft Word). Para obtener más información, visite el artículo de documentación [Detect File Format and Check Format Compatibility](https://docs.aspose.com/words/cpp/detect-file-format-and-check-format-compatibility/). |
| [HyphenationOptions](./hyphenationoptions/) | Permite configurar opciones de guionización del documento. Para obtener más información, visite el artículo de documentación [Working with Hyphenation](https://docs.aspose.com/words/cpp/working-with-hyphenation/). |
| [MailMergeSettings](./mailmergesettings/) | Especifica toda la información de combinación de correspondencia para un documento. Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [Odso](./odso/) | Especifica la configuración del Objeto de Fuente de Datos de Office (ODSO) para una fuente de datos de combinación de correspondencia. Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapData](./odsofieldmapdata/) | Especifica cómo se debe mapear una columna de la fuente de datos externa a los campos de combinación predefinidos dentro del documento. Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapDataCollection](./odsofieldmapdatacollection/) | Una colección tipada de los objetos [OdsoFieldMapData](./odsofieldmapdata/). Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientData](./odsorecipientdata/) | Representa información sobre un único registro dentro de una fuente de datos externa que debe excluirse de la combinación de correspondencia. Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientDataCollection](./odsorecipientdatacollection/) | Una colección tipada de [OdsoRecipientData](./odsorecipientdata/)Para obtener más información, visite el artículo de documentación [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [ViewOptions](./viewoptions/) | Proporciona varias opciones que controlan cómo se muestra un documento en Microsoft Word. Para obtener más información, visite el artículo de documentación [Work with Options and Appearance of Word Documents](https://docs.aspose.com/words/cpp/work-with-word-document-options-and-appearance/). |
| [WriteProtection](./writeprotection/) | Especifica la configuración de protección contra escritura para un documento. Para obtener más información, visite el artículo de documentación [Protect or Encrypt a Document](https://docs.aspose.com/words/cpp/protect-or-encrypt-a-document/). |
