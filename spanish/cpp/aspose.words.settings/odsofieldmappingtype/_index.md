## OdsoFieldMappingType enum


Especifica los tipos posibles utilizados para indicar si un campo de combinación de correspondencia dado ha sido asignado a una columna en la fuente de datos externa proporcionada.

```cpp
enum class OdsoFieldMappingType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Columna | 0 | Especifica que el campo de combinación de correspondencia ha sido asignado a una columna en la fuente de datos externa especificada. |
| Null | 1 | Especifica que el campo de combinación de correspondencia no ha sido asignado a una columna en la fuente de datos externa especificada. |
| Default | n/a | Igual a [Null](./). |
