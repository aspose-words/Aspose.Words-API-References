## MailMergeDataType enum


Especifica el tipo de una fuente de datos externa para la combinación de correspondencia.

```cpp
enum class MailMergeDataType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | -1 | No se ha especificado ninguna fuente de datos de combinación de correspondencia. |
| TextFile | 0 | Especifica que un documento dado ha sido conectado a un archivo de texto mediante el sistema Dynamic Data Exchange (DDE). |
| Database | 1 | Especifica que un documento dado ha sido conectado a una base de datos Access mediante el sistema Dynamic Data Exchange (DDE). |
| Spreadsheet | 2 | Especifica que un documento dado ha sido conectado a una hoja de cálculo Excel mediante el sistema Dynamic Data Exchange (DDE). |
| Query | 3 | Especifica que un documento dado ha sido conectado a una fuente de datos externa usando una herramienta de consulta externa. |
| Odbc | 4 | Especifica que un documento dado ha sido conectado a una fuente de datos externa mediante la interfaz Open Database Connectivity. |
| Native | 5 | Especifica que un documento dado ha sido conectado a una fuente de datos externa mediante la interfaz Office Data Source Object (ODSO). |
| Default | n/a | Igual a [None](./). |
