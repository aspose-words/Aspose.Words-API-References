## MailMerge::get_CleanupParagraphsWithPunctuationMarks method


Obtiene o establece un valor que indica si los párrafos con signos de puntuación se consideran vacíos y deben eliminarse si la opción [RemoveEmptyParagraphs](../../mailmergecleanupoptions/) está especificada.

```cpp
bool Aspose::Words::MailMerging::MailMerge::get_CleanupParagraphsWithPunctuationMarks() const
```

## Observaciones


El valor predeterminado es **true**. Aquí está la lista completa de signos de puntuación que se pueden limpiar:

* !
* ,
* .
* :
* ;
* ?
* ¡
* ¿
