## FieldMergingArgsBase::get_FieldName method


Obtiene el nombre del campo de combinación en la fuente de datos.

```cpp
System::String Aspose::Words::MailMerging::FieldMergingArgsBase::get_FieldName() const
```

## Observaciones


Si tiene un mapeo de un nombre de campo del documento a un nombre de campo diferente en la fuente de datos, entonces este es el nombre de campo mapeado.

Si especificó un prefijo de nombre de campo, por ejemplo "Image:MyFieldName" en el documento, entonces [FieldName](./) devuelve el nombre del campo sin el prefijo, es decir "MyFieldName".
