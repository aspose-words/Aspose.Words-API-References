El espacio de nombres **Aspose.Words.Themes** proporciona clases que permiten acceder a la información de temas en documentos de Microsoft Word.

## Clases

| Clase | Descripción |
| --- | --- |
| [Theme](./theme/) | Representa el documento [Theme](./theme/) y proporciona acceso a las partes principales del tema, incluyendo [MajorFonts](./theme/get_majorfonts/), [MinorFonts](./theme/get_minorfonts/) y [Colors](./theme/get_colors/). Para obtener más información, visite el artículo de documentación [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeColors](./themecolors/) | Representa el esquema de colores del tema del documento, que contiene doce colores. El objeto [ThemeColors](./themecolors/) contiene seis colores de acento, dos colores oscuros, dos colores claros y un color para cada hipervínculo y hipervínculo visitado. |
| [ThemeFonts](./themefonts/) | Representa una colección de fuentes en el esquema de fuentes, permitiendo especificar diferentes fuentes para distintos idiomas [Latin](./themefonts/get_latin/), [EastAsian](./themefonts/get_eastasian/) y [ComplexScript](./themefonts/get_complexscript/). Para obtener más información, visite el artículo de documentación [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
## Enums

| Enumeración | Descripción |
| --- | --- |
| [ThemeColor](./themecolor/) | Especifica los colores del tema para los temas de documentos. Para obtener más información, visite el artículo de documentación [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeFont](./themefont/) | Especifica los tipos de nombres de fuentes de tema para los temas de documentos. |
