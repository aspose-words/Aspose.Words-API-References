## FormField::get_OwnStatus method


Especifica la fuente del texto que se muestra en la barra de estado cuando un campo de formulario tiene el foco.

```cpp
bool Aspose::Words::Fields::FormField::get_OwnStatus()
```

## Observaciones


Si **true**, se muestra el texto especificado por la propiedad [StatusText](../get_statustext/). Si **false**, se muestra el texto de la entrada AutoText especificada por la propiedad [StatusText](../get_statustext/).
