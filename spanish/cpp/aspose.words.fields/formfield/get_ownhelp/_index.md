## FormField::get_OwnHelp method


Especifica la fuente del texto que se muestra en un cuadro de mensaje cuando un campo de formulario tiene el foco y el usuario pulsa F1.

```cpp
bool Aspose::Words::Fields::FormField::get_OwnHelp()
```

## Observaciones


Si **true**, se muestra el texto especificado por la propiedad [HelpText](../get_helptext/). Si **false**, se muestra el texto en la entrada AutoText especificada por la propiedad [HelpText](../get_helptext/).
