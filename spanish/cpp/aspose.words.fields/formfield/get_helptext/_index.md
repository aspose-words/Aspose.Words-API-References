## FormField::get_HelpText method


Devuelve o establece el texto que se muestra en un cuadro de mensaje cuando el campo de formulario tiene el foco y el usuario pulsa F1.

```cpp
System::String Aspose::Words::Fields::FormField::get_HelpText()
```

## Observaciones


Si la propiedad [OwnHelp](../get_ownhelp/) está establecida en **true**, [HelpText](./) especifica el valor de cadena de texto. Si [OwnHelp](../get_ownhelp/) está establecida en **false**, [HelpText](./) especifica el nombre de una entrada de AutoTexto que contiene texto de ayuda para el campo de formulario.

Microsoft Word permite cadenas con un máximo de 255 caracteres.
