## Merger::Merge(const System::String\&, const System::ArrayPtr\<System::String\>\&) method


Fusiona los documentos de entrada proporcionados en un solo documento de salida usando los nombres de archivo de entrada y salida especificados mediante [KeepSourceFormatting](../../mergeformatmode/).

```cpp
static void Aspose::Words::LowCode::Merger::Merge(const System::String &outputFile, const System::ArrayPtr<System::String> &inputFiles)
```


| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| outputFile | const System::String\& | El nombre del archivo de salida. |
| inputFiles | const System::ArrayPtr\<System::String\>\& | Los nombres de archivo de entrada. |
## Observaciones


Si el formato de salida es una imagen (BMP, EMF, EPS, GIF, JPEG, PNG o WebP), cada página de la salida se guardará como un archivo separado. El nombre de archivo de salida especificado se utilizará para generar los nombres de archivo de cada parte siguiendo la regla: outputFile_partIndex.extension.

Si el formato de salida es TIFF, la salida se guardará como un único archivo TIFF de varios fotogramas.
