## MailMergeOptions::get_CleanupParagraphsWithPunctuationMarks method


Obtiene o establece un valor que indica si los párrafos con signos de puntuación se consideran vacíos y deben eliminarse si la opción [RemoveEmptyParagraphs](../../../aspose.words.mailmerging/mailmergecleanupoptions/) está especificada.

```cpp
bool Aspose::Words::LowCode::MailMergeOptions::get_CleanupParagraphsWithPunctuationMarks() const
```

## Observaciones


El valor predeterminado es **true**. Aquí está la lista completa de signos de puntuación que se pueden limpiar:

* !
* ,
* .
* :
* ;
* ?
* ¡
* ¿
