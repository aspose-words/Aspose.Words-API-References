El espacio de nombres **Aspose.Words.WebExtensions** proporciona clases que permiten personalizar elementos y atributos que amplían el vocabulario XML para representar complementos de Office.

## Clases

| Clase | Descripción |
| --- | --- |
| [BaseWebExtensionCollection](./basewebextensioncollection/) | Clase base para las colecciones [TaskPaneCollection](./taskpanecollection/), [WebExtensionBindingCollection](./webextensionbindingcollection/), [WebExtensionPropertyCollection](./webextensionpropertycollection/) y [WebExtensionReferenceCollection](./webextensionreferencecollection/). Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [TaskPane](./taskpane/) | Representa un objeto de panel de tareas de complemento. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [TaskPaneCollection](./taskpanecollection/) | Especifica una lista de objetos de panel de tareas persistentes. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtension](./webextension/) | Representa un objeto de extensión web. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtensionBinding](./webextensionbinding/) | Especifica una relación de enlace entre una extensión web y los datos del documento. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Especifica una lista de enlaces de extensiones web. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtensionProperty](./webextensionproperty/) | Especifica una propiedad personalizada de la extensión web. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Especifica un conjunto de propiedades personalizadas de la extensión web. | [WebExtensionReference](./webextensionreference/) | Representa la referencia a una extensión web. La referencia se utiliza para identificar la ubicación del proveedor y la versión de la extensión. | [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Especifica una lista de referencias de extensiones web. Para obtener más información, visite el artículo de documentación [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
