El espacio de nombres **Aspose.Words.Notes** proporciona clases para trabajar con notas al final y notas al pie de Microsoft Word.

## Clases

| Clase | Descripción |
| --- | --- |
| [EndnoteOptions](./endnoteoptions/) | Representa las opciones de numeración de notas al final para un documento o sección. Para obtener más información, visite el artículo de documentación [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [Footnote](./footnote/) | Representa un contenedor para el texto de una nota al pie o nota al final. Para obtener más información, visite el artículo de documentación [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteOptions](./footnoteoptions/) | Representa las opciones de numeración de notas al pie para un documento o sección. Para obtener más información, visite el artículo de documentación [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteSeparator](./footnoteseparator/) | Representa un contenedor para el separador de notas al pie/al final y el contenido de continuación de un documento. |
| [FootnoteSeparatorCollection](./footnoteseparatorcollection/) | Proporciona acceso tipado a los nodos [FootnoteSeparator](./footnoteseparator/) de un documento. |
