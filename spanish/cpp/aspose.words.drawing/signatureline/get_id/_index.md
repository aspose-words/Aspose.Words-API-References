## SignatureLine::get_Id method


Obtiene o establece el identificador para esta línea de firma. Este identificador puede estar asociado con una firma digital, al firmar el documento usando [DigitalSignatureUtil](../../../aspose.words.digitalsignatures/digitalsignatureutil/). Este valor debe ser único y, por defecto, se genera aleatoriamente un nuevo Guid (**NewGuid**).
