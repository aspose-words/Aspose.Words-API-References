## ArrowType enum


Especifica el tipo de flecha al final de una línea.

```cpp
enum class ArrowType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | La línea no tiene una flecha al final. |
| Flecha | 1 | La flecha es un triángulo sólido. |
| Stealth | 2 | La flecha es una flecha "stealth". |
| Rombo | 3 | El extremo de la línea es un diamante sólido. |
| Oval | 4 | El extremo de la línea es un óvalo sólido. |
| Open | 5 | La flecha es una flecha abierta. |
| Default | n/a | Lo mismo que [None](./). |
