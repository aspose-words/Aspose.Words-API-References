El espacio de nombres **Aspose.Words.Lists** contiene clases para trabajar con listas con viñetas y numeradas definidas en un documento.

## Clases

| Clase | Descripción |
| --- | --- |
| [List](./list/) | Representa el formato de una lista. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListCollection](./listcollection/) | Almacena y gestiona el formato de listas con viñetas y numeradas usadas en un documento. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListFormat](./listformat/) | Permite controlar qué formato de lista se aplica a un párrafo. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLabel](./listlabel/) | Define propiedades específicas de una etiqueta de lista. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevel](./listlevel/) | Define el formato para un nivel de lista. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevelCollection](./listlevelcollection/) | Una colección de formatos de lista para cada nivel en una lista. Para obtener más información, visite el artículo de documentación [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
## Enums

| Enumeración | Descripción |
| --- | --- |
| [ListLevelAlignment](./listlevelalignment/) | Especifica la alineación del número o viñeta de la lista. |

| [ListTrailingCharacter](./listtrailingcharacter/) | Especifica el carácter que separa la etiqueta de la lista del texto del párrafo. |
