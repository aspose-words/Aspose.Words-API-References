El espacio de nombres **Aspose.Words.Comparing** proporciona clases y enumeraciones que permiten especificar opciones adicionales al comparar documentos.

## Clases

| Clase | Descripción |
| --- | --- |
| [AdvancedCompareOptions](./advancedcompareoptions/) | Permite establecer opciones avanzadas de comparación. |
| [CompareOptions](./compareoptions/) | Permite elegir opciones adicionales para la operación de comparación de documentos. Para obtener más información, visite el artículo de documentación [Compare Documents](https://docs.aspose.com/words/cpp/compare-documents/). |
## Enums

| Enumeración | Descripción |
| --- | --- |
| [ComparisonTargetType](./comparisontargettype/) | Permite especificar el documento base que se utilizará durante la comparación. El valor predeterminado es [Current](./comparisontargettype/). |
| [Granularity](./granularity/) | Especifica la granularidad de los cambios a rastrear al comparar dos documentos. |
