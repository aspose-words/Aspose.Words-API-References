## Observaciones


Los bloques de construcción en la interfaz de usuario de Microsoft Word se organizan en galerías. Cada [Gallery](./) puede tener múltiples categorías. Cada bloque dentro de una [Category](../get_category/) tiene un [Name](../get_name/).

Corresponde al elemento **docPartPr.category.gallery** en OOXML.
