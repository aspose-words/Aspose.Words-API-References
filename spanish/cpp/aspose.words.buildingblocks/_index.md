El espacio de nombres **Aspose.Words.BuildingBlocks** proporciona clases que permiten acceder y usar AutoTexto, entradas de AutoCorrección y bloques de construcción en un documento.

## Clases

| Clase | Descripción |
| --- | --- |
| [BuildingBlock](./buildingblock/) | Representa una entrada de documento de glosario como un Building Block, AutoText o una entrada de AutoCorrect. Para obtener más información, visite el artículo de documentación [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [BuildingBlockCollection](./buildingblockcollection/) | Una colección de objetos [BuildingBlock](./buildingblock/) en el documento. Para obtener más información, visite el artículo de documentación [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [GlossaryDocument](./glossarydocument/) | Representa el elemento raíz de un documento de glosario dentro de un documento de Word. Un documento de glosario es un almacenamiento para AutoText, entradas de AutoCorrect y Building Blocks. Para obtener más información, visite el artículo de documentación [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
## Enums

| Enumeración | Descripción |
| --- | --- |
| [BuildingBlockBehavior](./buildingblockbehavior/) | Especifica el comportamiento que se aplicará al contenido del bloque de construcción cuando se inserta en el documento principal. |
| [BuildingBlockGallery](./buildingblockgallery/) | Especifica la galería predefinida en la que se clasifica un bloque de construcción. |
| [BuildingBlockType](./buildingblocktype/) | Especifica un tipo de bloque de construcción. El tipo podría afectar la visibilidad y el comportamiento del bloque de construcción en Microsoft Word. |
