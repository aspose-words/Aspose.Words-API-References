## DmlRenderingMode enum


Especifica cómo se renderizan las formas DrawingML en formatos de página fija.

```cpp
enum class DmlRenderingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Fallback | 0 | Si hay una forma de respaldo disponible para DrawingML, Aspose.Words renderiza la forma de respaldo en lugar del DrawingML. |
| DrawingML | 1 | Aspose.Words ignora la forma de respaldo de DrawingML y renderiza el propio DrawingML. Este es el modo predeterminado. |
