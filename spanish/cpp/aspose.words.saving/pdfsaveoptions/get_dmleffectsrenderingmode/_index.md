## PdfSaveOptions::get_DmlEffectsRenderingMode method


Obtiene o establece un valor que determina cómo se renderizan los efectos DrawingML.

```cpp
Aspose::Words::Saving::DmlEffectsRenderingMode Aspose::Words::Saving::PdfSaveOptions::get_DmlEffectsRenderingMode() override
```

## Observaciones


El valor predeterminado es [Simplified](../../dmleffectsrenderingmode/).

Esta propiedad se utiliza cuando el documento se exporta a formatos de página fija.

Si [Compliance](../get_compliance/) está configurado a [PdfA1a](../../pdfcompliance/) o [PdfA1b](../../pdfcompliance/), la propiedad siempre devuelve [None](../../dmleffectsrenderingmode/).
