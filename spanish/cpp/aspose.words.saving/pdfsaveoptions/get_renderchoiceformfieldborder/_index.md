## PdfSaveOptions::get_RenderChoiceFormFieldBorder method


Especifica si se debe renderizar el borde del campo de formulario de elección en PDF.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_RenderChoiceFormFieldBorder() const
```

## Observaciones


Los campos de formulario de elección PDF se utilizan para exportar el control de contenido de cuadro combinado SDT, el control de contenido de lista desplegable SDT y el campo de formulario desplegable heredado cuando la opción [PreserveFormFields](../get_preserveformfields/) está habilitada.

El valor predeterminado es **true**.
