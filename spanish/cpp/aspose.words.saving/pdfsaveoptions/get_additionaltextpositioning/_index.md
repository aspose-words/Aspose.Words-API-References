## PdfSaveOptions::get_AdditionalTextPositioning method


Una bandera que indica si se deben escribir operadores adicionales de posicionamiento de texto o no.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_AdditionalTextPositioning() const
```

## Observaciones


Si **true**, los operadores adicionales de posicionamiento de texto se escriben en el PDF de salida. Esto puede ayudar a superar problemas de posicionamiento inexacto del texto con algunas impresoras. La desventaja es el aumento del tamaño del documento PDF.

El valor predeterminado es **false**.
