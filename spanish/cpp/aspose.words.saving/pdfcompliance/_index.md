## PdfCompliance enum


Especifica el nivel de cumplimiento de los estándares PDF.

```cpp
enum class PdfCompliance
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Pdf17 | 0 | El archivo de salida cumplirá con la norma PDF 1.7 (ISO 32000-1). |
| Pdf20 | 1 | El archivo de salida cumplirá con la norma PDF 2.0 (ISO 32000-2). |
| PdfA1a | 2 | El archivo de salida cumplirá con la norma PDF/A-1a (ISO 19005-1). Este nivel incluye todos los requisitos de PDF/A-1b y, además, exige que se incluya la estructura del documento (también conocida como "tagged"), con el objetivo de garantizar que el contenido del documento pueda ser buscado y reutilizado. |
| PdfA1b | 3 | El archivo de salida cumplirá con la norma PDF/A-1b (ISO 19005-1). PDF/A-1b tiene como objetivo garantizar la reproducción fiable de la apariencia visual del documento. |
| PdfA2a | 4 | El archivo de salida cumplirá con la norma PDF/A-2a (ISO 19005-2). Este nivel incluye todos los requisitos de PDF/A-2u y, adicionalmente, requiere que se incluya la estructura del documento (también conocida como "etiquetado"), con el objetivo de garantizar que el contenido del documento pueda ser buscado y reutilizado. |
| PdfA2u | 5 | El archivo de salida cumplirá con la norma PDF/A-2u (ISO 19005-2). PDF/A-2u tiene como objetivo preservar la apariencia visual estática del documento a lo largo del tiempo, independientemente de las herramientas y sistemas utilizados para crear, almacenar o renderizar los archivos. Además, cualquier texto contenido en el documento puede extraerse de forma fiable como una serie de puntos de código Unicode. |
| PdfA3a | 6 | El archivo de salida cumplirá con la norma PDF/A-3a (ISO 19005-3). Este nivel incluye todos los requisitos de PDF/A-3u y, adicionalmente, requiere que se incluya la estructura del documento (también conocida como "etiquetado"), con el objetivo de garantizar que el contenido del documento pueda ser buscado y reutilizado. |
| PdfA3u | 7 | El archivo de salida cumplirá con la norma PDF/A-3u (ISO 19005-3). PDF/A-3u (al igual que PDF/A-2u) tiene como objetivo preservar la apariencia visual estática del documento a lo largo del tiempo, independientemente de las herramientas y sistemas utilizados para crear, almacenar o renderizar los archivos. Además, cualquier texto contenido en el documento puede extraerse de forma fiable como una serie de puntos de código Unicode. Además de PDF/A-2u, PDF/A-3u permite incrustar archivos adjuntos en el documento PDF. |
| PdfA4 | 8 | El archivo de salida cumplirá con la norma PDF/A-4 (ISO 19005-4:2020). PDF/A-4 tiene como objetivo preservar la apariencia visual estática del documento a lo largo del tiempo, independientemente de las herramientas y sistemas utilizados para crear, almacenar o renderizar los archivos. Además, cualquier texto contenido en el documento puede extraerse de forma fiable como una serie de puntos de código Unicode. |
| PdfA4f | 9 | El archivo de salida cumplirá con la norma PDF/A-4f (ISO 19005-4:2020). Este nivel incluye todos los requisitos de PDF/A-4 y, adicionalmente, permite incrustar archivos adjuntos en el documento PDF. |
| PdfA4Ua2 | 10 | El archivo de salida cumplirá con las normas PDF/A-4 (ISO 19005-4:2020) y PDF/UA-2 (ISO 14289-2:2024). PDF/A-4 tiene como objetivo preservar la apariencia visual estática del documento a lo largo del tiempo, independientemente de las herramientas y sistemas utilizados para crear, almacenar o renderizar los archivos. El propósito principal de PDF/UA es definir cómo representar documentos electrónicos en formato PDF de manera que el archivo sea accesible. |
| PdfUa1 | 11 | El archivo de salida cumplirá con la norma PDF/UA-1 (ISO 14289-1). El propósito principal de PDF/UA es definir cómo representar documentos electrónicos en formato PDF de manera que el archivo sea accesible. |
| PdfUa2 | 12 | El archivo de salida cumplirá con la norma PDF/UA-2 (ISO 14289-2:2024). El propósito principal de PDF/UA es definir cómo representar documentos electrónicos en formato PDF de manera que el archivo sea accesible. |
