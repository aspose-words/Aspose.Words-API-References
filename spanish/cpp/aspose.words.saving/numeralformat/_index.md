## NumeralFormat enum


Indica el conjunto de símbolos que se usa para representar números al renderizar a formatos de página fija.

```cpp
enum class NumeralFormat
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Europeo | 0 | Números europeos: 0123456789. |
| ArabicIndic | 1 | Números usados en árabe: ٠١٢٣٤٥٦٧٨٩. Rango Unicode U+0660 - u+0669. |
| EasternArabicIndic | 2 | Números usados en persa y urdu: ۰۱۲۳۴۵۶۷۸۹. Rango Unicode U+06F0 - u+06F9. |
| Contexto | 3 | El conjunto de símbolos se decide a partir del contexto (locale y propiedad RTL). |
| Sistema | 4 | ESTA OPCIÓN NO ES COMPATIBLE. El conjunto de símbolos se decide a partir de la configuración regional. |
