## FontSavingArgs::get_FontStream method


Permite especificar el flujo donde se guardará la fuente.

```cpp
System::SharedPtr<System::IO::Stream> Aspose::Words::Saving::FontSavingArgs::get_FontStream() const
```

## Observaciones


Esta propiedad le permite guardar fuentes en flujos en lugar de archivos durante la exportación HTML.

El valor predeterminado es **null**. Cuando esta propiedad es **null**, la fuente se guardará en un archivo especificado en la propiedad [FontFileName](../get_fontfilename/).
