## FontSavingArgs::get_KeepFontStreamOpen method


Especifica si Aspose.Words debe mantener el flujo abierto o cerrarlo después de guardar una fuente.

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## Observaciones


El valor predeterminado es **false** y Aspose.Words cerrará el flujo que proporcionó en la propiedad [FontStream](../get_fontstream/) después de escribir una fuente en él. Especifique **true** para mantener el flujo abierto.
