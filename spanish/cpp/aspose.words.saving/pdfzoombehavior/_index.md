## PdfZoomBehavior enum


Especifica el tipo de zoom aplicado a un documento PDF cuando se abre en un visor de PDF.

```cpp
enum class PdfZoomBehavior
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | Cómo se muestra el documento depende del visor PDF. Normalmente el visor muestra el documento ajustado al ancho de la página. |
| ZoomFactor | 1 | Muestra la página usando el factor de zoom especificado. |
| FitPage | 2 | Muestra la página para que sea visible completamente. |
| FitWidth | 3 | Ajusta el ancho de la página. |
| FitHeight | 4 | Ajusta la altura de la página. |
| FitBox | 5 | Ajusta el cuadro delimitador (rectángulo que contiene todos los elementos visibles en la página). |
