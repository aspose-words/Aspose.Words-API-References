## OutlineOptions::get_HeadingsOutlineLevels method


Especifica cuántos niveles de encabezados (párrafos con los estilos de Encabezado) incluir en el esquema del documento.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_HeadingsOutlineLevels() const
```

## Observaciones


Especifique 0 para no incluir encabezados en el esquema; especifique 1 para un nivel de encabezados en el esquema y así sucesivamente.

El valor predeterminado es 0. El rango válido es de 0 a 9.
