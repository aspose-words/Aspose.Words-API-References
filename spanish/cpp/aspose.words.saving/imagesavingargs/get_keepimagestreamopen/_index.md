## ImageSavingArgs::get_KeepImageStreamOpen method


Especifica si Aspose.Words debe mantener el flujo abierto o cerrarlo después de guardar una imagen.

```cpp
bool Aspose::Words::Saving::ImageSavingArgs::get_KeepImageStreamOpen() const
```

## Observaciones


El valor predeterminado es **false** y Aspose.Words cerrará el flujo que proporcionó en la propiedad [ImageStream](../get_imagestream/) después de escribir una imagen en él. Especifique **true** para mantener el flujo abierto.
