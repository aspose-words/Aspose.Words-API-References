## ImageSaveOptions::get_GraphicsQualityOptions method


Permite especificar el modo de renderizado y la calidad para el objeto **Graphics**.

```cpp
System::SharedPtr<Aspose::Words::Saving::GraphicsQualityOptions> Aspose::Words::Saving::ImageSaveOptions::get_GraphicsQualityOptions() const
```

## Observaciones


Utiliza esta propiedad para sobrescribir la configuración de Graphics proporcionada por el motor Aspose.Words de forma predeterminada.

Tendrá efecto solo cuando un documento se guarde en un formato similar a una imagen.
