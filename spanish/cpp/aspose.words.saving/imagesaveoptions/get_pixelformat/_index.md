## ImageSaveOptions::get_PixelFormat method


Obtiene o establece el formato de píxel para las imágenes generadas.

```cpp
Aspose::Words::Saving::ImagePixelFormat Aspose::Words::Saving::ImageSaveOptions::get_PixelFormat() const
```

## Observaciones


Esta propiedad tiene efecto solo al guardar en formatos de imagen raster.

El valor predeterminado es [Format32BppArgb](../../imagepixelformat/).

El formato de píxel de la imagen de salida puede diferir del valor establecido debido al trabajo de GDI+.
