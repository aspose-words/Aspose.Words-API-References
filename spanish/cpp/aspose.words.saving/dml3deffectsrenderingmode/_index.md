## Dml3DEffectsRenderingMode enum


Especifica cómo se renderizan los efectos de formas 3D.

```cpp
enum class Dml3DEffectsRenderingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Basic | 0 | Una renderización ligera y estable, basada en el motor interno, pero los efectos avanzados como iluminación, materiales y otros efectos adicionales no se muestran al usar este modo. Consulte la documentación para obtener más detalles. |
| Advanced | 1 | [Renderizado](../../aspose.words.rendering/) de una lista ampliada de efectos especiales, incluidos los efectos 3D avanzados como biseles, iluminación y materiales. |
