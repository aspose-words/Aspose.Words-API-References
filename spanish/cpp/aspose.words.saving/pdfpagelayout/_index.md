## PdfPageLayout enum


Especifica el diseño de página que se usará cuando el documento se abra en un lector PDF.

```cpp
enum class PdfPageLayout
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| SinglePage | 0 | Muestra una página a la vez. |
| OneColumn | 1 | Muestra las páginas en una columna. |
| TwoColumnLeft | 2 | Muestra las páginas en dos columnas, con las páginas impares a la izquierda. |
| TwoColumnRight | 3 | Muestra las páginas en dos columnas, con las páginas impares a la derecha. |
| TwoPageLeft | 4 | Muestra dos páginas a la vez, con las páginas impares a la izquierda. |
| TwoPageRight | 5 | Muestra dos páginas a la vez, con las páginas impares a la derecha. |
