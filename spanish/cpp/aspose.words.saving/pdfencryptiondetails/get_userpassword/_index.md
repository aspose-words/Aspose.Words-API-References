## PdfEncryptionDetails::get_UserPassword method


Especifica la contraseña de usuario requerida para abrir el documento PDF cifrado.

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_UserPassword() const
```

## Observaciones


Se requerirá la contraseña de usuario para abrir un documento PDF cifrado para su visualización. Los permisos especificados en [Permissions](../get_permissions/) serán aplicados por el software lector.

La contraseña de usuario puede ser **null** o una cadena vacía; en este caso no se requerirá ninguna contraseña al usuario al abrir el documento PDF. La contraseña de usuario no puede ser la misma que la contraseña del propietario.
