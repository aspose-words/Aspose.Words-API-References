## HtmlFixedSaveOptions::get_ResourcesFolderAlias method


Especifica el nombre de la carpeta utilizada para construir los URIs de imágenes escritos en un documento Html. El valor predeterminado es **null**.

```cpp
System::String Aspose::Words::Saving::HtmlFixedSaveOptions::get_ResourcesFolderAlias() const
```

## Observaciones


Cuando guardas un [Document](../../../aspose.words/document/) en formato Html, Aspose.Words necesita guardar todas las imágenes incrustadas en el documento como archivos independientes. [ResourcesFolder](../get_resourcesfolder/) te permite especificar dónde se guardarán las imágenes y [ResourcesFolderAlias](./) permite especificar cómo se construirán los URI de las imágenes.
