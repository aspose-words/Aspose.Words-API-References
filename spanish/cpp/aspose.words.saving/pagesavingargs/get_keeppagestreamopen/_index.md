## PageSavingArgs::get_KeepPageStreamOpen method


Especifica si Aspose.Words debe mantener el flujo abierto o cerrarlo después de guardar una página del documento.

```cpp
bool Aspose::Words::Saving::PageSavingArgs::get_KeepPageStreamOpen() const
```

## Observaciones


El valor predeterminado es **false** y Aspose.Words cerrará el flujo que proporcionó en la propiedad [PageStream](../get_pagestream/) después de escribir una página del documento en él. Especifique **true** para mantener el flujo abierto.
