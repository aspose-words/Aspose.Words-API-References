## CssStyleSheetType enum


Especifica cómo se exportan los estilos CSS (Cascading [Style](../../aspose.words/style/) Sheet) a HTML.

```cpp
enum class CssStyleSheetType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| En línea | 0 | Los estilos CSS se escriben en línea (como valor del atributo **style** en cada elemento). |
| Incrustado | 1 | Los estilos CSS se escriben por separado del contenido en una hoja de estilo incrustada en el archivo HTML. |
| Externo | 2 | Los estilos CSS se escriben por separado del contenido en una hoja de estilo en un archivo externo. El archivo HTML enlaza la hoja de estilo. |
