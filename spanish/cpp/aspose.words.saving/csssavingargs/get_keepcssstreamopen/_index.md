## CssSavingArgs::get_KeepCssStreamOpen method


Especifica si Aspose.Words debe mantener el flujo abierto o cerrarlo después de guardar la información CSS.

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## Observaciones


El valor predeterminado es **false** y Aspose.Words cerrará el flujo que proporcionó en la propiedad [CssStream](../get_cssstream/) después de escribir información CSS en él. Especifique **true** para mantener el flujo abierto.
