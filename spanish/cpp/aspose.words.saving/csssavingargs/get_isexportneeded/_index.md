## CssSavingArgs::get_IsExportNeeded method


Permite especificar si el CSS se exportará a un archivo y se incrustará en el documento HTML. El valor predeterminado es **true**. Cuando esta propiedad es **false**, la información CSS no se guardará en un archivo CSS y no se incrustará en el documento HTML.
