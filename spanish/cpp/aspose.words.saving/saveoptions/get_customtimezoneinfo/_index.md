## SaveOptions::get_CustomTimeZoneInfo method


Obtiene o establece la zona horaria local personalizada utilizada para los campos de fecha/hora.

```cpp
System::SharedPtr<System::TimeZoneInfo> Aspose::Words::Saving::SaveOptions::get_CustomTimeZoneInfo() const
```

## Observaciones


Esta opción está disponible tanto en el framework .Net a partir de la versión 3.5 como en .Net Standard.

Por defecto, Aspose.Words utiliza la zona horaria local del sistema al escribir campos de fecha/hora; esta opción permite establecer un valor personalizado.
