## ResourceLoadingAction enum


Especifica el modo de carga de recursos. Para obtener más información, visite el artículo de documentación [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/).

```cpp
enum class ResourceLoadingAction
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Predeterminado | 0 | Aspose.Words cargará este recurso como de costumbre. |
| Omitir | 1 | Aspose.Words omitirá la carga de este recurso. Sólo se almacenará el enlace sin datos para una imagen, la hoja de estilo CSS será ignorada para el formato HTML. |
| UserProvided | 2 | Aspose.Words usará la matriz de bytes proporcionada por el usuario en [SetData()](../) como datos del recurso. |
