El espacio de nombres **Aspose.Words.Vba** proporciona clases para trabajar con proyectos VBA.

## Clases

| Clase | Descripción |
| --- | --- |
| [VbaModule](./vbamodule/) | Proporciona acceso al módulo del proyecto VBA. Para obtener más información, visite el artículo de documentación [Working with VBA Macros](https://docs.aspose.com/words/cpp/working-with-vba-macros/). |
| [VbaModuleCollection](./vbamodulecollection/) | Representa una colección de objetos [VbaModule](./vbamodule/). Para obtener más información, visite el artículo de documentación [Working with VBA Macros](https://docs.aspose.com/words/cpp/working-with-vba-macros/). |
| [VbaProject](./vbaproject/) | Proporciona acceso a la información del proyecto VBA. Un proyecto VBA dentro del documento se define como una colección de módulos VBA. Para obtener más información, visite el artículo de documentación [Working with VBA Macros](https://docs.aspose.com/words/cpp/working-with-vba-macros/). |
| [VbaReference](./vbareference/) | Implementa una referencia a una biblioteca de tipos Automation o a un proyecto VBA. Para obtener más información, visite el artículo de documentación [Working with VBA Macros](https://docs.aspose.com/words/cpp/working-with-vba-macros/). |
| [VbaReferenceCollection](./vbareferencecollection/) | Representa una colección de objetos [VbaReference](./vbareference/). Para obtener más información, visite el artículo de documentación [Working with VBA Macros](https://docs.aspose.com/words/cpp/working-with-vba-macros/). |
