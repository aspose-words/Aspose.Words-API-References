El paquete **com.aspose.words** proporciona clases para generar, convertir, modificar, renderizar e imprimir documentos de Microsoft Word sin utilizar Microsoft Word.

Aspose.Words está escrito completamente en Java. Microsoft Word no es necesario para usar Aspose.Words.

Las clases en el paquete **com.aspose.words** adoptan las mejores prácticas de dos marcos bien conocidos: Microsoft Word Automation y System.Xml. Un documento en Aspose.Words se representa mediante un árbol de nodos, muy similar al DOM XML. Cuando es posible, los nombres de clases, métodos y propiedades coinciden con los encontrados en Microsoft Word Automation.

Las clases principales en este espacio de nombres son:

 *  **Document** is the main class of the object model that represents a Microsoft Word document.
 *  **DocumentBuilder** provides an easy way to insert content and formatting into a document.
 *  **Node** is the base class for all nodes in the document.
 *  **CompositeNode** is the base class for all nodes of the document that can contain other nodes, for example **Paragraph**, **Section** and **Table** and .

El paquete **com.aspose.words** también contiene clases que forman el motor de informes de Aspose.Words. El motor de informes permite rellenar rápida y fácilmente documentos diseñados en Microsoft Word con datos de diversas fuentes, como **java.sql.ResultSet**, **matriz de ResultSets**, **com.aspose.words.net.System.Data.DataSet** o una **matriz de valores**.

El objeto **MailMerge**, que brinda acceso a la funcionalidad de informes, está disponible a través de la propiedad **Document.MailMerge**.
