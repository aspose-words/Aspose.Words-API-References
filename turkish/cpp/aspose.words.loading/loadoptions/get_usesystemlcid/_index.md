## LoadOptions::get_UseSystemLcid method


Sayfa ayarı varsayılan kenar boşluklarını belirlemek için Windows kayıt defterinden alınan LCID değerinin kullanılıp kullanılmayacağını alır veya ayarlar.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Açıklamalar


Eğer **true** olarak ayarlanırsa, Windows kayıt defterinden LCID değerini alan MS Word davranışı taklit edilir.

Varsayılan değer **false**'tur.
