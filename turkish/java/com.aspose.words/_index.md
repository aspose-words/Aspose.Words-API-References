Bu **com.aspose.words** paketi, Microsoft Word'i kullanmadan Microsoft Word belgelerini oluşturma, dönüştürme, değiştirme, render etme ve yazdırma için sınıflar sağlar.

Aspose.Words tamamen Java ile yazılmıştır. Aspose.Words'i kullanmak için Microsoft Word gerekli değildir.

Bu **com.aspose.words** paketindeki sınıflar, iki tanınmış çerçeveden en iyi uygulamaları alır: Microsoft Word Automation ve System.Xml. Aspose.Words'teki bir belge, XML DOM'daki gibi düğüm ağacıyla temsil edilir. Mümkün olduğunda, sınıf, yöntem ve özellik adları Microsoft Word Automation'da bulunanlarla eşleşir.

Bu ad alanındaki ana sınıflar şunlardır:

 *  **Document** is the main class of the object model that represents a Microsoft Word document.
 *  **DocumentBuilder** provides an easy way to insert content and formatting into a document.
 *  **Node** is the base class for all nodes in the document.
 *  **CompositeNode** is the base class for all nodes of the document that can contain other nodes, for example **Paragraph**, **Section** and **Table** and .

Bu **com.aspose.words** paketi ayrıca Aspose.Words'un raporlama motorunu oluşturan sınıfları da içerir. Raporlama motoru, Microsoft Word'de tasarlanmış belgeleri **java.sql.ResultSet**, **array of ResultSets**, **com.aspose.words.net.System.Data.DataSet** veya **array of values** gibi çeşitli veri kaynaklarından gelen verilerle hızlı ve kolay bir şekilde doldurmayı sağlar.

Bu **MailMerge** nesnesi, raporlama işlevine erişim sağlar ve **Document.MailMerge** özelliği aracılığıyla kullanılabilir.
