### CONTEXTUAL_LIGATURES {#CONTEXTUAL-LIGATURES}

Tipografik amaçlar için tercih edilen tek bir glif ile bir glif dizisini değiştirir. Diğer ligatür özelliklerinden farklı olarak, 'clig' ligatürün önerildiği bağlamı belirtir. Bu yetenek bazı yazı tasarımlarında ve süslü ligatürlerde önemlidir. https://docs.microsoft.com/en-us/typography/opentype/spec/features\_ae\#clig Equivalent OpenType tag: 'clig'

### GLYPH_COMPOSITION_DECOMPOSITION {#GLYPH-COMPOSITION-DECOMPOSITION}
```
public static int GLYPH_COMPOSITION_DECOMPOSITION
```


Glif alternatiflerinin sayısını en aza indirmek için, bazen bir karakterin varsayılan glifini iki veya daha fazla glife ayırmak istenir. Ayrıca, iki veya daha fazla karakterin varsayılan gliflerini daha iyi glif işleme için tek bir glife birleştirmek tercih edilebilir. Bu özellik bu tür birleştirme/ayırmayı sağlar. https://docs.microsoft.com/en-us/typography/opentype/spec/features\_ae\#ccmp Equivalent OpenType tag: 'ccmp'

### HISTORICAL_LIGATURES {#HISTORICAL-LIGATURES}
```
public static int HISTORICAL_LIGATURES
```


Bazı ligatürler geçmişte yaygın olarak kullanılıyordu, ancak bugün tarih dışı görünüyor. Bazı yazı tipleri tarihsel formları alternatif olarak içerir, böylece bir "dönem" etkisi için kullanılabilir. Bu özellik varsayılan (güncel) formları tarihsel alternatiflerle değiştirir. https://docs.microsoft.com/en-us/typography/opentype/spec/features\_fj\#hlig Equivalent OpenType tag: 'hlig'

### KERNING {#KERNING}
```
public static int KERNING
```


Glifler arasındaki boşluk miktarını ayarlar, genellikle glifler arasında optik olarak tutarlı bir aralık sağlamak için. İyi tasarlanmış bir yazı tipinin genel olarak tutarlı glif aralığı olsa da, bazı glif kombinasyonları okunabilirliği artırmak için ayarlama gerektirir. Yatay yöndeki standart ayarlamanın yanı sıra, bu özellik cihaz tabloları aracılığıyla boyuta bağlı kerning verisi, Y metin yönünde "çapraz akış" kerning ve ilerleme ayarlamasından bağımsız glif yerleşimi ayarlaması sağlayabilir. Bu özelliğin iki gliften fazla bir diziye uygulanabileceğini ve tek aralıklı (monospaced) yazı tiplerinde kullanılmayacağını unutmayın. Ayrıca bu özelliğin dikey olarak ayarlanmış metne uygulanmadığını da not edin. https://docs.microsoft.com/en-us/typography/opentype/spec/features\_ko\#kern Equivalent OpenType tag: 'kern'

### TABULAR_FIGURES {#TABULAR-FIGURES}
```
public static int TABULAR_FIGURES
```


Oranlı genişliklerde ayarlanmış rakam gliflerini, aynı gliflerin sabit (tablo) genişliklerdeki karşılıklarıyla değiştirir.
