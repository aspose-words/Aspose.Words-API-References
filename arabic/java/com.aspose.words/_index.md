توفر الحزمة **com.aspose.words** فئات لتوليد، تحويل، تعديل، عرض وطباعة مستندات Microsoft Word دون الحاجة إلى استخدام Microsoft Word.

تم كتابة Aspose.Words بالكامل بلغة Java. لا يلزم وجود Microsoft Word لاستخدام Aspose.Words.

تستعير الفئات في الحزمة **com.aspose.words** أفضل الممارسات من إطارين معروفين: Microsoft Word Automation وSystem.Xml. يتم تمثيل المستند في Aspose.Words بشجرة من العقد، مشابهًا لـ XML DOM. حيثما أمكن، تتطابق أسماء الفئات، الطرق والخصائص مع تلك الموجودة في Microsoft Word Automation.

الفئات الرئيسية في مساحة الاسم هذه هي:

 *  **Document** is the main class of the object model that represents a Microsoft Word document.
 *  **DocumentBuilder** provides an easy way to insert content and formatting into a document.
 *  **Node** is the base class for all nodes in the document.
 *  **CompositeNode** is the base class for all nodes of the document that can contain other nodes, for example **Paragraph**, **Section** and **Table** and .

تحتوي الحزمة **com.aspose.words** أيضًا على فئات تُشكل محرك التقارير في Aspose.Words. يتيح محرك التقارير ملء المستندات المصممة في Microsoft Word بسرعة وسهولة ببيانات من مصادر بيانات مختلفة مثل **java.sql.ResultSet**، **array of ResultSets**، **com.aspose.words.net.System.Data.DataSet** أو **array of values**.

الكائن **MailMerge** الذي يوفر الوصول إلى وظيفة التقارير متاح عبر الخاصية **Document.MailMerge**.
