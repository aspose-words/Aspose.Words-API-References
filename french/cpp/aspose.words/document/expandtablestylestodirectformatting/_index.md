## Document::ExpandTableStylesToDirectFormatting method


Convertit le formatage spécifié dans les styles de tableau en formatage direct sur les tableaux du document.

```cpp
void Aspose::Words::Document::ExpandTableStylesToDirectFormatting()
```

## Remarques


Cette méthode existe parce que cette version d'Aspose.Words offre uniquement un support limité des styles de tableau (voir ci‑dessous). Cette méthode peut être utile lorsque vous chargez un document DOCX ou WordprocessingML contenant des tableaux formatés avec des styles de tableau et que vous devez interroger le formatage des tableaux, des cellules, des paragraphes ou du texte.

Cette version d'Aspose.Words fournit un support limité des styles de tableau comme suit :

* Table styles defined in DOCX or WordprocessingML documents are preserved as table styles when saving the document as DOCX or WordprocessingML.
* Table styles defined in DOCX or WordprocessingML documents are automatically converted to direct formatting on tables when saving the document into any other format, rendering or printing.
* Table styles defined in DOC documents are preserved as table styles when saving the document as DOC only.
