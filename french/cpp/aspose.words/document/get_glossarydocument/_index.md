## Document::get_GlossaryDocument method


Obtient ou définit le document de glossaire dans ce document ou modèle. Un document de glossaire est un stockage pour les entrées AutoText, AutoCorrect et Building Block définies dans un document.

```cpp
System::SharedPtr<Aspose::Words::BuildingBlocks::GlossaryDocument> Aspose::Words::Document::get_GlossaryDocument() const
```

## Remarques


Cette propriété renvoie **null** si le document ne possède pas de document de glossaire.

Vous pouvez ajouter un document de glossaire à un document en créant un objet [GlossaryDocument](../../../aspose.words.buildingblocks/glossarydocument/) et en l'assignant à cette propriété.
