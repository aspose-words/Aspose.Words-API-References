L'espace de noms **Aspose.Words.Lists** contient des classes pour travailler avec les listes à puces et numérotées définies dans un document.

## Classes

| Classe | Description |
| --- | --- |
| [List](./list/) | Représente le formatage d’une liste. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListCollection](./listcollection/) | Stocke et gère le formatage des listes à puces et numérotées utilisées dans un document. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListFormat](./listformat/) | Permet de contrôler le formatage de liste appliqué à un paragraphe. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLabel](./listlabel/) | Définit les propriétés spécifiques à une étiquette de liste. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevel](./listlevel/) | Définit le formatage d’un niveau de liste. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevelCollection](./listlevelcollection/) | Une collection de formatages de liste pour chaque niveau d’une liste. Pour en savoir plus, consultez l’article de documentation [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
