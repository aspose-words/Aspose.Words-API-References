## MailMerge::DeleteFields method


Supprime les champs liés au publipostage du document.

```cpp
void Aspose::Words::MailMerging::MailMerge::DeleteFields()
```

## Remarques


Cette méthode supprime les champs MERGEFIELD et NEXT du document.

Cette méthode peut être utile si votre opération de fusion de courrier ne doit pas toujours remplir tous les champs du document. Utilisez cette méthode pour supprimer tous les champs de fusion restants.
