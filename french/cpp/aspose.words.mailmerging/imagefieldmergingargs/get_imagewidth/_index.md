## ImageFieldMergingArgs::get_ImageWidth method


Spécifie la largeur de l'image à insérer dans le document.

```cpp
const System::SharedPtr<Aspose::Words::Fields::MergeFieldImageDimension> & Aspose::Words::MailMerging::ImageFieldMergingArgs::get_ImageWidth() const
```

## Remarques


La valeur de cette propriété provient initialement du code du MERGEFIELD correspondant, contenu dans le document modèle. Pour remplacer la valeur initiale, vous devez affecter une instance de la classe [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) à cette propriété ou définir les propriétés de l'instance de la classe [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) renvoyée par cette propriété.

Pour indiquer que la valeur originale de la largeur de l'image doit être appliquée, vous devez affecter la valeur **null** à cette propriété ou définir la propriété [Value](../../../aspose.words.fields/mergefieldimagedimension/get_value/) de l'instance de la classe [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) renvoyée par cette propriété à une valeur négative.
