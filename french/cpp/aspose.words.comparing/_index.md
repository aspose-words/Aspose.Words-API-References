L'espace de noms **Aspose.Words.Comparing** fournit des classes et des énumérations qui permettent de spécifier des options supplémentaires lors de la comparaison de documents.

## Classes

| Classe | Description |
| --- | --- |
| [AdvancedCompareOptions](./advancedcompareoptions/) | Permet de définir des options de comparaison avancées. |
| [CompareOptions](./compareoptions/) | Permet de choisir des options supplémentaires pour l'opération de comparaison de documents. Pour en savoir plus, consultez l'article de documentation [Compare Documents](https://docs.aspose.com/words/cpp/compare-documents/). |
## Enums

| Enum | Description |
| --- | --- |
| [ComparisonTargetType](./comparisontargettype/) | Permet de spécifier le document de base qui sera utilisé pendant la comparaison. La valeur par défaut est [Current](./comparisontargettype/). |
| [Granularity](./granularity/) | Spécifie la granularité des modifications à suivre lors de la comparaison de deux documents. |
