## ChartYValueType enum


Permet de spécifier le type d'une valeur Y d'une série de graphique.

```cpp
enum class ChartYValueType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Double | 0 | Spécifie qu'une valeur Y est un nombre à virgule flottante double précision. |
| DateTime | 1 | Spécifie qu'une valeur Y est une date et une heure de la journée. |
| Temps | 2 | Spécifie qu'une valeur X est une heure de la journée. |
