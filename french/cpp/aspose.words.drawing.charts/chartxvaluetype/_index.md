## ChartXValueType enum


Permet de spécifier le type d'une valeur X d'une série de graphique.

```cpp
enum class ChartXValueType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| String | 0 | Spécifie qu'une valeur X est une catégorie de chaîne. |
| Double | 1 | Spécifie qu'une valeur X est un nombre à virgule flottante double précision. |
| DateTime | 2 | Spécifie qu'une valeur X est une date et une heure de la journée. |
| Temps | 3 | Spécifie qu'une valeur X est une heure de la journée. |
| Multiniveau | 4 | Spécifie qu'une valeur X est une valeur multiniveau. |
