L'espace de noms **Aspose.Words.Bibliography** fournit des classes qui permettent d'accéder à une liste de sources bibliographiques disponibles dans un document.

## Classes

| Classe | Description |
| --- | --- |
| [Bibliography](./bibliography/) | Représente la liste des sources bibliographiques disponibles dans le document. |
| [Contributor](./contributor/) | Représente un contributeur à la source bibliographique. Peut être soit une entité corporate (une organisation) ou une liste de personnes. |
| [ContributorCollection](./contributorcollection/) | Représente les contributeurs à la source bibliographique. |
| [Corporate](./corporate/) | Représente un contributeur corporate (une organisation) à la source bibliographique. |
| [Person](./person/) | Représente un contributeur individuel (une personne) à la source bibliographique. |
| [PersonCollection](./personcollection/) | Représente une liste de personnes qui sont des contributeurs à la source bibliographique. |
| [Source](./source/) | Représente une source individuelle, telle qu'un livre, un article de revue ou une interview. |
