## ColorPrintMode enum


Spécifie comment les pages non colorées sont imprimées si l'appareil prend en charge l'impression couleur.

```cpp
enum class ColorPrintMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | 0 | Toutes les pages sont imprimées selon les capacités et les paramètres de l'imprimante. |
| GrayscaleAuto | 1 | Les pages non colorées, si détectées, sont imprimées en niveaux de gris. |
