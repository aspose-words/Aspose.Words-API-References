Le **Aspose.Words.Rendering** espace de noms fournit des classes qui permettent de personnaliser l’impression ou le rendu des documents.

## Classes

| Classe | Description |
| --- | --- |
| [NodeRendererBase](./noderendererbase/) | Classe de base pour [ShapeRenderer](./shaperenderer/) et [OfficeMathRenderer](./officemathrenderer/). Pour en savoir plus, consultez l'article de documentation [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [OfficeMathRenderer](./officemathrenderer/) | Fournit des méthodes pour rendre un [OfficeMath](../aspose.words.math/officemath/) individuel en image raster ou vectorielle ou dans un objet Graphics. | [PageInfo](./pageinfo/) | Représente les informations concernant une page de document particulière. Pour en savoir plus, consultez l'article de documentation [Rendering](https://docs.aspose.com/words/cpp/rendering/). |
| [ShapeRenderer](./shaperenderer/) | Fournit des méthodes pour rendre un [Shape](../aspose.words.drawing/shape/) ou un [GroupShape](../aspose.words.drawing/groupshape/) individuel en image raster ou vectorielle ou dans un objet Graphics. Pour en savoir plus, consultez l'article de documentation [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [ThumbnailGeneratingOptions](./thumbnailgeneratingoptions/) | Peut être utilisé pour spécifier des options supplémentaires lors de la génération d'une miniature d'un document. |
