## MailMergeMainDocumentType enum


Spécifie les types possibles pour un document source de fusion de courrier.

```cpp
enum class MailMergeMainDocumentType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| NotAMergeDocument | 0 | Ce document n'est pas un document de fusion de courrier. |
| FormLetters | 1 | Spécifie que le document source de fusion de courrier est de type lettre de formulaire. |
| MailingLabels | 2 | Spécifie que le document source de fusion de courrier est de type étiquette postale. |
| Envelopes | 4 | Spécifie que le document source de fusion de courrier est de type enveloppe. |
| Catalog | 8 | Spécifie que le document source de fusion de courrier est de type catalogue. |
| Email | 16 | Spécifie que le document source de fusion de courrier est de type message électronique. |
| Fax | 32 | Spécifie que le document source de fusion de courrier est de type fax. |
| Default | n/a | Égal à [NotAMergeDocument](./) |
