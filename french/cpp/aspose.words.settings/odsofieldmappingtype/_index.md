## OdsoFieldMappingType enum


Spécifie les types possibles utilisés pour indiquer si un champ de fusion de courrier donné a été mappé à une colonne de la source de données externe donnée.

```cpp
enum class OdsoFieldMappingType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Colonne | 0 | Spécifie que le champ de publipostage a été mappé à une colonne dans la source de données externe donnée. |
| Null | 1 | Spécifie que le champ de publipostage n'a pas été mappé à une colonne dans la source de données externe donnée. |
| Default | n/a | Égal à [Null](./). |
