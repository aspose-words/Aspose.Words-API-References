## MergeFormatMode enum


Spécifie comment le formatage est fusionné lors de la combinaison de plusieurs documents.

```cpp
enum class MergeFormatMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| MergeFormatting | 0 | Combine le formatage des documents fusionnés. |
| KeepSourceFormatting | 1 | Cela signifie que le document source conservera son formatage original, tel que les styles de police, les tailles, les couleurs, les retraits, et tout autre élément de formatage appliqué à son contenu. |
| KeepSourceLayout | 2 | Préserve la mise en page des documents originaux dans le document final. |
