## SplitCriteria enum


Spécifie comment le document est découpé en parties.

```cpp
enum class SplitCriteria
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Page | 0 | Spécifie que le document est divisé en pages. |
| SectionBreak | 1 | Spécifie que le document est divisé en parties à un saut de section de tout type. |
| Style | 2 | Spécifie que le document est divisé en parties à un paragraphe formaté en utilisant le style spécifié dans [SplitStyle](../splitoptions/get_splitstyle/). |
