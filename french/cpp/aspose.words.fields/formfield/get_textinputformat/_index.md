## FormField::get_TextInputFormat method


Renvoie ou définit le formatage du texte pour un champ de formulaire texte.

```cpp
System::String Aspose::Words::Fields::FormField::get_TextInputFormat()
```

## Remarques


Si le champ de formulaire texte contient du texte ordinaire, alors les chaînes de format valides sont "", "UPPERCASE", "LOWERCASE", "FIRST CAPITAL" et "TITLE CASE". Les chaînes ne sont pas sensibles à la casse.

Si le champ de formulaire texte contient un nombre ou une valeur date/heure, alors les chaînes de format valides sont les chaînes de format de nombre ou de date et d'heure.

Microsoft Word autorise des chaînes d'au plus 64 caractères.
