## FormField::get_OwnHelp method


Spécifie la source du texte affiché dans une boîte de dialogue lorsque le champ de formulaire a le focus et que l'utilisateur appuie sur F1.

```cpp
bool Aspose::Words::Fields::FormField::get_OwnHelp()
```

## Remarques


Si **true**, le texte spécifié par la propriété [HelpText](../get_helptext/) est affiché. Si **false**, le texte de l'entrée AutoText spécifiée par la propriété [HelpText](../get_helptext/) est affiché.
