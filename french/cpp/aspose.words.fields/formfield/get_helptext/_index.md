## FormField::get_HelpText method


Renvoie ou définit le texte affiché dans une boîte de dialogue lorsque le champ de formulaire a le focus et que l'utilisateur appuie sur F1.

```cpp
System::String Aspose::Words::Fields::FormField::get_HelpText()
```

## Remarques


Si la propriété [OwnHelp](../get_ownhelp/) est définie sur **true**, [HelpText](./) spécifie la valeur de chaîne de texte. Si [OwnHelp](../get_ownhelp/) est définie sur **false**, [HelpText](./) spécifie le nom d'une entrée AutoText qui contient le texte d'aide pour le champ de formulaire.

Microsoft Word autorise des chaînes d'au plus 255 caractères.
