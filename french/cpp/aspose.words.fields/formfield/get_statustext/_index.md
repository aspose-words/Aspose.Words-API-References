## FormField::get_StatusText method


Renvoie ou définit le texte affiché dans la barre d'état lorsque le champ de formulaire a le focus.

```cpp
System::String Aspose::Words::Fields::FormField::get_StatusText()
```

## Remarques


Si la propriété [OwnStatus](../get_ownstatus/) est définie sur **true**, la propriété [StatusText](./) spécifie le texte de la barre d’état. Si la propriété [OwnStatus](../get_ownstatus/) est définie sur **false**, la propriété [StatusText](./) spécifie le nom d’une entrée AutoText qui contient le texte de la barre d’état pour le champ de formulaire.

Microsoft Word autorise des chaînes d’au plus 138 caractères.
