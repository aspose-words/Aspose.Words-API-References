## ResourceSavingArgs::get_KeepResourceStreamOpen method


Spécifie si Aspose.Words doit garder le flux ouvert ou le fermer après l'enregistrement d'une ressource.

```cpp
bool Aspose::Words::Saving::ResourceSavingArgs::get_KeepResourceStreamOpen() const
```

## Remarques


La valeur par défaut est **false** et Aspose.Words fermera le flux que vous avez fourni dans la propriété [ResourceStream](../get_resourcestream/) après y avoir écrit une ressource. Spécifiez **true** pour garder le flux ouvert.
