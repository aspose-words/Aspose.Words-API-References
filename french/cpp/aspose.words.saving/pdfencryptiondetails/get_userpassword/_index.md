## PdfEncryptionDetails::get_UserPassword method


Spécifie le mot de passe utilisateur requis pour ouvrir le document PDF chiffré.

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_UserPassword() const
```

## Remarques


Le mot de passe utilisateur sera requis pour ouvrir un document PDF chiffré en vue. Les permissions spécifiées dans [Permissions](../get_permissions/) seront appliquées par le logiciel de lecture.

Le mot de passe utilisateur peut être **null** ou une chaîne vide, dans ce cas aucun mot de passe ne sera demandé à l'utilisateur lors de l'ouverture du document PDF. Le mot de passe utilisateur ne peut pas être identique au mot de passe propriétaire.
