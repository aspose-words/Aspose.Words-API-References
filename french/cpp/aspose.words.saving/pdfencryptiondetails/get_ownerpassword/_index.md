## PdfEncryptionDetails::get_OwnerPassword method


Spécifie le mot de passe propriétaire du document PDF chiffré.

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_OwnerPassword() const
```

## Remarques


Le mot de passe propriétaire permet à l'utilisateur d'ouvrir un document PDF chiffré sans aucune restriction d'accès spécifiée dans [Permissions](../get_permissions/).

Le mot de passe propriétaire ne peut pas être identique au mot de passe utilisateur.
