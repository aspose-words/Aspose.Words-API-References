## PdfCompliance enum


Spécifie le niveau de conformité aux normes PDF.

```cpp
enum class PdfCompliance
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Pdf17 | 0 | Le fichier de sortie sera conforme à la norme PDF 1.7 (ISO 32000-1). |
| Pdf20 | 1 | Le fichier de sortie sera conforme à la norme PDF 2.0 (ISO 32000-2). |
| PdfA1a | 2 | Le fichier de sortie sera conforme à la norme PDF/A-1a (ISO 19005-1). Ce niveau inclut toutes les exigences du PDF/A-1b et exige en outre que la structure du document soit incluse (également connue sous le nom de "tagged"), dans le but de garantir que le contenu du document puisse être recherché et réutilisé. |
| PdfA1b | 3 | Le fichier de sortie sera conforme à la norme PDF/A-1b (ISO 19005-1). PDF/A-1b a pour objectif d'assurer une reproduction fiable de l'apparence visuelle du document. |
| PdfA2a | 4 | Le fichier de sortie sera conforme à la norme PDF/A-2a (ISO 19005-2). Ce niveau inclut toutes les exigences du PDF/A-2u et exige en outre que la structure du document soit incluse (également connue sous le nom de « balisé »), dans le but de garantir que le contenu du document puisse être recherché et réutilisé. |
| PdfA2u | 5 | Le fichier de sortie sera conforme à la norme PDF/A-2u (ISO 19005-2). PDF/A-2u a pour objectif de préserver l'apparence visuelle statique du document dans le temps, indépendamment des outils et systèmes utilisés pour créer, stocker ou rendre les fichiers. De plus, tout texte contenu dans le document peut être extrait de manière fiable sous forme d'une série de points de code Unicode. |
| PdfA3a | 6 | Le fichier de sortie sera conforme à la norme PDF/A-3a (ISO 19005-3). Ce niveau inclut toutes les exigences du PDF/A-3u et exige en outre que la structure du document soit incluse (également connue sous le nom de « balisé »), dans le but de garantir que le contenu du document puisse être recherché et réutilisé. |
| PdfA3u | 7 | Le fichier de sortie sera conforme à la norme PDF/A-3u (ISO 19005-3). PDF/A-3u (tout comme PDF/A-2u) a pour objectif de préserver l'apparence visuelle statique du document dans le temps, indépendamment des outils et systèmes utilisés pour créer, stocker ou rendre les fichiers. De plus, tout texte contenu dans le document peut être extrait de manière fiable sous forme d'une série de points de code Unicode. En plus du PDF/A-2u, le PDF/A-3u permet d'intégrer des pièces jointes au document PDF. |
| PdfA4 | 8 | Le fichier de sortie sera conforme à la norme PDF/A-4 (ISO 19005-4:2020). PDF/A-4 a pour objectif de préserver l'apparence visuelle statique du document dans le temps, indépendamment des outils et systèmes utilisés pour créer, stocker ou rendre les fichiers. De plus, tout texte contenu dans le document peut être extrait de manière fiable sous forme d'une série de points de code Unicode. |
| PdfA4f | 9 | Le fichier de sortie sera conforme à la norme PDF/A-4f (ISO 19005-4:2020). Ce niveau inclut toutes les exigences du PDF/A-4 et permet en outre d'intégrer des pièces jointes au document PDF. |
| PdfA4Ua2 | 10 | Le fichier de sortie sera conforme aux normes PDF/A-4 (ISO 19005-4:2020) et PDF/UA-2 (ISO 14289-2:2024). PDF/A-4 a pour objectif de préserver l'apparence visuelle statique du document dans le temps, indépendamment des outils et systèmes utilisés pour créer, stocker ou rendre les fichiers. Le but principal du PDF/UA est de définir comment représenter les documents électroniques au format PDF de manière à rendre le fichier accessible. |
| PdfUa1 | 11 | Le fichier de sortie sera conforme à la norme PDF/UA-1 (ISO 14289-1). Le but principal du PDF/UA est de définir comment représenter les documents électroniques au format PDF de manière à rendre le fichier accessible. |
| PdfUa2 | 12 | Le fichier de sortie sera conforme à la norme PDF/UA-2 (ISO 14289-2:2024). Le but principal du PDF/UA est de définir comment représenter les documents électroniques au format PDF de manière à rendre le fichier accessible. |
