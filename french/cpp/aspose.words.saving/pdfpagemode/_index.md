## PdfPageMode enum


Spécifie comment le document PDF doit être affiché lorsqu’il est ouvert dans le lecteur PDF.

```cpp
enum class PdfPageMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| UseNone | 0 | Ni le plan du document ni les images miniatures ne sont visibles. |
| UseOutlines | 1 | [Document](../../aspose.words/document/) le plan est visible. Notez que s'il n'y a aucun plan dans le document PDF, le volet de navigation du plan ne sera de toute façon pas visible. |
| UseThumbs | 2 | Les images miniatures sont visibles. |
| FullScreen | 3 | Mode plein écran, sans barre de menu, contrôles de fenêtre, ni aucune autre fenêtre visible. |
| UseOC | 4 | Le panneau du groupe de contenu optionnel est visible. |
| UseAttachments | 5 | Le panneau des pièces jointes est visible. |
