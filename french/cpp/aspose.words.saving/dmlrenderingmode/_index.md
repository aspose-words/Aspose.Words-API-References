## DmlRenderingMode enum


Spécifie comment les formes DrawingML sont rendues dans les formats de page fixe.

```cpp
enum class DmlRenderingMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Fallback | 0 | Si une forme de secours est disponible pour DrawingML, Aspose.Words rend la forme de secours à la place du DrawingML. |
| DrawingML | 1 | Aspose.Words ignore la forme de secours de DrawingML et rend le DrawingML lui‑même. C’est le mode par défaut. |
