## HtmlFixedSaveOptions::get_ResourcesFolderAlias method


Spécifie le nom du dossier utilisé pour construire les URI d'images écrites dans un document Html. La valeur par défaut est **null**.

```cpp
System::String Aspose::Words::Saving::HtmlFixedSaveOptions::get_ResourcesFolderAlias() const
```

## Remarques


Lorsque vous enregistrez un [Document](../../../aspose.words/document/) au format Html, Aspose.Words doit enregistrer toutes les images incorporées dans le document en tant que fichiers autonomes. [ResourcesFolder](../get_resourcesfolder/) vous permet de spécifier où les images seront enregistrées et [ResourcesFolderAlias](./) permet de spécifier comment les URI d'images seront construits.
