## ImageSaveOptions::get_GraphicsQualityOptions method


Permet de spécifier le mode de rendu et la qualité pour l'objet **Graphics**.

```cpp
System::SharedPtr<Aspose::Words::Saving::GraphicsQualityOptions> Aspose::Words::Saving::ImageSaveOptions::get_GraphicsQualityOptions() const
```

## Remarques


Utilisez cette propriété pour remplacer les paramètres Graphics fournis par le moteur Aspose.Words par défaut.

Cela prendra effet uniquement lorsqu'un document est enregistré dans un format similaire à une image.
