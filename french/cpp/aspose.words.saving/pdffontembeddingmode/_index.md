## PdfFontEmbeddingMode enum


Spécifie comment Aspose.Words doit incorporer les polices.

```cpp
enum class PdfFontEmbeddingMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| EmbedAll | 0 | Aspose.Words intègre toutes les polices. |
| EmbedNonstandard | 1 | Aspose.Words intègre toutes les polices à l'exception des polices Windows standard Arial et Times New Roman. Seules les polices Arial et Times New Roman sont concernées dans ce mode parce que MS Word n'intègre pas uniquement ces polices lors de l'enregistrement du document au format PDF. |
| EmbedNone | 2 | Aspose.Words n'intègre aucune police. |
