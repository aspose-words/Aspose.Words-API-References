## CssStyleSheetType enum


Spécifie comment les styles CSS (Cascading [Style](../../aspose.words/style/) Sheet) sont exportés vers HTML.

```cpp
enum class CssStyleSheetType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Inline | 0 | Les styles CSS sont écrits en ligne (comme valeur de l'attribut **style** sur chaque élément). |
| Intégré | 1 | Les styles CSS sont écrits séparément du contenu dans une feuille de style intégrée au fichier HTML. |
| Externe | 2 | Les styles CSS sont écrits séparément du contenu dans une feuille de style située dans un fichier externe. Le fichier HTML lie la feuille de style. |
