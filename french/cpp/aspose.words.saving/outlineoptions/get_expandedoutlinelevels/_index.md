## OutlineOptions::get_ExpandedOutlineLevels method


Spécifie le nombre de niveaux du plan du document à afficher développés lorsque le fichier est visualisé.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_ExpandedOutlineLevels() const
```

## Remarques


Notez que cette option ne fonctionnera pas lors de l'enregistrement au format XPS.

Spécifiez 0 et le plan du document sera réduit ; spécifiez 1 et les éléments du premier niveau du plan seront développés, etc.

La valeur par défaut est 0. La plage valide est de 0 à 9.
