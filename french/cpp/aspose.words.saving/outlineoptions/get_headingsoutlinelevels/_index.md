## OutlineOptions::get_HeadingsOutlineLevels method


Spécifie le nombre de niveaux de titres (paragraphes formatés avec les styles Titre) à inclure dans le plan du document.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_HeadingsOutlineLevels() const
```

## Remarques


Spécifiez 0 pour aucun titre dans le plan ; spécifiez 1 pour un niveau de titre dans le plan, etc.

La valeur par défaut est 0. La plage valide est de 0 à 9.
