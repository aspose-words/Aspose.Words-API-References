## PdfSaveOptions::get_DisplayDocTitle method


Un indicateur spécifiant si la barre de titre de la fenêtre doit afficher le titre du document provenant de l'entrée Title du dictionnaire d'informations du document.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_DisplayDocTitle() const
```

## Remarques


Si **false**, la barre de titre doit plutôt afficher le nom du fichier PDF contenant le document.

Cet indicateur est requis pour la conformité PDF/UA. La valeur **true** sera utilisée automatiquement lors de l'enregistrement au format PDF/UA.

La valeur par défaut est **false**.
