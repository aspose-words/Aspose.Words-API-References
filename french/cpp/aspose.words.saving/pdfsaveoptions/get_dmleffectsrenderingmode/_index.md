## PdfSaveOptions::get_DmlEffectsRenderingMode method


Obtient ou définit une valeur déterminant comment les effets DrawingML sont rendus.

```cpp
Aspose::Words::Saving::DmlEffectsRenderingMode Aspose::Words::Saving::PdfSaveOptions::get_DmlEffectsRenderingMode() override
```

## Remarques


La valeur par défaut est [Simplified](../../dmleffectsrenderingmode/).

Cette propriété est utilisée lorsque le document est exporté vers des formats de page fixe.

Si [Compliance](../get_compliance/) est définie sur [PdfA1a](../../pdfcompliance/) ou [PdfA1b](../../pdfcompliance/), la propriété renvoie toujours [None](../../dmleffectsrenderingmode/).
