## PdfSaveOptions::get_AttachmentsEmbeddingMode method


Obtient ou définit une valeur déterminant comment les pièces jointes sont incorporées au document PDF.

```cpp
Aspose::Words::Saving::PdfAttachmentsEmbeddingMode Aspose::Words::Saving::PdfSaveOptions::get_AttachmentsEmbeddingMode() const
```

## Remarques


La valeur par défaut est [None](../../pdfattachmentsembeddingmode/) et les pièces jointes ne sont pas incorporées.

Les normes PDF/A‑1, PDF/A‑2 et PDF/A‑4 (pas PDF/A‑4f) n'autorisent pas les fichiers incorporés. La valeur [None](../../pdfattachmentsembeddingmode/) sera utilisée automatiquement.
