## PdfSaveOptions::get_AdditionalTextPositioning method


Un indicateur spécifiant s'il faut écrire des opérateurs de positionnement de texte supplémentaires ou non.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_AdditionalTextPositioning() const
```

## Remarques


Si **true**, des opérateurs de positionnement de texte supplémentaires sont écrits dans le PDF de sortie. Cela peut aider à surmonter les problèmes de positionnement de texte inexact avec certaines imprimantes. L'inconvénient est l'augmentation de la taille du document PDF.

La valeur par défaut est **false**.
