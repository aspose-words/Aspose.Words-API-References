## PageSavingArgs::get_KeepPageStreamOpen method


Spécifie si Aspose.Words doit garder le flux ouvert ou le fermer après l'enregistrement d'une page de document.

```cpp
bool Aspose::Words::Saving::PageSavingArgs::get_KeepPageStreamOpen() const
```

## Remarques


La valeur par défaut est **false** et Aspose.Words fermera le flux que vous avez fourni dans la propriété [PageStream](../get_pagestream/) après y avoir écrit une page de document. Spécifiez **true** pour garder le flux ouvert.
