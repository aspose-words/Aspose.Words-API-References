## ImageSavingArgs::get_KeepImageStreamOpen method


Spécifie si Aspose.Words doit garder le flux ouvert ou le fermer après l'enregistrement d'une image.

```cpp
bool Aspose::Words::Saving::ImageSavingArgs::get_KeepImageStreamOpen() const
```

## Remarques


Par défaut, c'est **false** et Aspose.Words fermera le flux que vous avez fourni dans la propriété [ImageStream](../get_imagestream/) après y avoir écrit une image. Spécifiez **true** pour garder le flux ouvert.
