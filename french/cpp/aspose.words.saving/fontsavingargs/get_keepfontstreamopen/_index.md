## FontSavingArgs::get_KeepFontStreamOpen method


Spécifie si Aspose.Words doit garder le flux ouvert ou le fermer après avoir enregistré une police.

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## Remarques


La valeur par défaut est **false** et Aspose.Words fermera le flux que vous avez fourni dans la propriété [FontStream](../get_fontstream/) après y avoir écrit une police. Spécifiez **true** pour garder le flux ouvert.
