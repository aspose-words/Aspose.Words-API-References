## MetafileRenderingOptions::get_RenderingMode method


Obtient ou définit une valeur déterminant comment les images de métafichier doivent être rendues.

```cpp
Aspose::Words::Saving::MetafileRenderingMode Aspose::Words::Saving::MetafileRenderingOptions::get_RenderingMode() const
```

## Remarques


La valeur par défaut dépend du format de sauvegarde. Pour les images, il s'agit de [Bitmap](../../metafilerenderingmode/). Pour les autres formats, il s'agit de [VectorWithFallback](../../metafilerenderingmode/).
