## NumeralFormat enum


Indique le jeu de symboles utilisé pour représenter les nombres lors du rendu vers les formats de page fixe.

```cpp
enum class NumeralFormat
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Européen | 0 | Chiffres européens : 0123456789. |
| ArabicIndic | 1 | Chiffres utilisés en arabe : ٠١٢٣٤٥٦٧٨٩. Plage Unicode U+0660 - u+0669. |
| EasternArabicIndic | 2 | Chiffres utilisés en persan et en ourdou : ۰۱۲۳۴۵۶۷۸۹. Plage Unicode U+06F0 - u+06F9. |
| Contexte | 3 | L'ensemble de symboles est déterminé à partir du contexte (locale et propriété RTL). |
| Système | 4 | CETTE OPTION N'EST PAS PRISE EN CHARGE. L'ensemble de symboles est déterminé à partir des paramètres régionaux. |
