## PdfAttachmentsEmbeddingMode enum


Spécifie comment les pièces jointes sont incorporées dans le document PDF.

```cpp
enum class PdfAttachmentsEmbeddingMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | 0 | Les pièces jointes ne sont pas intégrées. |
| Annotations | 1 | Les pièces jointes sont intégrées en tant qu'annotations avec une localisation sur la page. |
| DocumentEmbeddedFiles | 2 | Les pièces jointes sont intégrées en tant que fichiers intégrés au document sans annotations. |
