## SvgSaveOptions::get_ResourcesFolderAlias method


Spécifie le nom du dossier utilisé pour construire les URI d'images écrites dans un document SVG. La valeur par défaut est **null**.

```cpp
System::String Aspose::Words::Saving::SvgSaveOptions::get_ResourcesFolderAlias() const
```

## Remarques


Lorsque vous enregistrez un [Document](../../../aspose.words/document/) au format SVG, Aspose.Words doit enregistrer toutes les images intégrées dans le document en fichiers autonomes. [ResourcesFolder](../get_resourcesfolder/) vous permet de spécifier où les images seront enregistrées et [ResourcesFolderAlias](./) permet de spécifier comment les URI des images seront construites.
