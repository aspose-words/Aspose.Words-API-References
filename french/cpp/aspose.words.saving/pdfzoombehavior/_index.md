## PdfZoomBehavior enum


Spécifie le type de zoom appliqué à un document PDF lorsqu'il est ouvert dans un visualiseur PDF.

```cpp
enum class PdfZoomBehavior
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | 0 | La façon dont le document est affiché dépend du visualiseur PDF. Habituellement, le visualiseur affiche le document pour ajuster la largeur de la page. |
| ZoomFactor | 1 | Affiche la page en utilisant le facteur de zoom spécifié. |
| FitPage | 2 | Affiche la page afin qu'elle soit entièrement visible. |
| FitWidth | 3 | Ajuste la largeur de la page. |
| FitHeight | 4 | Ajuste la hauteur de la page. |
| FitBox | 5 | Ajuste la boîte englobante (rectangle contenant tous les éléments visibles sur la page). |
