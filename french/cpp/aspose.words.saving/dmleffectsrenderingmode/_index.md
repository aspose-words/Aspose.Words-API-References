## DmlEffectsRenderingMode enum


Spécifie comment les effets DrawingML sont rendus dans les formats de page fixe.

```cpp
enum class DmlEffectsRenderingMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Simplified | 0 | Le [Rendering](../../aspose.words.rendering/) des effets DrawingML est simplifié. |
| None | 1 | Aucun effet DrawingML n'est rendu. |
| Fine | 2 | Les effets DrawingML sont rendus en mode fin qui implique un traitement avancé. Dans ce mode, le rendu des effets donne de meilleurs résultats mais à un coût de performance plus élevé que le mode [Simplified](./). |
