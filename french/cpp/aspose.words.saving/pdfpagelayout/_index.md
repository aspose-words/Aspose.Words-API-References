## PdfPageLayout enum


Spécifie la mise en page à utiliser lorsque le document est ouvert dans un lecteur PDF.

```cpp
enum class PdfPageLayout
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| SinglePage | 0 | Affiche une page à la fois. |
| OneColumn | 1 | Affiche les pages en une seule colonne. |
| TwoColumnLeft | 2 | Affiche les pages en deux colonnes, les pages impaires étant à gauche. |
| TwoColumnRight | 3 | Affiche les pages en deux colonnes, les pages impaires étant à droite. |
| TwoPageLeft | 4 | Affiche les pages deux à la fois, les pages impaires étant à gauche. |
| TwoPageRight | 5 | Affiche les pages deux à la fois, les pages impaires étant à droite. |
