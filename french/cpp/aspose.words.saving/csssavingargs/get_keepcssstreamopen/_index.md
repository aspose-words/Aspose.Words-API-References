## CssSavingArgs::get_KeepCssStreamOpen method


Spécifie si Aspose.Words doit garder le flux ouvert ou le fermer après l'enregistrement des informations CSS.

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## Remarques


La valeur par défaut est **false** et Aspose.Words fermera le flux que vous avez fourni dans la propriété [CssStream](../get_cssstream/) après y avoir écrit des informations CSS. Spécifiez **true** pour garder le flux ouvert.
