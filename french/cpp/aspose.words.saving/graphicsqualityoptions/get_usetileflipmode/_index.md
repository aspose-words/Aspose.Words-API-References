## GraphicsQualityOptions::get_UseTileFlipMode method


Obtient ou définit un indicateur indiquant si WrapMode est TileFlipXY.

```cpp
bool Aspose::Words::Saving::GraphicsQualityOptions::get_UseTileFlipMode() const
```

## Remarques


Le **WrapMode** spécifie comment une texture ou un dégradé est répété lorsqu'il est plus petit que la zone à remplir.

Par défaut, utilise **Tile** (spécifie un carrelage sans retournement). Cela entraîne un rendu inexact de l'image mise à l'échelle (avec haute résolution).

Cette propriété permet de passer WrapMode à **TileFlipXY** (spécifie que les carreaux sont retournés horizontalement lorsque vous vous déplacez le long d'une ligne et verticalement lorsque vous vous déplacez le long d'une colonne).
