L'espace de noms **Aspose.Words.BuildingBlocks** fournit des classes qui permettent d'accéder et d'utiliser l'AutoTexte, les entrées d'AutoCorrection et les blocs de construction dans un document.

## Classes

| Classe | Description |
| --- | --- |
| [BuildingBlock](./buildingblock/) | Représente une entrée de document de glossaire telle qu'un Building Block, AutoText ou une entrée AutoCorrect. Pour en savoir plus, consultez l'article de documentation [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [BuildingBlockCollection](./buildingblockcollection/) | Une collection d'objets [BuildingBlock](./buildingblock/) dans le document. Pour en savoir plus, consultez l'article de documentation [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [GlossaryDocument](./glossarydocument/) | Représente l'élément racine d'un document de glossaire au sein d'un document Word. Un document de glossaire est un stockage pour AutoText, les entrées AutoCorrect et les Building Blocks. Pour en savoir plus, consultez l'article de documentation [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
## Enums

| Enum | Description |
| --- | --- |
| [BuildingBlockBehavior](./buildingblockbehavior/) | Spécifie le comportement qui doit être appliqué au contenu du building block lorsqu'il est inséré dans le document principal. |
| [BuildingBlockGallery](./buildingblockgallery/) | Spécifie la galerie prédéfinie dans laquelle un building block est classé. |
| [BuildingBlockType](./buildingblocktype/) | Spécifie un type de building block. Le type peut affecter la visibilité et le comportement du building block dans Microsoft Word. |
