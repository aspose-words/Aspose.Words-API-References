## BuildingBlockBehavior enum


Spécifie le comportement qui doit être appliqué au contenu du building block lorsqu'il est inséré dans le document principal.

```cpp
enum class BuildingBlockBehavior
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Contenu | 0 | Spécifie que le bloc de construction doit être inséré comme contenu en ligne. |
| Paragraph | 1 | Spécifie que le bloc de construction doit être inséré dans son propre paragraphe. |
| Page | 2 | Spécifie que le bloc de construction doit être ajouté dans sa propre page. |
| Default | n/a | Identique à [Content](./). |

## Remarques


Correspond au type **ST_DocPartBehavior** dans OOXML.
