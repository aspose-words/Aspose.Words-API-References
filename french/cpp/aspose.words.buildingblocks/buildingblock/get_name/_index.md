## BuildingBlock::get_Name method


Obtient ou définit le nom de ce bloc de construction.

```cpp
System::String Aspose::Words::BuildingBlocks::BuildingBlock::get_Name() const
```

## Remarques


Le nom peut contenir n'importe quel texte, généralement un identifiant convivial. Plusieurs blocs de construction peuvent avoir le même nom.

Ne peut pas être **null** et ne peut pas être une chaîne vide.

Correspond à l'élément **docPartPr.name** dans OOXML.
