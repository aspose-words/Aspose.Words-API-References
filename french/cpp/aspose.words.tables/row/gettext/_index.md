```cpp
System::String Aspose::Words::Tables::Row::GetText() override
```

## Remarques


Renvoie le texte concaténé de tous les nœuds enfants avec le caractère de fin de ligne [Cell](../../../aspose.words/controlchar/cell/) ajouté à la fin.

La chaîne renvoyée comprend tous les caractères de contrôle et spéciaux tels que décrits dans [ControlChar](../../../aspose.words/controlchar/).
