## Table::get_Description method


Obtient ou définit la description de ce tableau. Elle fournit une représentation textuelle alternative des informations contenues dans le tableau.

```cpp
System::String Aspose::Words::Tables::Table::get_Description()
```

## Remarques


La valeur par défaut est une chaîne vide.

Cette propriété est pertinente pour les documents DOCX conformes à ISO/IEC 29500 ([OoxmlCompliance](../../../aspose.words.saving/ooxmlcompliance/)). Lorsqu'ils sont enregistrés dans des formats antérieurs à ISO/IEC 29500, la propriété est ignorée.
