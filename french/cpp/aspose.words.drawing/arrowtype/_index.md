## ArrowType enum


Spécifie le type de flèche à l'extrémité d'une ligne.

```cpp
enum class ArrowType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | 0 | La ligne n'a pas de flèche à l'extrémité. |
| Flèche | 1 | La flèche est un triangle plein. |
| Stealth | 2 | La flèche est une flèche "stealth". |
| Diamond | 3 | L'extrémité de la ligne est un losange plein. |
| Oval | 4 | L'extrémité de la ligne est un ovale plein. |
| Open | 5 | La flèche est une flèche ouverte. |
| Default | n/a | Identique à [None](./). |
