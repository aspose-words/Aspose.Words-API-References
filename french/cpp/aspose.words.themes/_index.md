Le **Aspose.Words.Themes** espace de noms fournit des classes qui permettent d’accéder aux informations de thème dans les documents Microsoft Word.

## Classes

| Classe | Description |
| --- | --- |
| [Theme](./theme/) | Représente le document [Theme](./theme/), et fournit l'accès aux principales parties du thème, y compris [MajorFonts](./theme/get_majorfonts/), [MinorFonts](./theme/get_minorfonts/) et [Colors](./theme/get_colors/). Pour en savoir plus, consultez l'article de documentation [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeColors](./themecolors/) | Représente le schéma de couleurs du thème du document qui contient douze couleurs. L'objet [ThemeColors](./themecolors/) contient six couleurs d'accent, deux couleurs sombres, deux couleurs claires et une couleur pour chaque hyperlien et hyperlien visité. |
| [ThemeFonts](./themefonts/) | Représente une collection de polices dans le schéma de polices, permettant de spécifier différentes polices pour différentes langues [Latin](./themefonts/get_latin/), [EastAsian](./themefonts/get_eastasian/) et [ComplexScript](./themefonts/get_complexscript/). Pour en savoir plus, consultez l'article de documentation [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
## Enums

| Enum | Description |
| --- | --- |
| [ThemeColor](./themecolor/) | Spécifie les couleurs du thème pour les thèmes de documents. Pour en savoir plus, consultez l'article de documentation [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeFont](./themefont/) | Spécifie les types de noms de polices du thème pour les thèmes de documents. |
