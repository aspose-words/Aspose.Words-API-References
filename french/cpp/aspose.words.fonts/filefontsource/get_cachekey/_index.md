## FileFontSource::get_CacheKey method


La clé de cette source dans le cache.

```cpp
System::String Aspose::Words::Fonts::FileFontSource::get_CacheKey() const
```

## Remarques


Cette clé est utilisée pour identifier l'élément du cache lors de l'enregistrement/chargement du cache de recherche de polices avec les méthodes [SaveSearchCache()](../) et [SetFontsSources()](../).

Si la clé n'est pas spécifiée, alors [FilePath](../get_filepath/) sera utilisée comme clé à la place.
