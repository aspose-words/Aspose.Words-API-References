## LoadOptions::get_UseSystemLcid method


Obtient ou définit s'il faut utiliser la valeur LCID obtenue du registre Windows pour déterminer les marges par défaut de la mise en page.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Remarques


Si défini sur **true**, le comportement de MS Word est émulé, ce qui prend la valeur LCID du registre Windows.

La valeur par défaut est **false**.
