L'espace de noms **Aspose.Words.Notes** fournit des classes pour travailler avec les notes de fin et les notes de bas de page de Microsoft Word.

## Classes

| Classe | Description |
| --- | --- |
| [EndnoteOptions](./endnoteoptions/) | Représente les options de numérotation des notes de fin pour un document ou une section. Pour en savoir plus, consultez l'article de documentation [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [Footnote](./footnote/) | Représente un conteneur pour le texte d'une note de bas de page ou d'une note de fin. Pour en savoir plus, consultez l'article de documentation [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteOptions](./footnoteoptions/) | Représente les options de numérotation des notes de bas de page pour un document ou une section. Pour en savoir plus, consultez l'article de documentation [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteSeparator](./footnoteseparator/) | Représente un conteneur pour le séparateur de note de bas de page/note de fin et le contenu de continuation d'un document. |
| [FootnoteSeparatorCollection](./footnoteseparatorcollection/) | Fournit un accès typé aux nœuds [FootnoteSeparator](./footnoteseparator/) d'un document. |
