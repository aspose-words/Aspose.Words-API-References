该 **Aspose.Words.BuildingBlocks** 命名空间提供允许在文档中访问和使用自动文本、自动更正条目以及构建块的类。

## 类

| 类 | 描述 |
| --- | --- |
| [BuildingBlock](./buildingblock/) | 表示词汇表文档条目，例如构建块、自动文本或自动更正条目。要了解更多信息，请访问 [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/) 文档文章。 |
| [BuildingBlockCollection](./buildingblockcollection/) | 文档中 [BuildingBlock](./buildingblock/) 对象的集合。要了解更多信息，请访问 [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/) 文档文章。 |
| [GlossaryDocument](./glossarydocument/) | 表示 Word 文档中词汇表文档的根元素。词汇表文档是用于存储自动文本、自动更正条目和构建块的存储。要了解更多信息，请访问 [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/) 文档文章。 |
## Enums

| 枚举 | 描述 |
| --- | --- |
| [BuildingBlockBehavior](./buildingblockbehavior/) | 指定在将构建块插入主文档时应应用于其内容的行为。 |
| [BuildingBlockGallery](./buildingblockgallery/) | 指定构建块所属的预定义库。 |
| [BuildingBlockType](./buildingblocktype/) | 指定构建块的类型。该类型可能影响构建块在 Microsoft Word 中的可见性和行为。 |
