## BuildingBlockBehavior enum


指定在将构建块插入主文档时应应用于其内容的行为。

```cpp
enum class BuildingBlockBehavior
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Content | 0 | 指定应将构建块作为内联内容插入。 |
| 段落 | 1 | 指定应将构建块插入其自己的段落中。 |
| Page | 2 | 指定应将构建块添加到其自己的页面中。 |
| Default | n/a | 与 [Content](./) 相同。 |

## 备注


对应于 OOXML 中的 **ST_DocPartBehavior** 类型。
