## BuildingBlockType enum


指定构建块的类型。该类型可能影响构建块在 Microsoft Word 中的可见性和行为。

```cpp
enum class BuildingBlockType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | 0 | 未为构建块指定类型信息。 |
| AutomaticallyReplaceNameWithContent | 1 | 允许在应用程序中输入其名称时，自动将构建块插入文档。 |
| StructuredDocumentTagPlaceholderText | 2 | 该构建块是结构化文档标签占位符文本。 |
| FormFieldHelpText | 3 | 该构建块是表单字段帮助文本。 |
| 普通 | 4 | 该构建块是普通（即常规）词汇表文档条目。 |
| AutoCorrect | 5 | 该构建块与拼写和语法工具关联。 |
| AutoText | 6 | 该构建块是 AutoText 条目。 |
| 全部 | 7 | 该构建块与所有类型关联。 |
| Default | n/a | 另存为 [None](./)。 |

## 备注


对应于 OOXML 中的 **ST_DocPartType** 类型。
