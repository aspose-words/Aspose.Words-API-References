该 **Aspose.Words.Bibliography** 命名空间提供允许访问文档中可用的参考文献来源列表的类。

## 类

| 类 | 描述 |
| --- | --- |
| [Bibliography](./bibliography/) | 表示文档中可用的参考文献来源列表。 |
| [Contributor](./contributor/) | 表示参考文献来源的贡献者。可以是企业（组织）或人员列表。 |
| [ContributorCollection](./contributorcollection/) | 表示参考文献来源的贡献者。 |
| [Corporate](./corporate/) | 表示企业（组织）参考文献来源的贡献者。 |
| [Person](./person/) | 表示个人（人员）参考文献来源的贡献者。 |
| [PersonCollection](./personcollection/) | 表示作为参考文献来源贡献者的人员列表。 |
| [Source](./source/) | 表示单个来源，例如图书、期刊文章或访谈。 |
