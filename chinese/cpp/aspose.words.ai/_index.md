该 **Aspose.Words.AI** 命名空间实现与大型语言模型（LLM），如 OpenAI 和 Gemini 的无缝集成，提供对 AI 驱动的文档处理的强大支持。

## 类

| 类 | 描述 |
| --- | --- |
| [AiModel](./aimodel/) | 一个抽象类，表示与 [Aspose.Words](../aspose.words/) 中各种 [AI](./) 模型的集成。 |
| [AnthropicAiModel](./anthropicaimodel/) | 一个抽象类，表示与 [Aspose.Words](../aspose.words/) 中 Anthropic 的 [AI](./) 模型的集成。 |
| [CheckGrammarOptions](./checkgrammaroptions/) | 允许在使用 [AI](./) 检查文档语法时指定各种选项。 |
| [GoogleAiModel](./googleaimodel/) | 表示 Google [AI](./) 模型（Gemini）在 [Aspose.Words](../aspose.words/) 中的集成的类。 |
| [OpenAiModel](./openaimodel/) | 表示 OpenAi 模型在 [Aspose.Words](../aspose.words/) 中集成的类。 |
| [SummarizeOptions](./summarizeoptions/) | 允许指定用于摘要文档内容的各种选项。 |
