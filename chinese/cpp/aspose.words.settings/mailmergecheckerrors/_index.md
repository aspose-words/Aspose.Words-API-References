## MailMergeCheckErrors enum


指定 Microsoft Word 在邮件合并期间如何报告检测到的错误。

```cpp
enum class MailMergeCheckErrors
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Simulate | 1 | 模拟合并并在新文档中报告错误。 |
| PauseOnError | 2 | 完成合并并暂停以报告错误。 |
| CollectErrors | 3 | 完成合并并在新文档中报告错误。 |
| Default | n/a | 等于 [PauseOnError](./) 值。 |
