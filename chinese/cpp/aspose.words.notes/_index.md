该 **Aspose.Words.Notes** 命名空间提供用于处理 Microsoft Word 尾注和脚注的类。

## 类

| 类 | 描述 |
| --- | --- |
| [EndnoteOptions](./endnoteoptions/) | 表示文档或节的尾注编号选项。欲了解更多，请访问 [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/) 文档文章。 |
| [Footnote](./footnote/) | 表示脚注或尾注文本的容器。欲了解更多，请访问 [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/) 文档文章。 |
| [FootnoteOptions](./footnoteoptions/) | 表示文档或节的脚注编号选项。欲了解更多，请访问 [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/) 文档文章。 |
| [FootnoteSeparator](./footnoteseparator/) | 表示文档中脚注/尾注分隔符和续接内容的容器。 |
| [FootnoteSeparatorCollection](./footnoteseparatorcollection/) | 提供对文档中 [FootnoteSeparator](./footnoteseparator/) 节点的类型化访问。 |
