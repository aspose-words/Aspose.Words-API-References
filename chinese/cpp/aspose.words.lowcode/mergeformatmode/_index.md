## MergeFormatMode enum


指定在合并多个文档时格式的合并方式。

```cpp
enum class MergeFormatMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| MergeFormatting | 0 | 合并已合并文档的格式。 |
| KeepSourceFormatting | 1 | 这意味着源文档将保留其原始格式，例如字体样式、大小、颜色、缩进以及应用于其内容的任何其他格式元素。 |
| KeepSourceLayout | 2 | 在最终文档中保留原始文档的布局。 |
