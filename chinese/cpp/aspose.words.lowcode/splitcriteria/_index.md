## SplitCriteria enum


指定文档如何拆分为多个部分。

```cpp
enum class SplitCriteria
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Page | 0 | 指定文档按页面拆分。 |
| SectionBreak | 1 | 指定文档在任意类型的节分隔处拆分为多个部分。 |
| Style | 2 | 指定文档在使用 [SplitStyle](../splitoptions/get_splitstyle/) 指定的样式格式化的段落处拆分为多个部分。 |
