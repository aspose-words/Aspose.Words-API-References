## Document::get_GlossaryDocument method


获取或设置此文档或模板中的词汇文档。词汇文档是用于存储在文档中定义的 AutoText、AutoCorrect 和 Building Block 条目的存储区。

```cpp
System::SharedPtr<Aspose::Words::BuildingBlocks::GlossaryDocument> Aspose::Words::Document::get_GlossaryDocument() const
```

## 备注


如果文档没有词汇文档，此属性返回 **null**。

您可以通过创建 [GlossaryDocument](../../../aspose.words.buildingblocks/glossarydocument/) 对象并将其赋给此属性，向文档添加词汇文档。
