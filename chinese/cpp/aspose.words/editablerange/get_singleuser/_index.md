```cpp
System::String Aspose::Words::EditableRange::get_SingleUser()
```

## 备注


此编辑器可以以以下形式之一存储：

DOMAIN\\Username - 对于其访问应使用当前用户的域凭据进行身份验证的用户。

user@domain.com - 对于其访问应使用用户电子邮件地址作为凭据进行身份验证的用户。

user - 对于其访问应使用当前用户的机器凭据进行身份验证的用户。

对于特定的可编辑范围，单个用户和编辑器组不能同时设置；如果设置了其中一个，另一个将被清除。
