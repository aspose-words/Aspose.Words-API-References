## LoadOptions::get_UseSystemLcid method


获取或设置是否使用从 Windows 注册表获取的 LCID 值来确定页面设置的默认边距。

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## 备注


如果设置为 **true**，则模拟 MS Word 的行为，该行为从 Windows 注册表获取 LCID 值。

默认值为 **false**。
