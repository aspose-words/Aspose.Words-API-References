该 **Aspose.Words.WebExtensions** 命名空间提供类，允许自定义扩展用于表示 Office 加载项的 XML 词汇的元素和属性。

## 类

| 类 | 描述 |
| --- | --- |
| [BaseWebExtensionCollection](./basewebextensioncollection/) | 是 [TaskPaneCollection](./taskpanecollection/)、[WebExtensionBindingCollection](./webextensionbindingcollection/)、[WebExtensionPropertyCollection](./webextensionpropertycollection/) 和 [WebExtensionReferenceCollection](./webextensionreferencecollection/) 集合的基类。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [TaskPane](./taskpane/) | 表示一个加载项任务窗格对象。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [TaskPaneCollection](./taskpanecollection/) | 指定持久化任务窗格对象的列表。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtension](./webextension/) | 表示一个 Web 扩展对象。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionBinding](./webextensionbinding/) | 指定 Web 扩展与文档中数据之间的绑定关系。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | 指定 Web 扩展绑定的列表。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionProperty](./webextensionproperty/) | 指定 Web 扩展的自定义属性。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | 指定一组 Web 扩展的自定义属性。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionReference](./webextensionreference/) | 表示对 Web 扩展的引用。该引用用于标识扩展的提供者位置和版本。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | 指定 Web 扩展引用的列表。了解更多，请访问 [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/) 文档文章。 |
