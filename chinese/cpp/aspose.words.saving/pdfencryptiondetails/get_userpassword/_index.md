## PdfEncryptionDetails::get_UserPassword method


指定打开加密 PDF 文档所需的用户密码。

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_UserPassword() const
```

## 备注


打开加密的 PDF 文档进行查看时需要用户密码。[Permissions](../get_permissions/) 中指定的权限将由阅读器软件强制执行。

用户密码可以是 **null** 或空字符串，在这种情况下打开 PDF 文档时不需要用户提供密码。用户密码不能与所有者密码相同。
