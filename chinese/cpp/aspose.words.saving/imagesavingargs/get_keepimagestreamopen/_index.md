## ImageSavingArgs::get_KeepImageStreamOpen method


指定 Aspose.Words 在保存图像后是保持流打开还是关闭它。

```cpp
bool Aspose::Words::Saving::ImageSavingArgs::get_KeepImageStreamOpen() const
```

## 备注


默认是 **false**，Aspose.Words 将在向您提供的 [ImageStream](../get_imagestream/) 属性写入图像后关闭该流。指定 **true** 以保持流打开。
