## HtmlFixedSaveOptions::get_ResourcesFolderAlias method


指定用于构建写入 Html 文档的图像 URI 的文件夹名称。默认值为 **null**。

```cpp
System::String Aspose::Words::Saving::HtmlFixedSaveOptions::get_ResourcesFolderAlias() const
```

## 备注


当您以 Html 格式保存 [Document](../../../aspose.words/document/) 时，Aspose.Words 需要将文档中嵌入的所有图像保存为独立文件。[ResourcesFolder](../get_resourcesfolder/) 允许您指定图像保存的位置，而 [ResourcesFolderAlias](./) 则允许指定图像 URI 的构建方式。
