## ResourceSavingArgs::get_KeepResourceStreamOpen method


指定 Aspose.Words 在保存资源后是保持流打开还是关闭。

```cpp
bool Aspose::Words::Saving::ResourceSavingArgs::get_KeepResourceStreamOpen() const
```

## 备注


默认是 **false**，Aspose.Words 将在向其中写入资源后关闭您在 [ResourceStream](../get_resourcestream/) 属性中提供的流。指定 **true** 以保持流打开。
