## PdfPageMode enum


指定 PDF 文档在 PDF 阅读器中打开时的显示方式。

```cpp
enum class PdfPageMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| UseNone | 0 | 文档大纲和缩略图均不可见。 |
| UseOutlines | 1 | [Document](../../aspose.words/document/) 大纲可见。请注意，如果 PDF 文档中没有大纲，则大纲导航窗格将始终不可见。 |
| UseThumbs | 2 | 缩略图可见。 |
| FullScreen | 3 | 全屏模式，未显示菜单栏、窗口控制或任何其他窗口。 |
| UseOC | 4 | 可选内容组面板可见。 |
| UseAttachments | 5 | 附件面板可见。 |
