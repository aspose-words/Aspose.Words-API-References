## TiffCompression enum


指定在将页面图像保存为 TIFF 文件时使用的压缩类型。

```cpp
enum class TiffCompression
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | 0 | 指定不使用压缩。 |
| Rle | 1 | 指定 RLE 压缩方案。 |
| Lzw | 2 | 指定 LZW 压缩方案。在 Java 中通过 Deflate（Zip）压缩进行模拟。 |
| Ccitt3 | 3 | 指定 CCITT3 压缩方案。 |
| Ccitt4 | 4 | 指定 CCITT4 压缩方案。 |
