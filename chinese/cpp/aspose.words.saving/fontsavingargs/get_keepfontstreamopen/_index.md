## FontSavingArgs::get_KeepFontStreamOpen method


指定 Aspose.Words 在保存字体后是保持流打开还是关闭。

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## 备注


默认值为 **false**，Aspose.Words 将在向其中写入字体后关闭您在 [FontStream](../get_fontstream/) 属性中提供的流。指定 **true** 可保持流打开。
