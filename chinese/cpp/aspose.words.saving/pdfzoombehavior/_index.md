## PdfZoomBehavior enum


指定在 PDF 查看器中打开 PDF 文档时的缩放类型。

```cpp
enum class PdfZoomBehavior
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | 0 | 文档的显示方式由 PDF 查看器决定。通常查看器会将文档显示为适合页面宽度。 |
| ZoomFactor | 1 | 使用指定的缩放因子显示页面。 |
| FitPage | 2 | 将页面完整显示。 |
| FitWidth | 3 | 适配页面宽度。 |
| FitHeight | 4 | 适配页面高度。 |
| FitBox | 5 | 适配边界框（包含页面上所有可见元素的矩形）。 |
