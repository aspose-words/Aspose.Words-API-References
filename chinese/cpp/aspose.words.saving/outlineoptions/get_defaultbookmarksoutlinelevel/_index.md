## OutlineOptions::get_DefaultBookmarksOutlineLevel method


指定在文档大纲中显示 Word 书签的默认级别。

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_DefaultBookmarksOutlineLevel() const
```

## 备注


可以使用 [BookmarksOutlineLevels](../get_bookmarksoutlinelevels/) 属性来指定单个书签级别。

指定 0 时，Word 书签将不会显示在文档大纲中。指定 1 时，Word 书签将在文档大纲的第 1 级显示；2 表示第 2 级，依此类推。

默认值为 0。有效范围是 0 到 9。
