## CssSavingArgs::get_KeepCssStreamOpen method


指定 Aspose.Words 在保存 CSS 信息后是保持流打开还是关闭。

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## 备注


默认值为 **false**，Aspose.Words 会在向您提供的 [CssStream](../get_cssstream/) 属性写入 CSS 信息后关闭该流。指定 **true** 可保持流打开。
