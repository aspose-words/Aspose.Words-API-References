## PdfPageLayout enum


指定文档在 PDF 阅读器中打开时使用的页面布局。

```cpp
enum class PdfPageLayout
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| SinglePage | 0 | 一次显示一页。 |
| OneColumn | 1 | 在单列中显示页面。 |
| TwoColumnLeft | 2 | 在两列中显示页面，奇数页在左侧。 |
| TwoColumnRight | 3 | 在两列中显示页面，奇数页在右侧。 |
| TwoPageLeft | 4 | 每次显示两页，奇数页在左侧。 |
| TwoPageRight | 5 | 每次显示两页，奇数页在右侧。 |
