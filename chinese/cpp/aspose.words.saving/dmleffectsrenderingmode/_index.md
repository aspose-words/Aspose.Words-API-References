## DmlEffectsRenderingMode enum


指定 DrawingML 效果在固定页面格式中的渲染方式。

```cpp
enum class DmlEffectsRenderingMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Simplified | 0 | [渲染](../../aspose.words.rendering/) 已简化 DrawingML 效果。 |
| None | 1 | 未渲染任何 DrawingML 效果。 |
| Fine | 2 | DrawingML 效果以精细模式渲染，该模式涉及高级处理。在此模式下，效果的渲染能够获得更好的结果，但相较于 [简化](./) 模式会有更高的性能开销。 |
