## PageSavingArgs::get_KeepPageStreamOpen method


指定 Aspose.Words 在保存文档页面后是保持流打开还是关闭。

```cpp
bool Aspose::Words::Saving::PageSavingArgs::get_KeepPageStreamOpen() const
```

## 备注


默认是 **false**，Aspose.Words 会在将文档页写入后关闭您在 [PageStream](../get_pagestream/) 属性中提供的流。指定 **true** 以保持流打开。
