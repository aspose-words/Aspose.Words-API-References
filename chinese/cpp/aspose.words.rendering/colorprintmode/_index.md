## ColorPrintMode enum


指定在设备支持彩色打印时，非彩色页面的打印方式。

```cpp
enum class ColorPrintMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| 普通 | 0 | 所有页面均按照打印机的功能和设置进行打印。 |
| GrayscaleAuto | 1 | 检测到的非彩色页面将以灰度方式打印。 |
