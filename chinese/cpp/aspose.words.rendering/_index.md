该 **Aspose.Words.Rendering** 命名空间提供类，允许自定义文档的打印或渲染。

## 类

| 类 | 描述 |
| --- | --- |
| [NodeRendererBase](./noderendererbase/) | 用于 [ShapeRenderer](./shaperenderer/) 和 [OfficeMathRenderer](./officemathrenderer/) 的基类。欲了解更多，请访问 [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/) 文档文章。 |
| [OfficeMathRenderer](./officemathrenderer/) | 提供将单个 [OfficeMath](../aspose.words.math/officemath/) 渲染为光栅或矢量图像或 Graphics 对象的方法。欲了解更多，请访问 [Working with OfficeMath](https://docs.aspose.com/words/cpp/working-with-officemath/) 文档文章。 |
| [PageInfo](./pageinfo/) | 表示特定文档页的信息。欲了解更多，请访问 [Rendering](https://docs.aspose.com/words/cpp/rendering/) 文档文章。 |
| [ShapeRenderer](./shaperenderer/) | 提供将单个 [Shape](../aspose.words.drawing/shape/) 或 [GroupShape](../aspose.words.drawing/groupshape/) 渲染为光栅或矢量图像或 Graphics 对象的方法。欲了解更多，请访问 [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/) 文档文章。 |
| [ThumbnailGeneratingOptions](./thumbnailgeneratingoptions/) | 可用于在为文档生成缩略图时指定其他选项。 |
