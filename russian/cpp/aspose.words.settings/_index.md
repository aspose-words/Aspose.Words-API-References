Пространство имен **Aspose.Words.Settings** содержит классы и перечисления, используемые при указании различных настроек и параметров, хранящихся в документе. Это слияние почты, защита от записи, совместимость и другие настройки.

## Классы

| Класс | Описание |
| --- | --- |
| [CompatibilityOptions](./compatibilityoptions/) | Содержит параметры совместимости (то есть пользовательские настройки, введённые на вкладке **Compatibility** диалогового окна **Options** в Microsoft Word). Чтобы узнать больше, посетите статью документации [Detect File Format and Check Format Compatibility](https://docs.aspose.com/words/cpp/detect-file-format-and-check-format-compatibility/). |
| [HyphenationOptions](./hyphenationoptions/) | Позволяет настраивать параметры переноса слов в документе. Чтобы узнать больше, посетите статью документации [Working with Hyphenation](https://docs.aspose.com/words/cpp/working-with-hyphenation/). |
| [MailMergeSettings](./mailmergesettings/) | Указывает всю информацию о слиянии почты для документа. Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [Odso](./odso/) | Указывает настройки объекта источника данных Office (ODSO) для источника данных слияния почты. Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapData](./odsofieldmapdata/) | Указывает, как столбец во внешнем источнике данных будет сопоставлен с предопределёнными полями слияния в документе. Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapDataCollection](./odsofieldmapdatacollection/) | Типизированная коллекция объектов [OdsoFieldMapData](./odsofieldmapdata/). Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientData](./odsorecipientdata/) | Представляет информацию об отдельной записи во внешнем источнике данных, которая должна быть исключена из слияния почты. Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientDataCollection](./odsorecipientdatacollection/) | Типизированная коллекция [OdsoRecipientData](./odsorecipientdata/). Чтобы узнать больше, посетите статью документации [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [ViewOptions](./viewoptions/) | Предоставляет различные параметры, которые контролируют отображение документа в Microsoft Word. Чтобы узнать больше, посетите статью документации [Work with Options and Appearance of Word Documents](https://docs.aspose.com/words/cpp/work-with-word-document-options-and-appearance/). |
| [WriteProtection](./writeprotection/) | Указывает настройки защиты от записи для документа. Чтобы узнать больше, посетите статью документации [Protect or Encrypt a Document](https://docs.aspose.com/words/cpp/protect-or-encrypt-a-document/). |
