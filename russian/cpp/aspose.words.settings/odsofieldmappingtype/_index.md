## OdsoFieldMappingType enum


Указывает возможные типы, используемые для указания, сопоставлено ли данное поле слияния почты с колонкой во внешнем источнике данных.

```cpp
enum class OdsoFieldMappingType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Колонка | 0 | Указывает, что поле слияния было сопоставлено с колонкой во внешнем источнике данных. |
| Null | 1 | Указывает, что поле слияния не было сопоставлено с колонкой во внешнем источнике данных. |
| Default | n/a | Равно [Null](./). |
