## MailMergeDataType enum


Указывает тип внешнего источника данных для слияния почты.

```cpp
enum class MailMergeDataType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | -1 | Не указан источник данных слияния почты. |
| TextFile | 0 | Указывает, что данный документ был подключен к текстовому файлу через систему Dynamic Data Exchange (DDE). |
| Database | 1 | Указывает, что данный документ был подключен к базе данных Access через систему Dynamic Data Exchange (DDE). |
| Spreadsheet | 2 | Указывает, что данный документ был подключен к электронному листу Excel через систему Dynamic Data Exchange (DDE). |
| Query | 3 | Указывает, что данный документ был подключен к внешнему источнику данных с использованием внешнего инструмента запросов. |
| Odbc | 4 | Указывает, что данный документ был подключен к внешнему источнику данных через интерфейс Open Database Connectivity. |
| Native | 5 | Указывает, что данный документ был подключен к внешнему источнику данных через интерфейс Office Data Source Object (ODSO). |
| Default | n/a | Равно [None](./). |
