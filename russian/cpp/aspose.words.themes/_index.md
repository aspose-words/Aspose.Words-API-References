Пространство имен **Aspose.Words.Themes** предоставляет классы, позволяющие получать информацию о темах в документах Microsoft Word.

## Классы

| Класс | Описание |
| --- | --- |
| [Theme](./theme/) | Представляет документ [Theme](./theme/), и предоставляет доступ к основным частям темы, включая [MajorFonts](./theme/get_majorfonts/), [MinorFonts](./theme/get_minorfonts/) и [Colors](./theme/get_colors/). Чтобы узнать больше, посетите статью документации [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeColors](./themecolors/) | Представляет цветовую схему темы документа, содержащую двенадцать цветов. Объект [ThemeColors](./themecolors/) содержит шесть акцентных цветов, два тёмных цвета, два светлых цвета и цвет для гиперссылки и посещённой гиперссылки. |
| [ThemeFonts](./themefonts/) | Представляет коллекцию шрифтов в схеме шрифтов, позволяя указывать разные шрифты для разных языков: [Latin](./themefonts/get_latin/), [EastAsian](./themefonts/get_eastasian/) и [ComplexScript](./themefonts/get_complexscript/). Чтобы узнать больше, посетите статью документации [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |

| [ThemeFont](./themefont/) | Указывает типы названий шрифтов темы для тем документа. |
