## LoadOptions::get_UseSystemLcid method


Получает или задает, использовать ли значение LCID, полученное из реестра Windows, для определения полей страницы по умолчанию.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Примечания


Если установлено в **true**, то эмулируется поведение MS Word, которое берёт значение LCID из реестра Windows.

Значение по умолчанию — **false**.
