Пространство имен **Aspose.Words.Properties** предоставляет классы для работы с пользовательскими и встроенными свойствами документа, такими как заголовок, ключевые слова, компания и т.д.

| Класс | Описание |
| --- | --- |
| [BuiltInDocumentProperties](./builtindocumentproperties/) | Коллекция встроенных свойств документа. Чтобы узнать больше, посетите статью документации [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [CustomDocumentProperties](./customdocumentproperties/) | Коллекция пользовательских свойств документа. Чтобы узнать больше, посетите статью документации [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [DocumentProperty](./documentproperty/) | Представляет пользовательское или встроенное свойство документа. Чтобы узнать больше, посетите статью документации [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [DocumentPropertyCollection](./documentpropertycollection/) | Базовый класс для коллекций [BuiltInDocumentProperties](./builtindocumentproperties/) и [CustomDocumentProperties](./customdocumentproperties/). Чтобы узнать больше, посетите статью документации [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
