Пространство имён **Aspose.Words.AI** обеспечивает бесшовную интеграцию с крупными языковыми моделями (LLM), такими как OpenAI и Gemini, предоставляя надёжную поддержку обработки документов с использованием ИИ.

## Классы

| Класс | Описание |
| --- | --- |
| [AiModel](./aimodel/) | Абстрактный класс, представляющий интеграцию с различными моделями [AI](./) в рамках [Aspose.Words](../aspose.words/). |
| [AnthropicAiModel](./anthropicaimodel/) | Абстрактный класс, представляющий интеграцию с моделями [AI](./) от Anthropic в рамках [Aspose.Words](../aspose.words/). |
| [CheckGrammarOptions](./checkgrammaroptions/) | Позволяет задавать различные параметры при проверке грамматики документа с использованием [AI](./). |
| [GoogleAiModel](./googleaimodel/) | Класс, представляющий интеграцию моделей Google [AI](./) (Gemini) в рамках [Aspose.Words](../aspose.words/). |
| [OpenAiModel](./openaimodel/) | Класс, представляющий интеграцию моделей OpenAi в рамках [Aspose.Words](../aspose.words/). |
| [SummarizeOptions](./summarizeoptions/) | Позволяет задавать различные параметры для суммирования содержимого документа. |
