Пространство имён **Aspose.Words.Comparing** предоставляет классы и перечисления, позволяющие задавать дополнительные параметры при сравнении документов.

## Классы

| Класс | Описание |
| --- | --- |
| [AdvancedCompareOptions](./advancedcompareoptions/) | Позволяет задавать расширенные параметры сравнения. |
| [CompareOptions](./compareoptions/) | Позволяет выбирать дополнительные параметры для операции сравнения документов. Чтобы узнать больше, посетите статью документации [Compare Documents](https://docs.aspose.com/words/cpp/compare-documents/). |
## Enums

| Перечисление | Описание |
| --- | --- |
| [ComparisonTargetType](./comparisontargettype/) | Позволяет указать базовый документ, который будет использоваться во время сравнения. Значение по умолчанию — [Current](./comparisontargettype/). |
| [Granularity](./granularity/) | Указывает степень детализации изменений, отслеживаемых при сравнении двух документов. |
