## FormField::get_StatusText method


Возвращает или задает текст, отображаемый в строке состояния, когда поле формы имеет фокус.

```cpp
System::String Aspose::Words::Fields::FormField::get_StatusText()
```

## Примечания


Если свойство [OwnStatus](../get_ownstatus/) установлено в **true**, свойство [StatusText](./) задает текст строки состояния. Если свойство [OwnStatus](../get_ownstatus/) установлено в **false**, свойство [StatusText](./) задает имя записи AutoText, содержащей текст строки состояния для поля формы.

Microsoft Word позволяет строки длиной не более 138 символов.
