## FormField::get_HelpText method


Возвращает или задает текст, отображаемый в диалоговом окне сообщения, когда поле формы имеет фокус и пользователь нажимает F1.

```cpp
System::String Aspose::Words::Fields::FormField::get_HelpText()
```

## Примечания


Если свойство [OwnHelp](../get_ownhelp/) установлено в **true**, [HelpText](./) задает строковое значение текста. Если [OwnHelp](../get_ownhelp/) установлено в **false**, [HelpText](./) задает имя записи AutoText, содержащей справочный текст для поля формы.

Microsoft Word допускает строки длиной не более 255 символов.
