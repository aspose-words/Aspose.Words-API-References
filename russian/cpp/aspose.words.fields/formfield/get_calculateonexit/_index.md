## FormField::get_CalculateOnExit method


True, если ссылки на указанный поле формы автоматически обновляются при выходе из поля.

```cpp
bool Aspose::Words::Fields::FormField::get_CalculateOnExit()
```

## Примечания


Настройка [CalculateOnExit](./) влияет только на поведение поля формы, когда документ открыт в Microsoft Word. Aspose.Words никогда не обновляет ссылки на поле формы.
