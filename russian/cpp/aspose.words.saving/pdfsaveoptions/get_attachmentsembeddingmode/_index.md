## PdfSaveOptions::get_AttachmentsEmbeddingMode method


Получает или задаёт значение, определяющее, как вложения встраиваются в PDF‑документ.

```cpp
Aspose::Words::Saving::PdfAttachmentsEmbeddingMode Aspose::Words::Saving::PdfSaveOptions::get_AttachmentsEmbeddingMode() const
```

## Примечания


Значение по умолчанию — [None](../../pdfattachmentsembeddingmode/), и вложения не встраиваются.

Стандарты PDF/A‑1, PDF/A‑2 и обычный PDF/A‑4 (не PDF/A‑4f) не допускают встраивание файлов. Значение [None](../../pdfattachmentsembeddingmode/) будет использоваться автоматически.
