## PdfSaveOptions::get_AdditionalTextPositioning method


Флаг, указывающий, следует ли записывать дополнительные операторы позиционирования текста или нет.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_AdditionalTextPositioning() const
```

## Примечания


Если **true**, дополнительные операторы позиционирования текста записываются в выходной PDF. Это может помочь решить проблемы с неточным позиционированием текста у некоторых принтеров. Недостаток — увеличенный размер PDF‑документа.

Значение по умолчанию — **false**.
