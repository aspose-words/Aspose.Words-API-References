## PdfSaveOptions::get_InterpolateImages method


Флаг, указывающий, должна ли интерполяция изображения выполняться совместимым просмотрщиком. Когда указано **false**, флаг не записывается в выходной документ, и используется поведение просмотрщика по умолчанию.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_InterpolateImages() const
```

## Примечания


Когда разрешение исходного изображения значительно ниже, чем у выходного устройства, каждый образец исходного изображения покрывает множество пикселей устройства. В результате изображения могут выглядеть зубчатыми или блочными. Эти визуальные артефакты можно уменьшить, применяя алгоритм интерполяции изображений во время рендеринга. Вместо того чтобы закрашивать все пиксели, покрытые образцом исходного изображения, одинаковым цветом, интерполяция пытается создать плавный переход между соседними значениями образцов.

Соответствующий Reader может решить не реализовывать эту функцию PDF, либо использовать любую конкретную реализацию интерполяции, которую он пожелает.

Значение по умолчанию — **false**.

Флаг интерполяции запрещён требованиями PDF/A. Значение **false** будет использоваться автоматически при сохранении в PDF/A.
