## PdfSaveOptions::get_DisplayDocTitle method


Флаг, указывающий, должно ли заголовок окна отображать название документа, взятое из записи Title словаря информации о документе.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_DisplayDocTitle() const
```

## Примечания


Если **false**, строка заголовка должна вместо этого отображать имя PDF‑файла, содержащего документ.

Этот флаг требуется для соответствия PDF/UA. Значение **true** будет использоваться автоматически при сохранении в PDF/UA.

Значение по умолчанию — **false**.
