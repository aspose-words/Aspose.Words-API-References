## NumeralFormat enum


Указывает набор символов, используемый для представления чисел при отображении в фиксированные форматы страниц.

```cpp
enum class NumeralFormat
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| European | 0 | Европейские цифры: 0123456789. |
| ArabicIndic | 1 | Цифры, используемые в арабском: ٠١٢٣٤٥٦٧٨٩. Диапазон Unicode U+0660 - u+0669. |
| Восточноарабские индик | 2 | Цифры, используемые в персидском и урду: ۰۱۲۳۴۵۶۷۸۹. Диапазон Unicode U+06F0 - u+06F9. |
| Контекст | 3 | Набор символов определяется из контекста (локаль и свойство RTL). |
| Система | 4 | ЭТА ОПЦИЯ НЕ ПОДДЕРЖИВАЕТСЯ. Набор символов определяется из региональных настроек. |
