## PdfImageColorSpaceExportMode enum


Указывает, как будет выбран цветовое пространство для изображений в PDF‑документе.

```cpp
enum class PdfImageColorSpaceExportMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Авто | 0 | Aspose.Words автоматически выбирает наиболее подходящее цветовое пространство для каждого изображения. |
| SimpleCmyk | 1 | Aspose.Words преобразует RGB‑изображения в CMYK‑цветовое пространство, используя простую формулу. |
