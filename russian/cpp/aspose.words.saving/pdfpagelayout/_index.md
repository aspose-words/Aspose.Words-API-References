## PdfPageLayout enum


Указывает макет страницы, который будет использоваться при открытии документа в PDF‑читалке.

```cpp
enum class PdfPageLayout
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| SinglePage | 0 | Отображать одну страницу за раз. |
| OneColumn | 1 | Отображать страницы в одной колонке. |
| TwoColumnLeft | 2 | Отображать страницы в двух колонках, при этом нечётные страницы находятся слева. |
| TwoColumnRight | 3 | Отображать страницы в двух колонках, при этом нечётные страницы находятся справа. |
| TwoPageLeft | 4 | Отображать две страницы одновременно, при этом нечётные страницы находятся слева. |
| TwoPageRight | 5 | Отображать две страницы одновременно, при этом нечётные страницы находятся справа. |
