## DmlRenderingMode enum


Указывает, как фигуры DrawingML отображаются в фиксированных форматах страниц.

```cpp
enum class DmlRenderingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Fallback | 0 | Если для DrawingML доступна резервная форма, Aspose.Words рендерит резервную форму вместо DrawingML. |
| DrawingML | 1 | Aspose.Words игнорирует резервную форму DrawingML и рендерит сам DrawingML. Это режим по умолчанию. |
