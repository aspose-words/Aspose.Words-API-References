## HtmlFixedSaveOptions::get_ResourcesFolderAlias method


Указывает имя папки, используемой для построения URI изображений, записываемых в документ Html. Значение по умолчанию — **null**.

```cpp
System::String Aspose::Words::Saving::HtmlFixedSaveOptions::get_ResourcesFolderAlias() const
```

## Примечания


При сохранении [Document](../../../aspose.words/document/) в формате Html, Aspose.Words необходимо сохранять все изображения, встроенные в документ, как отдельные файлы. [ResourcesFolder](../get_resourcesfolder/) позволяет указать, где будут сохраняться изображения, а [ResourcesFolderAlias](./) позволяет указать, как будут формироваться URI изображений.
