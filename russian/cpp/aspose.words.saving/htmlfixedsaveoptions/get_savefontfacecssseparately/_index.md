## HtmlFixedSaveOptions::get_SaveFontFaceCssSeparately method


Флаг указывает, должны ли правила CSS "@font-face" помещаться в отдельный файл "fontFaces.css", когда документ сохраняется с внешней таблицей стилей (то есть когда [ExportEmbeddedCss](../get_exportembeddedcss/) имеет значение **false**). Значение по умолчанию — **false**, все правила CSS записываются в один файл "styles.css".
