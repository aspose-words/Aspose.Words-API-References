## PdfPermissions enum


Указывает операции, разрешённые пользователю над зашифрованным PDF‑документом.

```cpp
enum class PdfPermissions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| DisallowAll | 0 | Запрещает все операции над PDF‑документом. Это значение по умолчанию. |
| AllowAll | 65535 | Разрешает все операции над PDF‑документом. |
| ContentCopy | n/a | Копировать или иным способом извлекать текст и графику из документа с помощью операций, отличных от контролируемых [ContentCopyForAccessibility](./). |
| ContentCopyForAccessibility | н/д | Извлекать текст и графику (в целях обеспечения доступности для пользователей с ограниченными возможностями или для других целей). |
| ModifyContents | n/a | Изменять содержимое документа с помощью операций, отличных от контролируемых [ModifyAnnotations](./), [FillIn](./) и [DocumentAssembly](./). |
| ModifyAnnotations | n/a | Добавлять или изменять текстовые аннотации, заполнять интерактивные поля формы и, если установлен [ModifyContents](./), создавать или изменять интерактивные поля формы (включая поля подписи). |
| FillIn | n/a | Заполнять существующие интерактивные поля формы (включая поля подписи), даже если [ModifyContents](./) не установлен. |
| DocumentAssembly | n/a | Собирать документ (вставлять, вращать или удалять страницы и создавать элементы структуры документа или миниатюры), даже если [ModifyContents](./) не установлен. |
| Printing | n/a | Печатать документ (возможно, не в самом высоком качестве, в зависимости от того, установлен ли также [HighResolutionPrinting](./)). |
| HighResolutionPrinting | n/a | Печатать документ в представление, из которого может быть создана точная цифровая копия PDF‑содержимого, на основе алгоритма, зависящего от реализации. Когда этот флаг не установлен (и установлен [Printing](./)), печать должна быть ограничена представлением низкого уровня внешнего вида, возможно, с ухудшенным качеством. |
