## PdfPageMode enum


Указывает, как PDF‑документ должен отображаться при открытии в PDF‑читалке.

```cpp
enum class PdfPageMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| UseNone | 0 | Ни контур документа, ни миниатюры не видны. |
| UseOutlines | 1 | [Document](../../aspose.words/document/) контур виден. Обратите внимание, что если в PDF‑документе нет контуров, панель навигации по контуру всё равно не будет видна. |
| UseThumbs | 2 | Миниатюры видны. |
| FullScreen | 3 | Режим полного экрана без панели меню, элементов управления окнами или каких‑либо других видимых окон. |
| UseOC | 4 | Панель группы дополнительного содержимого видна. |
| UseAttachments | 5 | Панель вложений видна. |
