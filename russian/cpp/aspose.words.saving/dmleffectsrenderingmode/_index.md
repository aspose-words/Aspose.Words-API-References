## DmlEffectsRenderingMode enum


Указывает, как эффекты DrawingML отображаются в фиксированных форматах страниц.

```cpp
enum class DmlEffectsRenderingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Simplified | 0 | [Rendering](../../aspose.words.rendering/) упрощает рендеринг эффектов DrawingML. |
| None | 1 | Эффекты DrawingML не рендерятся. |
| Fine | 2 | Эффекты DrawingML рендерятся в тонком режиме, который включает продвинутую обработку. В этом режиме рендеринг эффектов дает лучшие результаты, но с более высокой стоимостью производительности, чем режим [Simplified](./). |
