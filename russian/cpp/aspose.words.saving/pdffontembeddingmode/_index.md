## PdfFontEmbeddingMode enum


Указывает, как Aspose.Words должен встраивать шрифты.

```cpp
enum class PdfFontEmbeddingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| EmbedAll | 0 | Aspose.Words встраивает все шрифты. |
| EmbedNonstandard | 1 | Aspose.Words встраивает все шрифты, за исключением стандартных шрифтов Windows Arial и Times New Roman. Только шрифты Arial и Times New Roman затрагиваются в этом режиме, потому что MS Word не встраивает только эти шрифты при сохранении документа в PDF. |
| EmbedNone | 2 | Aspose.Words не встраивает никакие шрифты. |
