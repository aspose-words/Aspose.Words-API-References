## PdfAttachmentsEmbeddingMode enum


Указывает, как вложения встраиваются в PDF‑документ.

```cpp
enum class PdfAttachmentsEmbeddingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | 0 | Вложения не встраиваются. |
| Аннотации | 1 | Вложения встраиваются как аннотации с указанием местоположения на странице. |
| DocumentEmbeddedFiles | 2 | Вложения встраиваются как встроенные файлы документа без аннотаций. |
