## CssStyleSheetType enum


Указывает, как стили CSS (Cascading [Style](../../aspose.words/style/) Sheet) экспортируются в HTML.

```cpp
enum class CssStyleSheetType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Встроенный | 0 | Стили CSS записываются встроенно (в виде значения атрибута **style** у каждого элемента). |
| Встроенный | 1 | CSS‑стили записываются отдельно от содержимого в таблице стилей, встроенной в HTML‑файл. |
| Внешний | 2 | CSS‑стили записываются отдельно от содержимого в таблице стилей во внешнем файле. HTML‑файл связывает таблицу стилей. |
