## OutlineOptions::get_HeadingsOutlineLevels method


Указывает, сколько уровней заголовков (абзацев, отформатированных стилями Heading) включать в контур документа.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_HeadingsOutlineLevels() const
```

## Примечания


Укажите 0, чтобы не было заголовков в структуре; укажите 1, чтобы включить один уровень заголовков в структуру и т.д.

По умолчанию 0. Допустимый диапазон от 0 до 9.
