## OutlineOptions::get_DefaultBookmarksOutlineLevel method


Указывает уровень по умолчанию в контуре документа, на котором отображать закладки Word.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_DefaultBookmarksOutlineLevel() const
```

## Примечания


Уровень отдельных закладок можно задать с помощью свойства [BookmarksOutlineLevels](../get_bookmarksoutlinelevels/).

Укажите 0, и закладки Word не будут отображаться в структуре документа. Укажите 1, и закладки Word будут отображаться в структуре документа на уровне 1; 2 — на уровне 2 и так далее.

По умолчанию 0. Допустимый диапазон от 0 до 9.
