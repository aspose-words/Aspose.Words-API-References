## XamlFlowSaveOptions class


Может использоваться для указания дополнительных параметров при сохранении документа в формат [XamlFlow](../../aspose.words/saveformat/) или [XamlFlowPack](../../aspose.words/saveformat/). Чтобы узнать больше, посетите статью документации [Specify Save Options](https://docs.aspose.com/words/cpp/specify-save-options/).

```cpp
class XamlFlowSaveOptions : public Aspose::Words::Saving::SaveOptions
```
