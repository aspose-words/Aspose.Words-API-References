
## Примечания


Это свойство действует только при сохранении в растровые форматы изображений.

Значение по умолчанию — [Format32BppArgb](../../imagepixelformat/).

Пиксельный формат выходного изображения может отличаться от установленного значения из‑за работы GDI+.
