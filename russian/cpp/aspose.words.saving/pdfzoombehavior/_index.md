## PdfZoomBehavior enum


Указывает тип масштабирования, применяемый к PDF‑документу при его открытии в PDF‑просмотрщике.

```cpp
enum class PdfZoomBehavior
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | 0 | То, как документ отображается, зависит от PDF‑просмотрщика. Обычно просмотрщик отображает документ, подгоняя его под ширину страницы. |
| ZoomFactor | 1 | Отображает страницу с использованием указанного коэффициента масштабирования. |
| FitPage | 2 | Отображает страницу так, чтобы она была полностью видна. |
| FitWidth | 3 | Подгоняет ширину страницы. |
| FitHeight | 4 | Подгоняет высоту страницы. |
| FitBox | 5 | Подгоняет ограничивающий прямоугольник (прямоугольник, содержащий все видимые элементы на странице). |
