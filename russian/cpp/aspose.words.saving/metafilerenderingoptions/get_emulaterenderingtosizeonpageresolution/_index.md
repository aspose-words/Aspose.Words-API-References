## MetafileRenderingOptions::get_EmulateRenderingToSizeOnPageResolution method


Получает или задает разрешение в пикселях на дюйм для эмуляции рендеринга метафайла к размеру на странице.

```cpp
int32_t Aspose::Words::Saving::MetafileRenderingOptions::get_EmulateRenderingToSizeOnPageResolution() const
```

## Примечания


Эта опция используется только когда [EmulateRenderingToSizeOnPage](../get_emulaterenderingtosizeonpage/) установлена в **true**.

Значение по умолчанию — 96. Это стандартное разрешение экрана. Т.е. рендеринг метафайла будет эмулировать отображение метафайла в MS Word при коэффициенте масштабирования 100%.
