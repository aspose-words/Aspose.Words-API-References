## FontSavingArgs::get_KeepFontStreamOpen method


Указывает, должна ли Aspose.Words оставлять поток открытым или закрывать его после сохранения шрифта.

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## Примечания


По умолчанию **false**, и Aspose.Words закроет поток, указанный в свойстве [FontStream](../get_fontstream/), после записи в него шрифта. Установите **true**, чтобы оставить поток открытым.
