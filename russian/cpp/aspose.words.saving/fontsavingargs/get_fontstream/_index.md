## FontSavingArgs::get_FontStream method


Позволяет указать поток, в который будет сохранён шрифт.

```cpp
System::SharedPtr<System::IO::Stream> Aspose::Words::Saving::FontSavingArgs::get_FontStream() const
```

## Примечания


Это свойство позволяет сохранять шрифты в потоки вместо файлов при экспорте HTML.

Значение по умолчанию — **null**. Когда это свойство равно **null**, шрифт будет сохранён в файл, указанный в свойстве [FontFileName](../get_fontfilename/).
