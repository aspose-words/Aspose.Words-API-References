## XamlFixedSaveOptions::get_ResourcesFolderAlias method


Указывает имя папки, используемой для построения URI изображений, записываемых в фиксированный Xaml‑документ. По умолчанию **null**.

```cpp
System::String Aspose::Words::Saving::XamlFixedSaveOptions::get_ResourcesFolderAlias() const
```

## Примечания


Когда вы сохраняете [Document](../../../aspose.words/document/) в фиксированном Xaml-формате, Aspose.Words необходимо сохранять все изображения, встроенные в документ, как отдельные файлы. [ResourcesFolder](../get_resourcesfolder/) позволяет указать, где будут сохраняться изображения, а [ResourcesFolderAlias](./) позволяет задать, как будут формироваться URI изображений.
