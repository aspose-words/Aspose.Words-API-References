## CssSavingArgs::get_KeepCssStreamOpen method


Указывает, должен ли Aspose.Words оставлять поток открытым или закрывать его после сохранения информации CSS.

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## Примечания


По умолчанию **false**, и Aspose.Words закроет поток, указанный в свойстве [CssStream](../get_cssstream/), после записи в него информации CSS. Укажите **true**, чтобы оставить поток открытым.
