## CssSavingArgs::set_IsExportNeeded method


Позволяет указать, будет ли CSS экспортироваться в файл и встраиваться в HTML‑документ. По умолчанию **true**. Когда это свойство **false**, информация CSS не будет сохраняться в файл CSS и не будет встраиваться в HTML‑документ.
