## Table::get_Description method


Получает или задаёт описание этой таблицы. Оно предоставляет альтернативное текстовое представление информации, содержащейся в таблице.

```cpp
System::String Aspose::Words::Tables::Table::get_Description()
```

## Примечания


Значение по умолчанию — пустая строка.

Это свойство имеет смысл для DOCX‑документов, соответствующих ISO/IEC 29500 ([OoxmlCompliance](../../../aspose.words.saving/ooxmlcompliance/)). При сохранении в форматы до ISO/IEC 29500 свойство игнорируется.
