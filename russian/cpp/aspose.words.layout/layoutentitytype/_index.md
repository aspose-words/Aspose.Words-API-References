## LayoutEntityType enum


Типы сущностей компоновки.

```cpp
enum class LayoutEntityType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | н/д | Значение по умолчанию. |
| Page | n/a | Представляет страницу документа. Страница может иметь дочерние сущности [Column](./), [HeaderFooter](./) и [Comment](./). |
| Column | n/a | Представляет колонку текста на странице. Колонка может иметь те же дочерние сущности, что и [Cell](./), а также сущности [Footnote](./), [Endnote](./) и [NoteSeparator](./). |
| Row | n/a | Представляет строку таблицы. Строка может иметь [Cell](./) в качестве дочерних сущностей. |
| Cell | n/a | Представляет ячейку таблицы. Ячейка может иметь дочерние сущности [Line](./) и [Row](./). |
| Line | n/a | Представляет строку символов текста и встроенных объектов. Строка может иметь дочерние сущности [Span](./). |
| Span | н/д | Представляет один или несколько символов в строке. Это включает специальные символы, такие как маркеры начала/конца поля, закладки и комментарии. Span не может иметь дочерних сущностей. |
| Footnote | n/a | Представляет заполнитель для содержимого сноски. Сноска может иметь дочерние сущности [Note](./). |
| Endnote | n/a | Представляет заполнитель для содержимого концевой сноски. Концевая сноска может иметь дочерние сущности [Note](./). |
| Note | n/a | Представляет заполнитель для содержимого заметки. Заметка может иметь дочерние сущности [Line](./) и [Row](./). |
| HeaderFooter | n/a | Представляет заполнитель для содержимого верхнего/нижнего колонтитула на странице. [HeaderFooter](../../aspose.words/headerfooter/) может иметь дочерние сущности [Line](./) и [Row](./). |
| TextBox | n/a | Представляет текстовую область внутри фигуры. Textbox может иметь дочерние сущности [Line](./) и [Row](./). |
| Comment | n/a | Представляет заполнитель для содержимого комментария. [Comment](../../aspose.words/comment/) может иметь дочерние сущности [Line](./) и [Row](./). |
| NoteSeparator | n/a | Представляет разделитель сносок/концевых сносок. NoteSeparator может иметь дочерние сущности [Line](./) и [Row](./). |
