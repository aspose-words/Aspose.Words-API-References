## PageLayoutEvent enum


Код события, возникающего во время построения и отрисовки модели компоновки страниц. Модель компоновки страниц создаётся в два этапа. Сначала — "этап конверсии", когда компоновка извлекает содержимое документа и создает граф объектов. Затем — "этап перераспределения", когда структуры разбиваются, объединяются и размещаются по страницам. В зависимости от операции, инициировавшей построение, модель компоновки может быть либо не отрисована дальше в фиксированный формат страниц, либо отрисована. Например, вычисление количества страниц в документе или обновление полей не требует отрисовки, тогда как экспорт в PDF требует.

```cpp
enum class PageLayoutEvent
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | 0 | Значение по умолчанию. |
| WatchDog | 1 | Соответствует контрольной точке в коде, которая часто посещается и подходит для прерывания процесса. Находясь внутри [Notify()](../ipagelayoutcallback/notify/) бросайте пользовательское исключение, чтобы прервать процесс. Вы можете бросить его при обработке любого события обратного вызова, чтобы прервать процесс. Обратите внимание, что если процесс прерван, модель разметки страницы остаётся в неопределённом состоянии. Однако если процесс прерван во время перераспределения полной страницы, модель разметки всё равно можно использовать до конца этой страницы. |
| BuildStarted | 2 | Построение разметки страницы началось. Событие генерируется один раз. Это первое событие, которое происходит при вызове [UpdatePageLayout](../../aspose.words/document/updatepagelayout/). |
| BuildFinished | 3 | Построение разметки страницы завершилось. Событие генерируется один раз. Это последнее событие, которое происходит при вызове [UpdatePageLayout](../../aspose.words/document/updatepagelayout/). |
| ConversionStarted | 4 | Конверсия модели документа в разметку страницы началась. Событие генерируется один раз. Это происходит, когда модель разметки начинает вытягивать содержимое документа. |
| ConversionFinished | 5 | Конверсия модели документа в разметку страницы завершилась. Событие генерируется один раз. Это происходит, когда модель разметки прекращает вытягивать содержимое документа. |
| ReflowStarted | 6 | Перераспределение разметки страницы началось. Событие генерируется один раз. Это происходит, когда модель разметки начинает перераспределять содержимое документа. |
| ReflowFinished | 7 | Перераспределение разметки страницы завершилось. Событие генерируется один раз. Это происходит, когда модель разметки прекращает перераспределять содержимое документа. |
| PartReflowStarted | 8 | Перераспределение страницы началось. Обратите внимание, что страница может перераспределяться несколько раз, и процесс может перезапускаться до завершения. |
| PartReflowFinished | 9 | Перераспределение страницы завершилось. Обратите внимание, что страница может перераспределяться несколько раз, и процесс может перезапускаться до завершения. |
| PartRenderingStarted | 10 | [Rendering](../../aspose.words.rendering/) страницы начался. Это событие генерируется один раз для каждой страницы. |
| PartRenderingFinished | 11 | [Rendering](../../aspose.words.rendering/) страницы завершилось. Это событие генерируется один раз для каждой страницы. |
