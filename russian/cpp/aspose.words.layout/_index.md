Пространство имён **Aspose.Words.Layout** предоставляет классы, позволяющие получать информацию о том, на какой странице и где на странице находятся конкретные элементы документа при его разбиении на страницы.

## Классы

| Класс | Описание |
| --- | --- |
| [LayoutCollector](./layoutcollector/) | Этот класс позволяет вычислять номера страниц узлов документа. Чтобы узнать больше, посетите статью документации [Converting to Fixed-page Format](https://docs.aspose.com/words/cpp/converting-to-fixed-page-format/). |
| [LayoutEnumerator](./layoutenumerator/) | Перечисляет сущности компоновки страниц документа. Вы можете использовать этот класс для обхода модели компоновки страниц. Доступные свойства: тип, геометрия, текст и индекс страницы, на которой отрисовывается сущность, а также общая структура и взаимосвязи. Используйте комбинацию [GetEntity()](../) и [Current](./layoutenumerator/get_current/) для перехода к сущности, соответствующей узлу документа. Чтобы узнать больше, посетите статью документации [Converting to Fixed-page Format](https://docs.aspose.com/words/cpp/converting-to-fixed-page-format/). |
| [LayoutOptions](./layoutoptions/) | Содержит параметры, позволяющие управлять процессом компоновки документа. Чтобы узнать больше, посетите статью документации [Converting to Fixed-page Format](https://docs.aspose.com/words/cpp/converting-to-fixed-page-format/). |
| [PageLayoutCallbackArgs](./pagelayoutcallbackargs/) | Аргумент, передаваемый в [Notify()](./ipagelayoutcallback/notify/). Чтобы узнать больше, посетите статью документации [Converting to Fixed-page Format](https://docs.aspose.com/words/cpp/converting-to-fixed-page-format/). |
| [RevisionOptions](./revisionoptions/) | Позволяет управлять тем, как обрабатываются ревизии документа во время процесса компоновки. Чтобы узнать больше, посетите статью документации [Converting to Fixed-page Format](https://docs.aspose.com/words/cpp/converting-to-fixed-page-format/). |

## Enums

| Перечисление | Описание |
| --- | --- |
| [CommentDisplayMode](./commentdisplaymode/) | Указывает режим отрисовки комментариев к документу. |
| [ContinuousSectionRestart](./continuoussectionrestart/) | Представляет различные поведения при вычислении номеров страниц в непрерывном разделе, который перезапускает нумерацию страниц. |
| [LayoutEntityType](./layoutentitytype/) | Типы сущностей компоновки. |
| [PageLayoutEvent](./pagelayoutevent/) | Код события, возникающего во время построения и отрисовки модели компоновки страниц. Модель компоновки страниц создаётся в два этапа. Сначала — "этап конверсии", когда компоновка извлекает содержимое документа и создает граф объектов. Затем — "этап перераспределения", когда структуры разбиваются, объединяются и размещаются по страницам. В зависимости от операции, инициировавшей построение, модель компоновки может быть либо не отрисована дальше в фиксированный формат страниц, либо отрисована. Например, вычисление количества страниц в документе или обновление полей не требует отрисовки, тогда как экспорт в PDF требует. |
| [RevisionColor](./revisioncolor/) | Позволяет задать цвет ревизий документа. |
| [RevisionTextEffect](./revisiontexteffect/) | Позволяет задать эффект декорирования для ревизий текста документа. |
| [ShowInBalloons](./showinballoons/) | Указывает, какие ревизии отображаются в виде баллонов. |
