Пространство имён **Aspose.Words.Bibliography** предоставляет классы, позволяющие получить доступ к списку библиографических источников, доступных в документе.

## Классы

| Класс | Описание |
| --- | --- |
| [Bibliography](./bibliography/) | Представляет список библиографических источников, доступных в документе. |
| [Contributor](./contributor/) | Представляет участника источника библиографии. Может быть как корпоративным (организацией), так и списком лиц. |
| [ContributorCollection](./contributorcollection/) | Представляет участников источника библиографии. |
| [Corporate](./corporate/) | Представляет корпоративного (организацию) участника источника библиографии. |
| [Person](./person/) | Представляет индивидуального (человека) участника источника библиографии. |
| [PersonCollection](./personcollection/) | Представляет список лиц, являющихся участниками источника библиографии. |
| [Source](./source/) | Представляет отдельный источник, такой как книга, статья в журнале или интервью. |
