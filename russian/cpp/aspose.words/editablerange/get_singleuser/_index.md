## EditableRange::get_SingleUser method


Возвращает или задает единственного пользователя для редактируемого диапазона.

```cpp
System::String Aspose::Words::EditableRange::get_SingleUser()
```

## Примечания


Этот редактор может быть сохранён в одной из следующих форм:

DOMAIN\Username — для пользователей, доступ которых будет аутентифицирован с использованием учётных данных домена текущего пользователя.

user@domain.com — для пользователей, доступ которых будет аутентифицирован с использованием адреса электронной почты пользователя в качестве учётных данных.

user — для пользователей, доступ которых будет аутентифицирован с использованием учётных данных машины текущего пользователя.

Единственный пользователь и группа редакторов не могут быть заданы одновременно для конкретного редактируемого диапазона; если один параметр установлен, другой будет сброшен.
