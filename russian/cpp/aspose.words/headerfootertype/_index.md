## HeaderFooterType enum


Определяет тип колонтитула, найденного в файле Word.

```cpp
enum class HeaderFooterType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| HeaderEven | 0 | Заголовок для чётных страниц. |
| HeaderPrimary | 1 | Основной заголовок, также используется для нечётных страниц. |
| FooterEven | 2 | Нижний колонтитул для чётных страниц. |
| FooterPrimary | 3 | Основной нижний колонтитул, также используется для нечётных страниц. |
| HeaderFirst | 4 | Заголовок для первой страницы раздела. |
| FooterFirst | 5 | Нижний колонтитул для первой страницы раздела. |
