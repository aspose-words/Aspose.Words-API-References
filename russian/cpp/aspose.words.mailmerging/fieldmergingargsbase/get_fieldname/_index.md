## FieldMergingArgsBase::get_FieldName method


Получает имя поля слияния в источнике данных.

```cpp
System::String Aspose::Words::MailMerging::FieldMergingArgsBase::get_FieldName() const
```

## Примечания


Если у вас есть сопоставление имени поля документа с другим именем поля в источнике данных, то это — сопоставленное имя поля.

Если вы указали префикс имени поля, например "Image:MyFieldName" в документе, то [FieldName](./) возвращает имя поля без префикса, то есть "MyFieldName".
