## MailMerge::DeleteFields method


Удаляет из документа поля, связанные со слиянием почты.

```cpp
void Aspose::Words::MailMerging::MailMerge::DeleteFields()
```

## Примечания


Этот метод удаляет поля MERGEFIELD и NEXT из документа.

Этот метод может быть полезен, если ваша операция слияния почты не всегда должна заполнять все поля в документе. Используйте этот метод, чтобы удалить все оставшиеся поля слияния почты.
