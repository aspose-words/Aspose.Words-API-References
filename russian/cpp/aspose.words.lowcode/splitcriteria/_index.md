## SplitCriteria enum


Указывает, как документ разбивается на части.

```cpp
enum class SplitCriteria
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Page | 0 | Указывает, что документ разбивается на страницы. |
| SectionBreak | 1 | Указывает, что документ разбивается на части при разрыве раздела любого типа. |
| Style | 2 | Указывает, что документ разбивается на части в абзаце, отформатированном с использованием стиля, указанного в [SplitStyle](../splitoptions/get_splitstyle/). |
