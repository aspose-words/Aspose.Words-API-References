Пространство имен **Aspose.Words.Replacing** предоставляет классы для работы с операциями поиска/замены в дереве документа.

## Классы

| Класс | Описание |
| --- | --- |
| [FindReplaceOptions](./findreplaceoptions/) | Указывает параметры операций поиска/замены. Чтобы узнать больше, посетите статью документации [Find and Replace](https://docs.aspose.com/words/cpp/find-and-replace/). |
| [ReplacingArgs](./replacingargs/) | Предоставляет данные для пользовательской операции замены. Чтобы узнать больше, посетите статью документации [Find and Replace](https://docs.aspose.com/words/cpp/find-and-replace/). |
## Интерфейсы

| Интерфейс | Описание |
