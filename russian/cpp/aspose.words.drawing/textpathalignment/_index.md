### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Растянуть | 0 | Растянуть каждую строку текста, чтобы она соответствовала ширине. |
| По центру | 1 | Центрировать текст по ширине. |
| Слева | 2 | Выровнять по левому краю. |
| Справа | 3 | Выровнять по правому краю. |
| LetterJustify | 4 | Распределить буквы, чтобы они соответствовали ширине. |
| WordJustify | 5 | Распределить слова, чтобы они соответствовали ширине. |
