## ArrowType enum


Указывает тип стрелки на конце линии.

```cpp
enum class ArrowType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | 0 | Линия не имеет стрелки на конце. |
| Стрелка | 1 | Стрелка представляет собой сплошной треугольник. |
| Stealth | 2 | Стрелка является стрелкой "stealth". |
| Diamond | 3 | Конец линии — сплошной ромб. |
| Oval | 4 | Конец линии — сплошное овальное. |
| Open | 5 | Стрелка — открытая стрелка. |
| Default | n/a | То же, что и [None](./). |
