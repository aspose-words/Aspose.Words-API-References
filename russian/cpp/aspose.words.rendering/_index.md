Пространство имен **Aspose.Words.Rendering** предоставляет классы, позволяющие настраивать печать или визуализацию документов.

## Классы

| Класс | Описание |
| --- | --- |
| [NodeRendererBase](./noderendererbase/) | Базовый класс для [ShapeRenderer](./shaperenderer/) и [OfficeMathRenderer](./officemathrenderer/). Чтобы узнать больше, посетите статью документации [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [OfficeMathRenderer](./officemathrenderer/) | Предоставляет методы для визуализации отдельного [OfficeMath](../aspose.words.math/officemath/) в растровое или векторное изображение или в объект Graphics. Чтобы узнать больше, посетите статью документации [Working with OfficeMath](https://docs.aspose.com/words/cpp/working-with-officemath/). |
| [PageInfo](./pageinfo/) | Представляет информацию о конкретной странице документа. Чтобы узнать больше, посетите статью документации [Rendering](https://docs.aspose.com/words/cpp/rendering/). |
| [ShapeRenderer](./shaperenderer/) | Предоставляет методы для визуализации отдельного [Shape](../aspose.words.drawing/shape/) или [GroupShape](../aspose.words.drawing/groupshape/) в растровое или векторное изображение или в объект Graphics. Чтобы узнать больше, посетите статью документации [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [ThumbnailGeneratingOptions](./thumbnailgeneratingoptions/) | Можно использовать для указания дополнительных параметров при создании миниатюры документа. |
