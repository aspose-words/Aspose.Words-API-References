Пространство имён **Aspose.Words.BuildingBlocks** предоставляет классы, позволяющие получать доступ и использовать автотекст, автокоррекцию и строительные блоки в документе.

## Классы

| Класс | Описание |
| --- | --- |
| [BuildingBlock](./buildingblock/) | Представляет элемент глоссарного документа, такой как строительный блок, автотекст или запись автокоррекции. Чтобы узнать больше, посетите статью документации [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [BuildingBlockCollection](./buildingblockcollection/) | Коллекция объектов [BuildingBlock](./buildingblock/) в документе. Чтобы узнать больше, посетите статью документации [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [GlossaryDocument](./glossarydocument/) | Представляет корневой элемент глоссарного документа внутри документа Word. Глоссарный документ служит хранилищем автотекста, записей автокоррекции и строительных блоков. Чтобы узнать больше, посетите статью документации [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
## Enums

| Перечисление | Описание |
| --- | --- |

| [BuildingBlockGallery](./buildingblockgallery/) | Указывает предопределённую галерею, в которую классифицируется строительный блок. |
