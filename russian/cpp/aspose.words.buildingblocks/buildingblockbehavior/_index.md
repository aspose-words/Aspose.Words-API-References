## BuildingBlockBehavior enum


Указывает поведение, которое будет применено к содержимому строительного блока при его вставке в основной документ.

```cpp
enum class BuildingBlockBehavior
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Content | 0 | Указывает, что строительный блок должен быть вставлен как встроенное содержимое. |
| Paragraph | 1 | Указывает, что строительный блок должен быть вставлен в собственный абзац. |
| Page | 2 | Указывает, что строительный блок должен быть добавлен на отдельную страницу. |
| Default | n/a | То же, что и [Content](./). |

## Примечания


Соответствует типу **ST_DocPartBehavior** в OOXML.
