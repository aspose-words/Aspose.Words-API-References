## BuildingBlockType enum


Указывает тип строительного блока. Тип может влиять на видимость и поведение строительного блока в Microsoft Word.

```cpp
enum class BuildingBlockType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | 0 | Для строительного блока не указана информация о типе. |
| AutomaticallyReplaceNameWithContent | 1 | Позволяет автоматически вставлять строительный блок в документ, когда его имя вводится в приложении. |
| StructuredDocumentTagPlaceholderText | 2 | Строительный блок — это текст-заполнитель структурированного тега документа. |
| FormFieldHelpText | 3 | Строительный блок — это справочный текст поля формы. |
| Обычный | 4 | Строительный блок — это обычная (т.е. регулярная) запись глоссария документа. |
| AutoCorrect | 5 | Строительный блок связан с инструментами проверки орфографии и грамматики. |
| AutoText | 6 | Строительный блок — это запись AutoText. |
| Все | 7 | Строительный блок связан со всеми типами. |
| Default | n/a | Сохранить как [None](./). |

## Примечания


Соответствует типу **ST_DocPartType** в OOXML.
