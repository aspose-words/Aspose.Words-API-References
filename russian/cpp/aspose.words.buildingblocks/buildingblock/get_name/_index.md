## BuildingBlock::get_Name method


Получает или задает имя этого строительного блока.

```cpp
System::String Aspose::Words::BuildingBlocks::BuildingBlock::get_Name() const
```

## Примечания


Имя может содержать любой строковый контент, обычно это удобочитаемый идентификатор. Несколько строительных блоков могут иметь одинаковое имя.

Не может быть **null** и не может быть пустой строкой.

Соответствует элементу **docPartPr.name** в OOXML.
