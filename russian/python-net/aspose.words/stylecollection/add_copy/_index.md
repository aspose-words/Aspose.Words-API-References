## add_copy(style) {#style}

Copies a style into this collection.


```python
def add_copy(self, style: aspose.words.Style):
    ...
```

| Parameter | Type | Description |
| --- | --- | --- |
| style | [Style](../../style/) | Style to be copied. |

### Remarks

Style to be copied can belong to the same document as well as to different document.

Linked style is copied.

This method does doesn't copy base styles.

If collection already contains a style with the same name, then new name is
automatically generated by adding "_number" suffix starting from 0 e.g. "Normal_0", "Heading 1_1" etc.
Use [Style.name](../../style/name/) setter for changing the name of the imported style.




### Returns

Copied style ready for usage.


### Examples

Shows how to clone a document's style.

```python
doc = aw.Document()
# Метод AddCopy создаёт копию указанного стиля и
# автоматически генерирует новое имя для стиля, например "Heading 1_0".
new_style = doc.styles.add_copy(doc.styles.get_by_name('Heading 1'))
# Используйте свойство "Name" стиля, чтобы изменить его идентифицирующее имя.
new_style.name = 'My Heading 1'
# Теперь наш документ содержит два визуально одинаковых стиля с разными именами.
# Изменение настроек одного из стилей не влияет на другой.
new_style.font.color = aspose.pydrawing.Color.red
self.assertEqual('My Heading 1', new_style.name)
self.assertEqual('Heading 1', doc.styles.get_by_name('Heading 1').name)
self.assertEqual(doc.styles.get_by_name('Heading 1').type, new_style.type)
self.assertEqual(doc.styles.get_by_name('Heading 1').font.name, new_style.font.name)
self.assertEqual(doc.styles.get_by_name('Heading 1').font.size, new_style.font.size)
self.assertNotEqual(doc.styles.get_by_name('Heading 1').font.color, new_style.font.color)
```

Shows how to import a style from one document into a different document.

```python
src_doc = aw.Document()
# Создайте пользовательский стиль для исходного документа.
src_style = src_doc.styles.add(aw.StyleType.PARAGRAPH, 'MyStyle')
src_style.font.color = aspose.pydrawing.Color.red
# Импортируйте пользовательский стиль исходного документа в целевой документ.
dst_doc = aw.Document()
new_style = dst_doc.styles.add_copy(src_style)
# Импортированный стиль имеет внешний вид, идентичный исходному стилю.
self.assertEqual('MyStyle', new_style.name)
self.assertEqual(aspose.pydrawing.Color.red.to_argb(), new_style.font.color.to_argb())
```
