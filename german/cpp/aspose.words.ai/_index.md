Der **Aspose.Words.AI**-Namensraum ermöglicht nahtlose Integration mit großen Sprachmodellen (LLMs) wie OpenAI und Gemini und bietet robuste Unterstützung für KI‑gestützte Dokumentenverarbeitung.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AiModel](./aimodel/) | Eine abstrakte Klasse, die die Integration mit verschiedenen [AI](./)-Modellen innerhalb von [Aspose.Words](../aspose.words/) darstellt. |
| [AnthropicAiModel](./anthropicaimodel/) | Eine abstrakte Klasse, die die Integration mit Anthropic‑[AI](./)-Modellen innerhalb von [Aspose.Words](../aspose.words/) darstellt. |
| [CheckGrammarOptions](./checkgrammaroptions/) | Ermöglicht das Festlegen verschiedener Optionen beim Grammatik‑Check eines Dokuments mithilfe von [AI](./). |
| [GoogleAiModel](./googleaimodel/) | Klasse, die die Integration von Google‑[AI](./)-Modellen (Gemini) innerhalb von [Aspose.Words](../aspose.words/) darstellt. |
| [OpenAiModel](./openaimodel/) | Klasse, die die Integration von OpenAi‑Modellen innerhalb von [Aspose.Words](../aspose.words/) darstellt. |
| [SummarizeOptions](./summarizeoptions/) | Ermöglicht das Festlegen verschiedener Optionen zum Zusammenfassen von Dokumentinhalten. |
