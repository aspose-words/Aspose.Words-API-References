Der **Aspose.Words.Replacing** Namespace stellt Klassen zur Verfügung, um Find/Ersetzen‑Operationen im Dokumentenbaum zu manipulieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FindReplaceOptions](./findreplaceoptions/) | Gibt Optionen für Suchen/Ersetzen-Operationen an. Weitere Informationen finden Sie im [Find and Replace](https://docs.aspose.com/words/cpp/find-and-replace/) Dokumentationsartikel. |
| [ReplacingArgs](./replacingargs/) | Stellt Daten für eine benutzerdefinierte Ersetzen-Operation bereit. Weitere Informationen finden Sie im [Find and Replace](https://docs.aspose.com/words/cpp/find-and-replace/) Dokumentationsartikel. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IReplacingCallback](./ireplacingcallback/) | Implementieren Sie dieses Interface, wenn Sie Ihre eigene benutzerdefinierte Methode während einer Suchen‑Ersetzen‑Operation aufrufen möchten. |
## Enums

| Enum | Beschreibung |
| --- | --- |
| [FindReplaceDirection](./findreplacedirection/) | Gibt die Richtung für Ersetzen-Operationen an. |
