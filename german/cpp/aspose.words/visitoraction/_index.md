## VisitorAction enum


Ermöglicht dem Besucher die Steuerung der Aufzählung von Knoten.

```cpp
enum class VisitorAction
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Weiter | 0 | Der Besucher fordert, dass die Aufzählung fortgesetzt wird. |
| SkipThisNode | 1 | Der Besucher fordert, den aktuellen Knoten zu überspringen und die Aufzählung fortzusetzen. |
| Stopp | 2 | Der Besucher fordert die Aufzählung der Knoten zum Stoppen an. |
