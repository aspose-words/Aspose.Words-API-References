## HeaderFooterType enum


Identifiziert den Typ von Kopf- oder Fußzeile, die in einer Word-Datei gefunden wird.

```cpp
enum class HeaderFooterType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| HeaderEven | 0 | Kopfzeile für gerade Seiten. |
| HeaderPrimary | 1 | Primäre Kopfzeile, die auch für ungerade Seiten verwendet wird. |
| FooterEven | 2 | Fußzeile für gerade Seiten. |
| FooterPrimary | 3 | Primäre Fußzeile, die auch für ungerade Seiten verwendet wird. |
| HeaderFirst | 4 | Kopfzeile für die erste Seite des Abschnitts. |
| FooterFirst | 5 | Fußzeile für die erste Seite des Abschnitts. |
