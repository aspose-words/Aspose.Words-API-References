Der **Aspose.Words.Rendering** Namespace stellt Klassen bereit, die es ermöglichen, das Drucken oder Rendern von Dokumenten anzupassen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [NodeRendererBase](./noderendererbase/) | Basisklasse für [ShapeRenderer](./shaperenderer/) und [OfficeMathRenderer](./officemathrenderer/). Weitere Informationen finden Sie im Dokumentationsartikel [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [OfficeMathRenderer](./officemathrenderer/) | Stellt Methoden bereit, um ein einzelnes [OfficeMath](../aspose.words.math/officemath/) in ein Raster- oder Vektorbild oder in ein Graphics-Objekt zu rendern. Weitere Informationen finden Sie im Dokumentationsartikel [Working with OfficeMath](https://docs.aspose.com/words/cpp/working-with-officemath/). |
| [PageInfo](./pageinfo/) | Stellt Informationen über eine bestimmte Dokumentseite dar. Weitere Informationen finden Sie im Dokumentationsartikel [Rendering](https://docs.aspose.com/words/cpp/rendering/). |
| [ShapeRenderer](./shaperenderer/) | Stellt Methoden bereit, um ein einzelnes [Shape](../aspose.words.drawing/shape/) oder [GroupShape](../aspose.words.drawing/groupshape/) in ein Raster- oder Vektorbild oder in ein Graphics-Objekt zu rendern. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [ThumbnailGeneratingOptions](./thumbnailgeneratingoptions/) | Kann verwendet werden, um zusätzliche Optionen beim Erzeugen einer Miniaturansicht für ein Dokument anzugeben. |
