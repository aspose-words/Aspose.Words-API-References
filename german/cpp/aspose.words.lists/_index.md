Der **Aspose.Words.Lists**-Namensraum enthält Klassen zur Arbeit mit Aufzählungs‑ und Nummerierungslisten, die in einem Dokument definiert sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [List](./list/) | Stellt die Formatierung einer Liste dar. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListCollection](./listcollection/) | Speichert und verwaltet die Formatierung von Aufzählungs‑ und nummerierten Listen, die in einem Dokument verwendet werden. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListFormat](./listformat/) | Ermöglicht die Steuerung, welche Listenformatierung auf einen Absatz angewendet wird. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLabel](./listlabel/) | Definiert Eigenschaften, die spezifisch für ein Listenelement sind. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevel](./listlevel/) | Definiert die Formatierung für eine Listenebene. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevelCollection](./listlevelcollection/) | Eine Sammlung von Listformatierungen für jede Ebene einer Liste. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
## Enums

| Enum | Beschreibung |
| --- | --- |
| [ListLevelAlignment](./listlevelalignment/) | Gibt die Ausrichtung für die Listennummer oder das Aufzählungszeichen an. |
| [ListTemplate](./listtemplate/) | Gibt eines der vordefinierten Listformate an, die in Microsoft Word verfügbar sind. |
| [ListTrailingCharacter](./listtrailingcharacter/) | Gibt das Zeichen an, das das Listenelement vom Text des Absatzes trennt. |
