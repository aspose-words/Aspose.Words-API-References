## ChartXValueType enum


Ermöglicht die Angabe des Typs eines X‑Werts einer Diagrammreihe.


### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| String | 0 | Gibt an, dass ein X‑Wert eine Zeichenkettenkategorie ist. |
| Double | 1 | Gibt an, dass ein X‑Wert eine doppelt‑genaue Gleitkommazahl ist. |
| DateTime | 2 | Gibt an, dass ein X‑Wert ein Datum und eine Uhrzeit ist. |
| Zeit | 3 | Gibt an, dass ein X‑Wert eine Uhrzeit ist. |
| Mehrstufig | 4 | Gibt an, dass ein X‑Wert ein mehrstufiger Wert ist. |
