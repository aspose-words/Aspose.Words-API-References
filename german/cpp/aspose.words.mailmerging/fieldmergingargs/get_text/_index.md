## FieldMergingArgs::get_Text method


Ermittelt oder setzt den Text, der in das Dokument für das aktuelle Seriendruckfeld eingefügt wird.

```cpp
System::String Aspose::Words::MailMerging::FieldMergingArgs::get_Text() const
```

## Hinweise


Wenn Ihr Ereignishandler aufgerufen wird, wird diese Eigenschaft auf **null** gesetzt.

Wenn Sie Text als **null** belassen, fügt die Seriendruck-Engine [FieldValue](../../fieldmergingargsbase/get_fieldvalue/) anstelle des Seriendruckfelds ein.

Wenn Sie Text auf eine beliebige Zeichenfolge (einschließlich leer) setzen, wird die Zeichenfolge anstelle des Seriendruckfelds in das Dokument eingefügt.
