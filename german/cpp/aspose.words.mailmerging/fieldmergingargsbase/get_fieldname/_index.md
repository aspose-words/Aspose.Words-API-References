## FieldMergingArgsBase::get_FieldName method


Ermittelt den Namen des Seriendruckfeldes in der Datenquelle.

```cpp
System::String Aspose::Words::MailMerging::FieldMergingArgsBase::get_FieldName() const
```

## Hinweise


Wenn Sie eine Zuordnung von einem Dokumentfeldnamen zu einem anderen Datenquellenfeldnamen haben, dann ist dies der zugeordnete Feldname.

Wenn Sie ein Feldnamenspräfix angegeben haben, zum Beispiel \"Image:MyFieldName\" im Dokument, dann gibt [FieldName](./) den Feldnamen ohne das Präfix zurück, also \"MyFieldName\".
