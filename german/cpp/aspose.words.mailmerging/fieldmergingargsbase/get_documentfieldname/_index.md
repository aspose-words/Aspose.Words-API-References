## FieldMergingArgsBase::get_DocumentFieldName method


Ermittelt den Namen des Seriendruckfeldes, wie im Dokument angegeben.

```cpp
System::String Aspose::Words::MailMerging::FieldMergingArgsBase::get_DocumentFieldName() const
```

## Hinweise


Wenn Sie eine Zuordnung von einem Dokumentfeldnamen zu einem anderen Datenquellenfeldnamen haben, dann ist dies der ursprüngliche Feldname, wie im Dokument angegeben.

Wenn Sie ein Feldnamenspräfix angegeben haben, zum Beispiel \"Image:MyFieldName\" im Dokument, dann gibt [DocumentFieldName](./) den Feldnamen ohne das Präfix zurück, also \"MyFieldName\".
