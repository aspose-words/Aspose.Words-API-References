Der **Aspose.Words.MailMerging**-Namensraum enthält Klassen der „originalen“ Seriendruck‑Reporting‑Engine.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FieldMergingArgs](./fieldmergingargs/) | Stellt Daten für das **MergeField**-Ereignis bereit. Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [FieldMergingArgsBase](./fieldmergingargsbase/) | Basisklasse für [FieldMergingArgs](./fieldmergingargs/) und [ImageFieldMergingArgs](./imagefieldmergingargs/). Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [ImageFieldMergingArgs](./imagefieldmergingargs/) | Stellt Daten für das [ImageFieldMerging()](./ifieldmergingcallback/imagefieldmerging/) Ereignis bereit. Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [MailMerge](./mailmerge/) | Stellt die Seriendruck-Funktionalität dar. Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [MailMergeRegionInfo](./mailmergeregioninfo/) | Enthält Informationen über einen Seriendruckbereich. Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [MappedDataFieldCollection](./mappeddatafieldcollection/) | Ermöglicht das automatische Zuordnen zwischen Feldnamen in Ihrer Datenquelle und den Namen der Seriendruckfelder im Dokument. Weitere Informationen finden Sie im Dokumentationsartikel [Mail Merge and Reporting](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [MustacheTag](./mustachetag/) | Stellt ein "mustache"-Tag dar. |
## Schnittstellen

| Schnittstelle | Beschreibung |
