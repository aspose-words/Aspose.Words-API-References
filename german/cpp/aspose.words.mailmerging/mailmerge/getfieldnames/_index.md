## MailMerge::GetFieldNames method


Gibt eine Sammlung von Seriendruckfeldnamen zurück, die im Dokument verfügbar sind.

```cpp
System::ArrayPtr<System::String> Aspose::Words::MailMerging::MailMerge::GetFieldNames()
```

## Hinweise


Gibt vollständige Merge‑Feldnamen einschließlich optionalem Präfix zurück. Entfernt keine doppelten Feldnamen.

Bei jedem Aufruf wird ein neues String‑Array erstellt.

Enthält \"mustache\"-Feldnamen, wenn [UseNonMergeFields](../get_usenonmergefields/) **true** ist.
