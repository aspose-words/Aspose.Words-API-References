## Hinweise


Der Wert dieser Eigenschaft stammt zunächst aus dem Code des entsprechenden MERGEFIELD, der im Vorlagendokument enthalten ist. Um den Anfangswert zu überschreiben, sollten Sie dieser Eigenschaft eine Instanz der Klasse [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) zuweisen oder die Eigenschaften der von dieser Eigenschaft zurückgegebenen Instanz der Klasse [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) festlegen.

Um anzuzeigen, dass der ursprüngliche Wert der Bildbreite angewendet werden soll, sollten Sie dieser Eigenschaft den **null**-Wert zuweisen oder die [Value](../../../aspose.words.fields/mergefieldimagedimension/get_value/)‑Eigenschaft für die Instanz der Klasse [MergeFieldImageDimension](../../../aspose.words.fields/mergefieldimagedimension/) auf einen negativen Wert setzen, die von dieser Eigenschaft zurückgegeben wird.
