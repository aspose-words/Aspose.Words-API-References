## SplitCriteria enum


Gibt an, wie das Dokument in Teile aufgeteilt wird.

```cpp
enum class SplitCriteria
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Page | 0 | Gibt an, dass das Dokument in Seiten aufgeteilt wird. |
| SectionBreak | 1 | Gibt an, dass das Dokument an einem Abschnittswechsel beliebigen Typs in Teile aufgeteilt wird. |
| Style | 2 | Gibt an, dass das Dokument an einem Absatz, der mit dem in [SplitStyle](../splitoptions/get_splitstyle/) angegebenen Stil formatiert ist, in Teile aufgeteilt wird. |
