## MergeFormatMode enum


Gibt an, wie Formatierungen beim Kombinieren mehrerer Dokumente zusammengeführt werden.

```cpp
enum class MergeFormatMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| MergeFormatting | 0 | Kombiniert die Formatierung der zusammengeführten Dokumente. |
| KeepSourceFormatting | 1 | Bedeutet, dass das Quelldokument seine ursprüngliche Formatierung beibehält, wie Schriftarten, -größen, -farben, Einzüge und alle anderen auf den Inhalt angewendeten Formatierungselemente. |
| KeepSourceLayout | 2 | Erhalte das Layout der Originaldokumente im endgültigen Dokument. |
