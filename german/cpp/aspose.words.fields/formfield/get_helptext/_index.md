## FormField::get_HelpText method


Liest oder setzt den Text, der in einer Meldungsbox angezeigt wird, wenn das Formularfeld den Fokus hat und der Benutzer F1 drückt.

```cpp
System::String Aspose::Words::Fields::FormField::get_HelpText()
```

## Hinweise


Wenn die [OwnHelp](../get_ownhelp/) Eigenschaft auf **true** gesetzt ist, gibt [HelpText](./) den Textzeichenfolgenwert an. Wenn [OwnHelp](../get_ownhelp/) auf **false** gesetzt ist, gibt [HelpText](./) den Namen eines AutoText-Eintrags an, der Hilfetext für das Formularfeld enthält.

Microsoft Word erlaubt Zeichenfolgen mit höchstens 255 Zeichen.
