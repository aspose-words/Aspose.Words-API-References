## FormField::get_OwnHelp method


Gibt die Quelle des Textes an, der in einer Meldungsbox angezeigt wird, wenn ein Formularfeld den Fokus hat und der Benutzer F1 drückt.

```cpp
bool Aspose::Words::Fields::FormField::get_OwnHelp()
```

## Hinweise


Wenn **true**, wird der durch die [HelpText](../get_helptext/) Eigenschaft angegebene Text angezeigt. Wenn **false**, wird der Text im AutoText-Eintrag angezeigt, der durch die [HelpText](../get_helptext/) Eigenschaft angegeben ist.
