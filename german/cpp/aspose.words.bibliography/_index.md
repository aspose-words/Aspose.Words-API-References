Der **Aspose.Words.Bibliography**-Namensraum stellt Klassen bereit, die den Zugriff auf eine Liste von Bibliografien, die in einem Dokument verfügbar sind, ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Bibliography](./bibliography/) | Stellt die Liste der im Dokument verfügbaren Bibliographie‑Quellen dar. |
| [Contributor](./contributor/) | Stellt einen Bibliographie‑Quellen‑Beitragenden dar. Kann entweder ein Unternehmen (eine Organisation) oder eine Liste von Personen sein. |
| [ContributorCollection](./contributorcollection/) | Stellt Bibliographie‑Quellen‑Beitragende dar. |
| [Corporate](./corporate/) | Stellt einen Unternehmens‑ (eine Organisation) Bibliographie‑Quellen‑Beitragenden dar. |
| [Person](./person/) | Stellt einen individuellen (eine Person) Bibliographie‑Quellen‑Beitragenden dar. |
| [PersonCollection](./personcollection/) | Stellt eine Liste von Personen dar, die Bibliographie‑Quellen‑Beitragende sind. |
| [Source](./source/) | Stellt eine einzelne Quelle dar, wie ein Buch, einen Zeitschriftenartikel oder ein Interview. |
## Enums

| Enum | Beschreibung |
| --- | --- |
| [SourceType](./sourcetype/) | Stellt Bibliographie‑Quellen‑Typen dar. |
