Der **Aspose.Words.Themes** Namespace stellt Klassen bereit, die den Zugriff auf Themeninformationen in Microsoft‑Word‑Dokumenten ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Theme](./theme/) | Stellt das Dokument [Theme](./theme/) dar und bietet Zugriff auf die Hauptteile des Themas, einschließlich [MajorFonts](./theme/get_majorfonts/), [MinorFonts](./theme/get_minorfonts/) und [Colors](./theme/get_colors/). Weitere Informationen finden Sie im Dokumentationsartikel [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeColors](./themecolors/) | Stellt das Farbschema des Dokumentthemas dar, das zwölf Farben enthält. Das Objekt [ThemeColors](./themecolors/) enthält sechs Akzentfarben, zwei dunkle Farben, zwei helle Farben und eine Farbe für jeden Hyperlink und besuchten Hyperlink. |
| [ThemeFonts](./themefonts/) | Stellt eine Sammlung von Schriftarten im Schriftschema dar, die es ermöglicht, verschiedene Schriftarten für verschiedene Sprachen anzugeben: [Latin](./themefonts/get_latin/), [EastAsian](./themefonts/get_eastasian/) und [ComplexScript](./themefonts/get_complexscript/). Weitere Informationen finden Sie im Dokumentationsartikel [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
## Enums

| Enum | Beschreibung |
| --- | --- |
| [ThemeColor](./themecolor/) | Gibt die Themenfarben für Dokumentthemen an. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Styles and Themes](https://docs.aspose.com/words/cpp/working-with-styles-and-themes/). |
| [ThemeFont](./themefont/) | Gibt die Typen von Themen-Schriftartnamen für Dokumentthemen an. |
