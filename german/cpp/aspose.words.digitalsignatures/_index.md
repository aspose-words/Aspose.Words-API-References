Der **Aspose.Words.DigitalSignatures**-Namensraum stellt Klassen zum Signieren von Dokumenten und zur Überprüfung von Signaturen bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CertificateHolder](./certificateholder/) | Stellt einen Halter einer **X509Certificate2**-Instanz dar. Weitere Informationen finden Sie im [Work with Digital Signatures](https://docs.aspose.com/words/cpp/working-with-digital-signatures/) Dokumentationsartikel. |
| [DigitalSignature](./digitalsignature/) | Stellt eine digitale Signatur in einem Dokument und das Ergebnis ihrer Verifizierung dar. Weitere Informationen finden Sie im [Work with Digital Signatures](https://docs.aspose.com/words/cpp/working-with-digital-signatures/) Dokumentationsartikel. |
| [DigitalSignatureCollection](./digitalsignaturecollection/) | Stellt eine schreibgeschützte Sammlung digitaler Signaturen bereit, die an ein Dokument angehängt sind. Weitere Informationen finden Sie im [Work with Digital Signatures](https://docs.aspose.com/words/cpp/working-with-digital-signatures/) Dokumentationsartikel. |
| [DigitalSignatureUtil](./digitalsignatureutil/) | Stellt Methoden zum Signieren von Dokumenten bereit. Weitere Informationen finden Sie im [Work with Digital Signatures](https://docs.aspose.com/words/cpp/working-with-digital-signatures/) Dokumentationsartikel. |
| [SignOptions](./signoptions/) | Ermöglicht das Festlegen von Optionen für das Signieren von Dokumenten. Weitere Informationen finden Sie im [Work with Digital Signatures](https://docs.aspose.com/words/cpp/working-with-digital-signatures/) Dokumentationsartikel. |
