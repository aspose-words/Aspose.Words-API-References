## MailMergeSettings::get_LinkToQuery method


Nicht sicher bei diesem. Die Microsoft Word Automation Reference legt nahe, dass dies angibt, dass die Abfrage jedes Mal ausgeführt wird, wenn das Dokument in Microsoft Word geöffnet wird. Aber die OOXML-Spezifikation legt nahe, dass dies angibt, dass die Abfrage einen Verweis auf eine externe Abfragedatei enthält, die die eigentliche Abfrage enthält. Der Standardwert ist **false**.
