## MailMergeDestination enum


Gibt die möglichen Ergebnisse an, die beim Durchführen eines Seriendrucks auf einem Dokument erzeugt werden können.

```cpp
enum class MailMergeDestination
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| NewDocument | 0 | Gibt an, dass konforme Host-Anwendungen neue Dokumente erzeugen, indem sie die Felder in einem gegebenen Dokument mit Daten aus der angegebenen externen Datenquelle füllen. |
| Printer | 1 | Gibt an, dass konforme Host-Anwendungen die Dokumente drucken, die durch das Befüllen der Felder in einem gegebenen Dokument mit externen Daten aus der angegebenen externen Datenquelle entstehen. |
| Email | 2 | Gibt an, dass konforme Host-Anwendungen E-Mails erzeugen, indem sie die Dokumente verwenden, die durch das Befüllen der Felder in einem gegebenen Dokument mit Daten aus der angegebenen externen Datenquelle entstehen. |
| Fax | 4 | Gibt an, dass konforme Host-Anwendungen Faxe erzeugen, indem sie die Dokumente verwenden, die durch das Befüllen der Felder in einem gegebenen Dokument mit Daten aus der angegebenen externen Datenquelle entstehen. |
| Default | n/a | Entspricht dem Wert [NewDocument](./). |
