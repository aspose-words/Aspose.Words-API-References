Der **Aspose.Words.Notes**-Namensraum stellt Klassen zur Arbeit mit Endnoten und Fußnoten in Microsoft Word bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EndnoteOptions](./endnoteoptions/) | Stellt die Nummerierungsoptionen für Endnoten in einem Dokument oder Abschnitt dar. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [Footnote](./footnote/) | Stellt einen Container für den Text einer Fußnote oder Endnote dar. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteOptions](./footnoteoptions/) | Stellt die Nummerierungsoptionen für Fußnoten in einem Dokument oder Abschnitt dar. Weitere Informationen finden Sie im Dokumentationsartikel [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteSeparator](./footnoteseparator/) | Stellt einen Container für den Fußnoten/Endnoten‑Trenner und den Fortsetzungsinhalt eines Dokuments dar. |
| [FootnoteSeparatorCollection](./footnoteseparatorcollection/) | Bietet typisierten Zugriff auf die Knoten [FootnoteSeparator](./footnoteseparator/) eines Dokuments. |
