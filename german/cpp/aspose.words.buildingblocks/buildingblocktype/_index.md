## BuildingBlockType enum


Gibt einen Building Block-Typ an. Der Typ kann die Sichtbarkeit und das Verhalten des Building Blocks in Microsoft Word beeinflussen.

```cpp
enum class BuildingBlockType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Keine | 0 | Für den Baustein ist keine Typinformation angegeben. |
| AutomaticallyReplaceNameWithContent | 1 | Ermöglicht, dass der Baustein automatisch in das Dokument eingefügt wird, sobald sein Name in einer Anwendung eingegeben wird. |
| StructuredDocumentTagPlaceholderText | 2 | Der Baustein ist ein Platzhaltertext für ein strukturiertes Dokument-Tag. |
| FormFieldHelpText | 3 | Der Baustein ist ein Hilfetext für ein Formularfeld. |
| Normal | 4 | Der Baustein ist ein normaler (d. h. regulärer) Glossareintrag. |
| AutoCorrect | 5 | Der Baustein ist mit den Rechtschreib- und Grammatikwerkzeugen verknüpft. |
| AutoText | 6 | Der Baustein ist ein AutoText-Eintrag. |
| Alle | 7 | Der Baustein ist mit allen Typen verknüpft. |
| Default | n/a | Speichern als [None](./). |
