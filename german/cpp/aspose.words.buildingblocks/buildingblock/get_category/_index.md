## Hinweise


Bausteine in der Benutzeroberfläche von Microsoft Word sind in Galerien angeordnet. Jede [Galerie](../get_gallery/) kann mehrere Kategorien enthalten. Jeder Block innerhalb einer [Kategorie](./) hat einen [Name](../get_name/).

Darf nicht **null** sein und darf kein leerer String sein.

Entspricht dem **docPartPr.category.name** Element in OOXML.
