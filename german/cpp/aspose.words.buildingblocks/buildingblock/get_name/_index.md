## Hinweise


Der Name kann beliebigen Zeicheninhalt enthalten, normalerweise einen benutzerfreundlichen Bezeichner. Mehrere Bausteine können denselben Namen haben.

Darf nicht **null** sein und darf kein leerer String sein.

Entspricht dem **docPartPr.name** Element in OOXML.
