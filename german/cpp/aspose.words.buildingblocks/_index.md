Der **Aspose.Words.BuildingBlocks**-Namensraum stellt Klassen bereit, die den Zugriff auf und die Verwendung von AutoText, AutoCorrect‑Einträgen und Bausteinen in einem Dokument ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BuildingBlock](./buildingblock/) | Stellt einen Glossareintragsdokumenteintrag wie einen Building Block, AutoText oder einen AutoCorrect-Eintrag dar. Weitere Informationen finden Sie im Dokumentationsartikel [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [BuildingBlockCollection](./buildingblockcollection/) | Eine Sammlung von [BuildingBlock](./buildingblock/) Objekten im Dokument. Weitere Informationen finden Sie im Dokumentationsartikel [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [GlossaryDocument](./glossarydocument/) | Stellt das Wurzelelement für ein Glossardokument innerhalb eines Word-Dokuments dar. Ein Glossardokument ist ein Speicher für AutoText, AutoCorrect-Einträge und Building Blocks. Weitere Informationen finden Sie im Dokumentationsartikel [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
## Enums

| Enum | Beschreibung |
| --- | --- |
| [BuildingBlockBehavior](./buildingblockbehavior/) | Gibt das Verhalten an, das auf den Inhalt des Building Blocks angewendet werden soll, wenn er in das Hauptdokument eingefügt wird. |
| [BuildingBlockGallery](./buildingblockgallery/) | Gibt die vordefinierte Galerie an, in die ein Building Block klassifiziert wird. |
| [BuildingBlockType](./buildingblocktype/) | Gibt einen Building Block-Typ an. Der Typ kann die Sichtbarkeit und das Verhalten des Building Blocks in Microsoft Word beeinflussen. |
