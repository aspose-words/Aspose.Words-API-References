## MetafileRenderingOptions::get_EmulateRenderingToSizeOnPageResolution method


Liest oder legt die Auflösung in Pixel pro Zoll für die Emulation des Metafile-Renderings zur Größe auf der Seite fest.

```cpp
int32_t Aspose::Words::Saving::MetafileRenderingOptions::get_EmulateRenderingToSizeOnPageResolution() const
```

## Hinweise


Diese Option wird nur verwendet, wenn [EmulateRenderingToSizeOnPage](../get_emulaterenderingtosizeonpage/) auf **true** gesetzt ist.

Der Standardwert ist 96. Dies ist eine Standardanzeigeauflösung. Das heißt, das Metadatei-Rendering wird die Anzeige der Metadatei in MS Word mit einem Zoomfaktor von 100 % emulieren.
