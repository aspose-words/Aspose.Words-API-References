## CssSavingArgs::set_IsExportNeeded method


Ermöglicht das Angeben, ob das CSS in eine Datei exportiert und in das HTML-Dokument eingebettet wird. Standardwert ist **true**. Wenn diese Eigenschaft **false** ist, werden die CSS-Informationen nicht in einer CSS-Datei gespeichert und nicht in das HTML-Dokument eingebettet.
