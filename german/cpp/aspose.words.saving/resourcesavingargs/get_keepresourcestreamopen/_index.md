## ResourceSavingArgs::get_KeepResourceStreamOpen method


Gibt an, ob Aspose.Words den Stream offen halten oder nach dem Speichern einer Ressource schließen soll.

```cpp
bool Aspose::Words::Saving::ResourceSavingArgs::get_KeepResourceStreamOpen() const
```

## Hinweise


Standard ist **false** und Aspose.Words schließt den von Ihnen im Feld [ResourceStream](../get_resourcestream/) bereitgestellten Stream, nachdem eine Ressource darin geschrieben wurde. Geben Sie **true** an, um den Stream offen zu halten.
