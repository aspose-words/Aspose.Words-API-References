## DmlEffectsRenderingMode enum


Gibt an, wie DrawingML‑Effekte in feste Seitenformate gerendert werden.

```cpp
enum class DmlEffectsRenderingMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Simplified | 0 | [Rendering](../../aspose.words.rendering/) von DrawingML‑Effekten ist vereinfacht. |
| Keine | 1 | Keine DrawingML‑Effekte werden gerendert. |
| Fine | 2 | DrawingML-Effekte werden im Feinkmodus gerendert, der eine erweiterte Verarbeitung beinhaltet. In diesem Modus liefert das Rendern von Effekten bessere Ergebnisse, jedoch zu höheren Leistungskosten als der [Simplified](./)-Modus. |
