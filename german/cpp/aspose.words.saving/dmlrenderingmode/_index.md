## DmlRenderingMode enum


Gibt an, wie DrawingML‑Formen in feste Seitenformate gerendert werden.

```cpp
enum class DmlRenderingMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Fallback | 0 | Wenn für DrawingML ein Ersatz‑Shape verfügbar ist, rendert Aspose.Words das Ersatz‑Shape anstelle des DrawingML. |
| DrawingML | 1 | Aspose.Words ignoriert das Ersatz‑Shape von DrawingML und rendert das DrawingML selbst. Dies ist der Standardmodus. |
