## CssStyleSheetType enum


Gibt an, wie CSS (Cascading [Style](../../aspose.words/style/) Sheet)-Stile nach HTML exportiert werden.

```cpp
enum class CssStyleSheetType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Inline | 0 | CSS-Stile werden inline geschrieben (als Wert des **style**-Attributs jedes Elements). |
| Eingebettet | 1 | CSS-Stile werden getrennt vom Inhalt in einem im HTML-Dokument eingebetteten Stylesheet geschrieben. |
| Extern | 2 | CSS-Stile werden getrennt vom Inhalt in einem Stylesheet in einer externen Datei geschrieben. Die HTML-Datei verlinkt das Stylesheet. |
