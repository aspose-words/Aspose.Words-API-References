## TiffCompression enum


Gibt an, welchen Kompressionstyp man beim Speichern von Seitenbildern in einer TIFF-Datei anwenden soll.

```cpp
enum class TiffCompression
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Keine | 0 | Gibt an, dass keine Kompression verwendet wird. |
| Rle | 1 | Gibt das RLE-Kompressionsverfahren an. |
| Lzw | 2 | Gibt das LZW-Kompressionsverfahren an. In Java wird es durch Deflate (Zip)-Kompression emuliert. |
| Ccitt3 | 3 | Gibt das CCITT3-Kompressionsverfahren an. |
| Ccitt4 | 4 | Gibt das CCITT4-Komprimierungsschema an. |
