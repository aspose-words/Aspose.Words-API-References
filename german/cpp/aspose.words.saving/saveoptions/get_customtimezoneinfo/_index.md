## SaveOptions::get_CustomTimeZoneInfo method


Liest oder setzt die benutzerdefinierte lokale Zeitzone, die für Datums-/Uhrzeitfelder verwendet wird.

```cpp
System::SharedPtr<System::TimeZoneInfo> Aspose::Words::Saving::SaveOptions::get_CustomTimeZoneInfo() const
```

## Hinweise


Diese Option ist sowohl im .Net Framework ab Version 3.5 als auch im .Net Standard verfügbar.

Standardmäßig verwendet Aspose.Words die lokale Systemzeitzone beim Schreiben von Datums-/Uhrzeitfeldern; diese Option ermöglicht das Festlegen eines benutzerdefinierten Werts.
