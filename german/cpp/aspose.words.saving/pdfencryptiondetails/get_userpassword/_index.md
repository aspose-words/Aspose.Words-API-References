## PdfEncryptionDetails::get_UserPassword method


Gibt das Benutzerpasswort an, das zum Öffnen des verschlüsselten PDF-Dokuments erforderlich ist.

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_UserPassword() const
```

## Hinweise


Das Benutzerpasswort wird zum Öffnen eines verschlüsselten PDF-Dokuments zum Anzeigen benötigt. Die in [Permissions](../get_permissions/) angegebenen Berechtigungen werden von der Lesesoftware durchgesetzt.

Das Benutzerpasswort kann **null** oder ein leerer String sein; in diesem Fall wird beim Öffnen des PDF-Dokuments kein Passwort vom Benutzer verlangt. Das Benutzerpasswort darf nicht dasselbe sein wie das Eigentümerpasswort.
