## PdfSaveOptions::get_DmlEffectsRenderingMode method


Liest oder setzt einen Wert, der bestimmt, wie DrawingML-Effekte gerendert werden.

```cpp
Aspose::Words::Saving::DmlEffectsRenderingMode Aspose::Words::Saving::PdfSaveOptions::get_DmlEffectsRenderingMode() override
```

## Hinweise


Der Standardwert ist [Simplified](../../dmleffectsrenderingmode/).

Diese Eigenschaft wird verwendet, wenn das Dokument in feste Seitenformate exportiert wird.

Wenn [Compliance](../get_compliance/) auf [PdfA1a](../../pdfcompliance/) oder [PdfA1b](../../pdfcompliance/) gesetzt ist, gibt die Eigenschaft immer [None](../../dmleffectsrenderingmode/) zurück.
