## PdfCustomPropertiesExport enum


Gibt an, wie [CustomDocumentProperties](../../aspose.words/document/get_customdocumentproperties/) in eine PDF‑Datei exportiert werden.


### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Keine | 0 | Keine benutzerdefinierten Eigenschaften werden exportiert. |
| Standard | 1 | Benutzerdefinierte Eigenschaften werden als Einträge im /Info‑Verzeichnis exportiert.
