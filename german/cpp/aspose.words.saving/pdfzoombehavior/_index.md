## PdfZoomBehavior enum


Gibt den Zoomtyp an, der auf ein PDF-Dokument angewendet wird, wenn es in einem PDF‑Betrachter geöffnet wird.

```cpp
enum class PdfZoomBehavior
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Keine | 0 | Wie das Dokument angezeigt wird, bleibt dem PDF‑Betrachter überlassen. Normalerweise passt der Betrachter das Dokument an die Seitenbreite an. |
| ZoomFactor | 1 | Zeigt die Seite mit dem angegebenen Zoomfaktor an. |
| FitPage | 2 | Zeigt die Seite so an, dass sie vollständig sichtbar ist. |
| FitWidth | 3 | Passt die Breite der Seite an. |
| FitHeight | 4 | Passt die Höhe der Seite an. |
| FitBox | 5 | Passt das Begrenzungsrechteck an (Rechteck, das alle sichtbaren Elemente auf der Seite enthält). |
