## PdfPageMode enum


Gibt an, wie das PDF-Dokument angezeigt werden soll, wenn es im PDF‑Reader geöffnet wird.

```cpp
enum class PdfPageMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| UseNone | 0 | Weder die Dokumentgliederung noch die Miniaturbilder sind sichtbar. |
| UseOutlines | 1 | [Document](../../aspose.words/document/) Gliederung ist sichtbar. Hinweis: Wenn im PDF-Dokument keine Gliederungen vorhanden sind, wird das Gliederungs-Navigationsfenster ohnehin nicht sichtbar sein. |
| UseThumbs | 2 | Miniaturbilder sind sichtbar. |
| FullScreen | 3 | Vollbildmodus, ohne Menüleiste, Fenstersteuerungen oder irgendein anderes sichtbares Fenster. |
| UseOC | 4 | Optional-Content-Group-Panel ist sichtbar. |
| UseAttachments | 5 | Anlagen-Panel ist sichtbar. |
