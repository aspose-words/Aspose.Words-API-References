## OutlineOptions::get_HeadingsOutlineLevels method


Gibt an, wie viele Ebenen von Überschriften (Absätze, die mit den Überschriftsformaten formatiert sind) in die Dokumenten­gliederung aufgenommen werden sollen.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_HeadingsOutlineLevels() const
```

## Hinweise


Geben Sie 0 an, um keine Überschriften in der Übersicht zu haben; geben Sie 1 an, um eine Ebene von Überschriften in der Übersicht zu haben, und so weiter.

Standardwert ist 0. Gültiger Bereich ist von 0 bis 9.
