## OutlineOptions::get_ExpandedOutlineLevels method


Gibt an, wie viele Ebenen in der Dokumenten­gliederung beim Anzeigen der Datei erweitert angezeigt werden sollen.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_ExpandedOutlineLevels() const
```

## Hinweise


Beachten Sie, dass diese Option nicht funktioniert, wenn Sie in XPS speichern.

Geben Sie 0 an, und die Dokumentenübersicht wird zusammengeklappt; geben Sie 1 an, und die Elemente der ersten Ebene in der Übersicht werden erweitert, und so weiter.

Standardwert ist 0. Gültiger Bereich ist von 0 bis 9.
