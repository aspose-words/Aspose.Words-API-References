## PdfPageLayout enum


Gibt das Seitenlayout an, das verwendet wird, wenn das Dokument in einem PDF‑Reader geöffnet wird.

```cpp
enum class PdfPageLayout
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| SinglePage | 0 | Zeigt jeweils eine Seite an. |
| OneColumn | 1 | Zeigt die Seiten in einer Spalte an. |
| TwoColumnLeft | 2 | Zeigt die Seiten in zwei Spalten an, wobei ungerade Seiten links stehen. |
| TwoColumnRight | 3 | Zeigt die Seiten in zwei Spalten an, wobei ungerade Seiten rechts stehen. |
| TwoPageLeft | 4 | Zeigt jeweils zwei Seiten an, wobei ungerade Seiten links stehen. |
| TwoPageRight | 5 | Zeigt jeweils zwei Seiten an, wobei ungerade Seiten rechts stehen. |
