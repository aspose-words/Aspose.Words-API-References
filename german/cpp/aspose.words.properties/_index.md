Der **Aspose.Words.Properties** Namespace stellt Klassen zur Verfügung, um mit benutzerdefinierten und integrierten Dokumenteigenschaften wie Titel, Schlüsselwörtern, Unternehmen usw. zu arbeiten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BuiltInDocumentProperties](./builtindocumentproperties/) | Eine Sammlung integrierter Dokumenteigenschaften. Weitere Informationen finden Sie im Dokumentationsartikel [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [CustomDocumentProperties](./customdocumentproperties/) | Eine Sammlung benutzerdefinierter Dokumenteigenschaften. Weitere Informationen finden Sie im Dokumentationsartikel [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [DocumentProperty](./documentproperty/) | Stellt eine benutzerdefinierte oder integrierte Dokumenteigenschaft dar. Weitere Informationen finden Sie im Dokumentationsartikel [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
| [DocumentPropertyCollection](./documentpropertycollection/) | Basisklasse für die Sammlungen [BuiltInDocumentProperties](./builtindocumentproperties/) und [CustomDocumentProperties](./customdocumentproperties/). Weitere Informationen finden Sie im Dokumentationsartikel [Work with Document Properties](https://docs.aspose.com/words/cpp/work-with-document-properties/). |
