## LoadOptions::get_UseSystemLcid method


Liest oder setzt, ob der aus der Windows‑Registrierung erhaltene LCID‑Wert zur Bestimmung der Standardränder der Seiteneinrichtung verwendet werden soll.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Hinweise


Wenn auf **true** gesetzt, wird das Verhalten von MS Word emuliert, das den LCID-Wert aus der Windows-Registrierung übernimmt.

Der Standardwert ist **false**.
