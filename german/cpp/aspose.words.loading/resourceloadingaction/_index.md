## ResourceLoadingAction enum


Gibt den Modus des Ressourcenladens an. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/).

```cpp
enum class ResourceLoadingAction
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Standard | 0 | Aspose.Words lädt diese Ressource wie üblich. |
| Überspringen | 1 | Aspose.Words überspringt das Laden dieser Ressource. Nur ein Link ohne Daten wird für ein Bild gespeichert, das CSS-Stylesheet wird für das HTML-Format ignoriert. |
| UserProvided | 2 | Aspose.Words verwendet das vom Benutzer in [SetData()](../) bereitgestellte Byte-Array als Ressourcendaten. |
