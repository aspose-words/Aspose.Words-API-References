Der **Aspose.Words.Loading**-Namensraum stellt Klassen und Aufzählungen bereit, die das Festlegen zusätzlicher Optionen beim Laden von Dokumenten ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ChmLoadOptions](./chmloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines CHM-Dokuments in ein [Document](../aspose.words/document/)-Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [DocumentLoadingArgs](./documentloadingargs/) | Ein Argument, das an [Notify()](./idocumentloadingcallback/notify/) übergeben wird. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [HtmlLoadOptions](./htmlloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines HTML-Dokuments in ein [Document](../aspose.words/document/) Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [LanguagePreferences](./languagepreferences/) | Ermöglicht das Festlegen von Spracheinstellungen. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [LoadOptions](./loadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen (wie Passwort oder Basis-URI) beim Laden eines Dokuments in ein [Document](../aspose.words/document/) Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [MarkdownLoadOptions](./markdownloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines [Markdown](../aspose.words/loadformat/) Dokuments in ein [Document](../aspose.words/document/) Objekt. |
| [PdfLoadOptions](./pdfloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines PDF-Dokuments in ein [Document](../aspose.words/document/) Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [ResourceLoadingArgs](./resourceloadingargs/) | Stellt Daten für die Methode [ResourceLoading()](./iresourceloadingcallback/resourceloading/) bereit. |
| [RtfLoadOptions](./rtfloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines [Rtf](../aspose.words/loadformat/) Dokuments in ein [Document](../aspose.words/document/) Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
| [TxtLoadOptions](./txtloadoptions/) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines [Text](../aspose.words/loadformat/) Dokuments in ein [Document](../aspose.words/document/) Objekt. Weitere Informationen finden Sie im Dokumentationsartikel [Specify Load Options](https://docs.aspose.com/words/cpp/specify-load-options/). |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IDocumentLoadingCallback](./idocumentloadingcallback/) | Implementieren Sie diese Schnittstelle, wenn Sie eine eigene benutzerdefinierte Methode während des Ladens eines Dokuments aufrufen möchten. |
