## RowFormat.allow_break_across_pages property

True if the text in a table row is allowed to split across a page break.

def allow_break_across_pages(self) -> bool:
    ...

### Examples

Shows how to disable rows breaking across pages for every row in a table.

```python
doc = aw.Document(file_name=MY_DIR + 'Table spanning two pages.docx')
table = doc.first_section.body.tables[0]
# Setzen Sie die Eigenschaft "AllowBreakAcrossPages" auf "false", um die Zeile
# intakt zu halten, wenn eine Tabelle über zwei Seiten geht und an dieser Zeile umbricht.
# Ist die Zeile zu groß, um auf eine Seite zu passen, schiebt Microsoft Word sie auf die nächste Seite.
# Setzen Sie die Eigenschaft "AllowBreakAcrossPages" auf "true", um zu erlauben, dass die Zeile über zwei Seiten hinweg umbricht.
for row in table:
    row = row.as_row()
    row.row_format.allow_break_across_pages = allow_break_across_pages
doc.save(file_name=ARTIFACTS_DIR + 'Table.AllowBreakAcrossPages.docx')
```
