```
public class KnownTypeSet implements Iterable
```

Stellt eine ungeordnete Menge dar (d. h. eine Sammlung eindeutiger Elemente), die java.lang.Class-Objekte enthält, deren vollständig oder teilweise qualifizierte Namen in Berichtsvorlagen verwendet werden können, um die statischen Mitglieder der entsprechenden Typen aufzurufen, Typumwandlungen durchzuführen usw.

Weitere Informationen finden Sie im Dokumentationsartikel zum [ LINQ Reporting Engine ][LINQ Reporting Engine].


[LINQ Reporting Engine]: https://docs.aspose.com/words/java/linq-reporting-engine/
