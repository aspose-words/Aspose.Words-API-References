Namnområdet **Aspose.Words.Notes** tillhandahåller klasser för att arbeta med Microsoft Word-slutnoter och fotnoter.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EndnoteOptions](./endnoteoptions/) | Representerar numreringsalternativen för slutnoter i ett dokument eller avsnitt. För att lära dig mer, besök dokumentationsartikeln [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [Footnote](./footnote/) | Representerar en behållare för texten i en fotnot eller slutnot. För att lära dig mer, besök dokumentationsartikeln [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteOptions](./footnoteoptions/) | Representerar alternativ för fotnotnumrering för ett dokument eller avsnitt. För att lära dig mer, besök dokumentationsartikeln [Working with Footnote and Endnote](https://docs.aspose.com/words/cpp/working-with-footnote-and-endnote/). |
| [FootnoteSeparator](./footnoteseparator/) | Representerar en behållare för fotnot-/slutnotseparatorn och fortsättningsinnehållet i ett dokument. |
| [FootnoteSeparatorCollection](./footnoteseparatorcollection/) | Tillhandahåller typad åtkomst till noderna [FootnoteSeparator](./footnoteseparator/) i ett dokument. |
