## MailMerge::DeleteFields method


Tar bort kopplingsrelaterade fält från dokumentet.

```cpp
void Aspose::Words::MailMerging::MailMerge::DeleteFields()
```

## Anmärkningar


Denna metod tar bort MERGEFIELD- och NEXT-fält från dokumentet.

Denna metod kan vara användbar om din mail merge-operation inte alltid behöver fylla i alla fält i dokumentet. Använd denna metod för att ta bort alla återstående mail merge-fält.
