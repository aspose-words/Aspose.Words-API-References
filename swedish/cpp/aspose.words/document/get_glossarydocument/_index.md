## Document::get_GlossaryDocument method


Hämtar eller anger glossariedokumentet inom detta dokument eller mall. Ett glossariedokument är en lagring för AutoText-, AutoCorrect- och Building Block‑poster som definierats i ett dokument.

```cpp
System::SharedPtr<Aspose::Words::BuildingBlocks::GlossaryDocument> Aspose::Words::Document::get_GlossaryDocument() const
```

## Anmärkningar


Denna egenskap returnerar **null** om dokumentet inte har ett glossarie-dokument.

Du kan lägga till ett glossarie-dokument i ett dokument genom att skapa ett [GlossaryDocument](../../../aspose.words.buildingblocks/glossarydocument/)‑objekt och tilldela det till denna egenskap.
