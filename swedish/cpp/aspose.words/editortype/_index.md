## EditorType enum


Anger mängden möjliga alias (eller redigeringsgrupper) som kan användas som alias för att avgöra om den aktuella användaren ska tillåtas redigera ett enskilt område definierat av ett redigerbart område i ett dokument.

```cpp
enum class EditorType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Ospecificerad | 0 | Betyder att redigeringstypen inte är specificerad. |
| Administratörer | 1 | Anger att användare som är associerade med Administratörer-gruppen ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Bidragsgivare | 2 | Anger att användare som är associerade med Bidragsgivare-gruppen ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Aktuell | 3 | Anger att användare som är associerade med Aktuell-gruppen ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Redaktörer | 4 | Anger att användare som är associerade med Redaktörer-gruppen ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Alla | 5 | Anger att alla användare som öppnar dokumentet ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| None | 6 | Anger att ingen av användarna som öppnar dokumentet ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Ägare | 7 | Anger att användare som är associerade med gruppen Ägare ska tillåtas redigera redigerbara områden med denna redigeringstyp när dokumentskydd är aktiverat. |
| Default | n/a | Samma som [Unspecified](./). |
