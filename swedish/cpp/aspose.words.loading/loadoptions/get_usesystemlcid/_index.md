## LoadOptions::get_UseSystemLcid method


Hämtar eller anger om LCID-värdet som hämtas från Windows-registret ska användas för att bestämma standards marginaler för sidinställning.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Anmärkningar


Om den är satt till **true** emuleras MS Word‑beteende som hämtar LCID‑värdet från Windows‑registret.

Standardvärdet är **false**.
