## FontSavingArgs::get_KeepFontStreamOpen method


Anger om Aspose.Words ska hålla strömmen öppen eller stänga den efter att ett teckensnitt har sparats.

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## Anmärkningar


Standard är **false** och Aspose.Words kommer att stänga den ström du angav i egenskapen [FontStream](../get_fontstream/) efter att ha skrivit ett teckensnitt till den. Ange **true** för att hålla strömmen öppen.
