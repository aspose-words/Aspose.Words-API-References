## CssStyleSheetType enum


Anger hur CSS (Cascading [Style](../../aspose.words/style/) Sheet) stilar exporteras till HTML.

```cpp
enum class CssStyleSheetType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Inbäddad | 0 | CSS-stilar skrivs inline (som ett värde för **style**-attributet på varje element). |
| Inbäddad | 1 | CSS-stilar skrivs separat från innehållet i ett stilblad som är inbäddat i HTML-filen. |
| Extern | 2 | CSS-stilar skrivs separat från innehållet i ett stilblad i en extern fil. HTML-filen länkar till stilbladet. |
