## CssSavingArgs::get_KeepCssStreamOpen method


Anger om Aspose.Words ska hålla strömmen öppen eller stänga den efter att ha sparat CSS‑information.

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## Anmärkningar


Standard är **false** och Aspose.Words kommer att stänga den ström du angav i egenskapen [CssStream](../get_cssstream/) efter att ha skrivit CSS‑information till den. Ange **true** för att hålla strömmen öppen.
