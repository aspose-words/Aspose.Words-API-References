## OutlineOptions::get_DefaultBookmarksOutlineLevel method


Anger standardnivån i dokumentets kontur där Word‑bokmärken ska visas.

```cpp
int32_t Aspose::Words::Saving::OutlineOptions::get_DefaultBookmarksOutlineLevel() const
```

## Anmärkningar


Individuell bokmärkesnivå kan anges med egenskapen [BookmarksOutlineLevels](../get_bookmarksoutlinelevels/).

Ange 0 så kommer Word‑bokmärken inte att visas i dokumentets disposition. Ange 1 så kommer Word‑bokmärken att visas i dokumentets disposition på nivå 1; 2 för nivå 2 och så vidare.

Standardvärdet är 0. Giltigt intervall är 0 till 9.
