## PdfSaveOptions::get_DisplayDocTitle method


En flagga som anger om fönstrets titelrad ska visa dokumenttiteln hämtad från Title-posten i dokumentinformationens katalog.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_DisplayDocTitle() const
```

## Anmärkningar


Om **false** bör titelfältet istället visa namnet på PDF‑filen som innehåller dokumentet.

Denna flagga krävs för PDF/UA‑efterlevnad. **true**‑värdet kommer att användas automatiskt vid sparande till PDF/UA.

Standardvärdet är **false**.
