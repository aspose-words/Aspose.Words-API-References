## PdfSaveOptions::get_ExportDocumentStructure method


Hämtar eller anger ett värde som bestämmer om dokumentstrukturen ska exporteras eller inte.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_ExportDocumentStructure() const
```

## Anmärkningar


Detta värde ignoreras vid sparande till PDF/A-1a, PDF/A-2a och PDF/UA-1 eftersom dokumentstruktur krävs för denna efterlevnad.

Observera att export av dokumentstrukturen avsevärt ökar minnesförbrukningen, särskilt för stora dokument.
