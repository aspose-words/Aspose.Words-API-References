## PdfSaveOptions::get_AdditionalTextPositioning method


En flagga som anger om ytterligare textpositioneringsoperatorer ska skrivas eller inte.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_AdditionalTextPositioning() const
```

## Anmärkningar


Om **true** skrivs ytterligare textpositioneringsoperatorer till den genererade PDF-filen. Detta kan hjälpa till att lösa problem med felaktig textpositionering med vissa skrivare. Nackdelen är den ökade PDF-dokumentstorleken.

Standardvärdet är **false**.
