## PdfEncryptionDetails::get_UserPassword method


Anger användarlösenordet som krävs för att öppna det krypterade PDF-dokumentet.

```cpp
System::String Aspose::Words::Saving::PdfEncryptionDetails::get_UserPassword() const
```

## Anmärkningar


Användarlösenordet kommer att krävas för att öppna ett krypterat PDF-dokument för visning. De behörigheter som anges i [Permissions](../get_permissions/) kommer att verkställas av läsprogramvaran.

Användarlösenordet kan vara **null** eller en tom sträng, i så fall krävs inget lösenord från användaren när PDF-dokumentet öppnas. Användarlösenordet får inte vara detsamma som ägarlösenordet.
