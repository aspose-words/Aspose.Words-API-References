## PdfZoomBehavior enum


Anger vilken typ av zoom som tillämpas på ett PDF-dokument när det öppnas i en PDF-visare.

```cpp
enum class PdfZoomBehavior
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | 0 | Hur dokumentet visas lämnas åt PDF-visaren. Vanligtvis visar visaren dokumentet så att det passar sidbredden. |
| ZoomFactor | 1 | Visar sidan med den angivna zoomfaktorn. |
| FitPage | 2 | Visar sidan så att den är helt synlig. |
| FitWidth | 3 | Anpassar sidans bredd. |
| FitHeight | 4 | Anpassar sidans höjd. |
| FitBox | 5 | Anpassar den omgivande rutan (rektangeln som innehåller alla synliga element på sidan). |
