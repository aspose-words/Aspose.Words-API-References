## FormField::get_TextInputFormat method


Returnerar eller anger textformateringen för ett textformulärfält.

```cpp
System::String Aspose::Words::Fields::FormField::get_TextInputFormat()
```

## Anmärkningar


Om textformulärfältet innehåller vanlig text, är giltiga formatsträngar "", "UPPERCASE", "LOWERCASE", "FIRST CAPITAL" och "TITLE CASE". Strängarna är skiftlägesokänsliga.

Om textformulärfältet innehåller ett tal eller ett datum/tid‑värde, är giltiga formatsträngar tal‑ eller datum‑ och tidsformatsträngar.

Microsoft Word tillåter strängar med högst 64 tecken.
