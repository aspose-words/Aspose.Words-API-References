## FormField::get_StatusText method


Returnerar eller anger texten som visas i statusfältet när ett formulärfält har fokus.

```cpp
System::String Aspose::Words::Fields::FormField::get_StatusText()
```

## Anmärkningar


Om egenskapen [OwnStatus](../get_ownstatus/) är inställd på **true**, anger egenskapen [StatusText](./) texten i statusfältet. Om egenskapen [OwnStatus](../get_ownstatus/) är inställd på **false**, anger egenskapen [StatusText](./) namnet på ett AutoText-inlägg som innehåller statusfältstext för formulärfältet.

Microsoft Word tillåter strängar med högst 138 tecken.
