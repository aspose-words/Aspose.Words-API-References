## BuildingBlockBehavior enum


Anger beteendet som ska tillämpas på innehållet i byggblocket när det infogas i huvuddokumentet.

```cpp
enum class BuildingBlockBehavior
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Content | 0 | Anger att byggblocket ska infogas som inline-innehåll. |
| Paragraph | 1 | Anger att byggblocket ska infogas i ett eget stycke. |
| Page | 2 | Anger att byggblocket ska läggas till på en egen sida. |
| Default | n/a | Samma som [Content](./). |
