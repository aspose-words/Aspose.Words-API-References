Namnområdet **Aspose.Words.BuildingBlocks** tillhandahåller klasser som möjliggör åtkomst till och användning av AutoText, AutoCorrect-poster och byggblock i ett dokument.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [BuildingBlock](./buildingblock/) | Representerar ett post i ett ordlista-dokument, såsom ett byggblock, AutoText eller en AutoCorrect-post. För att lära dig mer, besök dokumentationsartikeln [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [BuildingBlockCollection](./buildingblockcollection/) | En samling av [BuildingBlock](./buildingblock/)-objekt i dokumentet. För att lära dig mer, besök dokumentationsartikeln [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
| [GlossaryDocument](./glossarydocument/) | Representerar rot-elementet för ett ordlista-dokument inom ett Word-dokument. Ett ordlista-dokument är en lagring för AutoText, AutoCorrect-poster och byggblock. För att lära dig mer, besök dokumentationsartikeln [Aspose.Words Document Object Model (DOM)](https://docs.aspose.com/words/cpp/aspose-words-document-object-model/). |
## Enums

| Enum | Beskrivning |
| --- | --- |
| [BuildingBlockBehavior](./buildingblockbehavior/) | Anger beteendet som ska tillämpas på innehållet i byggblocket när det infogas i huvuddokumentet. |
| [BuildingBlockGallery](./buildingblockgallery/) | Anger det fördefinierade galleriet som ett byggblock klassificeras i. |
| [BuildingBlockType](./buildingblocktype/) | Anger en byggblockstyp. Typen kan påverka synligheten och beteendet för byggblocket i Microsoft Word. |
