## ArrowType enum


Specifica il tipo di freccia all'estremità di una linea.

```cpp
enum class ArrowType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | 0 | La linea non ha una freccia all'estremità. |
| Freccia | 1 | La freccia è un triangolo pieno. |
| Stealth | 2 | La freccia è una freccia "stealth". |
| Diamond | 3 | L'estremità della linea è un diamante pieno. |
| Oval | 4 | L'estremità della linea è un ovale pieno. |
| Open | 5 | La freccia è una freccia aperta. |
| Default | n/a | Stesso di [None](./). |
