## TextPath::get_XScale method


Determina se verrà utilizzato un percorso di testo rettilineo invece del percorso della forma.

```cpp
bool Aspose::Words::Drawing::TextPath::get_XScale()
```

## Note


Il valore predefinito è **false**.

Se **true**, il testo scorre lungo un percorso da sinistra a destra lungo il valore x del bordo inferiore della forma.
