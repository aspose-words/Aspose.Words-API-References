## SignatureLine::get_Id method


Ottiene o imposta l'identificatore per questa linea di firma. Questo identificatore può essere associato a una firma digitale, quando si firma il documento usando [DigitalSignatureUtil](../../../aspose.words.digitalsignatures/digitalsignatureutil/). Questo valore deve essere univoco e, per impostazione predefinita, è generato casualmente un nuovo Guid (**NewGuid**).
