Il namespace **Aspose.Words.WebExtensions** fornisce classi che consentono di personalizzare elementi e attributi che estendono il vocabolario XML per la rappresentazione dei componenti aggiuntivi di Office.

## Classi

| Classe | Descrizione |
| --- | --- |
| [BaseWebExtensionCollection](./basewebextensioncollection/) | Classe base per le collezioni [TaskPaneCollection](./taskpanecollection/), [WebExtensionBindingCollection](./webextensionbindingcollection/), [WebExtensionPropertyCollection](./webextensionpropertycollection/) e [WebExtensionReferenceCollection](./webextensionreferencecollection/). Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [TaskPane](./taskpane/) | Rappresenta un oggetto task pane di un add-in. Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [TaskPaneCollection](./taskpanecollection/) | Specifica un elenco di oggetti task pane persistenti. Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
| [WebExtension](./webextension/) | Rappresenta un oggetto web extension. Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |

| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Specifica un elenco di binding di estensioni web. Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |

| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Specifica un insieme di proprietà personalizzate dell'estensione web. Per saperne di più, visita l'articolo di documentazione [Work with Office Add-ins](https://docs.aspose.com/words/cpp/work-with-office-add-ins/). |
