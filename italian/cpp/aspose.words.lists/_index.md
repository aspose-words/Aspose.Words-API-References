Il namespace **Aspose.Words.Lists** contiene classi per lavorare con elenchi puntati e numerati definiti in un documento.

## Classi

| Classe | Descrizione |
| --- | --- |
| [List](./list/) | Rappresenta la formattazione di un elenco. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListCollection](./listcollection/) | Memorizza e gestisce la formattazione di elenchi puntati e numerati usati in un documento. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListFormat](./listformat/) | Consente di controllare quale formattazione dell'elenco viene applicata a un paragrafo. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLabel](./listlabel/) | Definisce le proprietà specifiche di un'etichetta di elenco. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevel](./listlevel/) | Definisce la formattazione per un livello di elenco. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
| [ListLevelCollection](./listlevelcollection/) | Una raccolta di formattazioni di elenco per ogni livello in un elenco. Per saperne di più, visita l'articolo di documentazione [Working with Lists](https://docs.aspose.com/words/cpp/working-with-lists/). |
