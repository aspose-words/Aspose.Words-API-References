Il namespace **Aspose.Words.Rendering** fornisce classi che consentono di personalizzare la stampa o il rendering dei documenti.

## Classi

| Classe | Descrizione |
| --- | --- |
| [NodeRendererBase](./noderendererbase/) | Classe base per [ShapeRenderer](./shaperenderer/) e [OfficeMathRenderer](./officemathrenderer/). Per saperne di più, visita l'articolo di documentazione [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [OfficeMathRenderer](./officemathrenderer/) | Fornisce metodi per renderizzare un singolo [OfficeMath](../aspose.words.math/officemath/) in un'immagine raster o vettoriale o in un oggetto Graphics. Per saperne di più, visita l'articolo di documentazione [Working with OfficeMath](https://docs.aspose.com/words/cpp/working-with-officemath/). |
| [PageInfo](./pageinfo/) | Rappresenta le informazioni su una specifica pagina del documento. Per saperne di più, visita l'articolo di documentazione [Rendering](https://docs.aspose.com/words/cpp/rendering/). |
| [ShapeRenderer](./shaperenderer/) | Fornisce metodi per renderizzare un singolo [Shape](../aspose.words.drawing/shape/) o [GroupShape](../aspose.words.drawing/groupshape/) in un'immagine raster o vettoriale o in un oggetto Graphics. Per saperne di più, visita l'articolo di documentazione [Working with Shapes](https://docs.aspose.com/words/cpp/working-with-shapes/). |
| [ThumbnailGeneratingOptions](./thumbnailgeneratingoptions/) | Può essere usato per specificare opzioni aggiuntive durante la generazione di una miniatura per un documento. |
