## DmlRenderingMode enum


Specifica come le forme DrawingML vengono renderizzate nei formati a pagina fissa.

```cpp
enum class DmlRenderingMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Fallback | 0 | Se è disponibile una forma di fallback per DrawingML, Aspose.Words renderizza la forma di fallback invece di DrawingML. |
| DrawingML | 1 | Aspose.Words ignora la forma di fallback di DrawingML e renderizza direttamente DrawingML. Questa è la modalità predefinita. |
