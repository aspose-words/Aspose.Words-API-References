## ResourceSavingArgs::get_KeepResourceStreamOpen method


Specifica se Aspose.Words deve mantenere il flusso aperto o chiuderlo dopo aver salvato una risorsa.

```cpp
bool Aspose::Words::Saving::ResourceSavingArgs::get_KeepResourceStreamOpen() const
```

## Note


Il valore predefinito è **false** e Aspose.Words chiuderà lo stream fornito nella proprietà [ResourceStream](../get_resourcestream/) dopo aver scritto una risorsa al suo interno. Specificare **true** per mantenere lo stream aperto.
