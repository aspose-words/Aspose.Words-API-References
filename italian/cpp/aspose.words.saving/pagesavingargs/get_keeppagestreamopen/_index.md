## PageSavingArgs::get_KeepPageStreamOpen method


Specifica se Aspose.Words deve mantenere lo stream aperto o chiuderlo dopo il salvataggio di una pagina del documento.

```cpp
bool Aspose::Words::Saving::PageSavingArgs::get_KeepPageStreamOpen() const
```

## Note


Il valore predefinito è **false** e Aspose.Words chiuderà il flusso fornito nella proprietà [PageStream](../get_pagestream/) dopo aver scritto una pagina del documento al suo interno. Specificare **true** per mantenere il flusso aperto.
