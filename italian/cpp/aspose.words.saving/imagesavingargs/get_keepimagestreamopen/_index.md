## ImageSavingArgs::get_KeepImageStreamOpen method


Specifica se Aspose.Words deve mantenere lo stream aperto o chiuderlo dopo il salvataggio di un'immagine.

```cpp
bool Aspose::Words::Saving::ImageSavingArgs::get_KeepImageStreamOpen() const
```

## Note


Il valore predefinito è **false** e Aspose.Words chiuderà il flusso fornito nella proprietà [ImageStream](../get_imagestream/) dopo aver scritto un'immagine al suo interno. Specifica **true** per mantenere il flusso aperto.
