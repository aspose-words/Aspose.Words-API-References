## NumeralFormat enum


Indica il set di simboli utilizzato per rappresentare i numeri durante il rendering nei formati di pagina fissi.

```cpp
enum class NumeralFormat
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| European | 0 | Numeri europei: 0123456789. |
| ArabicIndic | 1 | Numeri usati in arabo: ٠١٢٣٤٥٦٧٨٩. Intervallo Unicode U+0660 - u+0669. |
| EasternArabicIndic | 2 | Numeri usati in persiano e urdu: ۰۱۲۳۴۵۶۷۸۹. Intervallo Unicode U+06F0 - u+06F9. |
| Contesto | 3 | Il set di simboli è determinato dal contesto (locale e proprietà RTL). |
| Sistema | 4 | QUESTA OPZIONE NON È SUPPORTATA. Il set di simboli è determinato dalle impostazioni regionali. |
