## FontSavingArgs::get_FontStream method


Consente di specificare lo stream dove il carattere verrà salvato.

```cpp
System::SharedPtr<System::IO::Stream> Aspose::Words::Saving::FontSavingArgs::get_FontStream() const
```

## Note


Questa proprietà consente di salvare i font su stream invece che su file durante l'esportazione HTML.

Il valore predefinito è **null**. Quando questa proprietà è **null**, il font verrà salvato in un file specificato nella proprietà [FontFileName](../get_fontfilename/).
