## FontSavingArgs::get_KeepFontStreamOpen method


Specifica se Aspose.Words deve mantenere il flusso aperto o chiuderlo dopo aver salvato un carattere.

```cpp
bool Aspose::Words::Saving::FontSavingArgs::get_KeepFontStreamOpen() const
```

## Note


Il valore predefinito è **false** e Aspose.Words chiuderà lo stream fornito nella proprietà [FontStream](../get_fontstream/) dopo aver scritto un font al suo interno. Specificare **true** per mantenere lo stream aperto.
