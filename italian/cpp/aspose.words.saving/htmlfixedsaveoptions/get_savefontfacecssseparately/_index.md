## HtmlFixedSaveOptions::get_SaveFontFaceCssSeparately method


Il flag indica se le regole CSS \"@font-face\" devono essere collocate in un file separato \"fontFaces.css\" quando un documento viene salvato con un foglio di stile esterno (cioè, quando [ExportEmbeddedCss](../get_exportembeddedcss/) è **false**). Il valore predefinito è **false**, tutte le regole CSS sono scritte in un unico file \"styles.css\".
