```cpp
System::SharedPtr<Aspose::Words::Saving::GraphicsQualityOptions> Aspose::Words::Saving::ImageSaveOptions::get_GraphicsQualityOptions() const
```

## Note


Usa questa proprietà per sovrascrivere le impostazioni Graphics fornite dal motore Aspose.Words per impostazione predefinita.

Avrà effetto solo quando un documento viene salvato in un formato simile a un'immagine.
