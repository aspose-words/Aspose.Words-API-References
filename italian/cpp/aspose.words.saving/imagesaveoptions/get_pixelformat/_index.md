## ImageSaveOptions::get_PixelFormat method


Ottiene o imposta il formato pixel per le immagini generate.

```cpp
Aspose::Words::Saving::ImagePixelFormat Aspose::Words::Saving::ImageSaveOptions::get_PixelFormat() const
```

## Note


Questa proprietà ha effetto solo quando si salva in formati di immagine raster.

Il valore predefinito è [Format32BppArgb](../../imagepixelformat/).

Il formato pixel dell'immagine di output può differire dal valore impostato a causa del funzionamento di GDI+.
