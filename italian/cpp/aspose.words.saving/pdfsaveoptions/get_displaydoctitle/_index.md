## PdfSaveOptions::get_DisplayDocTitle method


Un flag che specifica se la barra del titolo della finestra deve visualizzare il titolo del documento preso dalla voce Title del dizionario delle informazioni del documento.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_DisplayDocTitle() const
```

## Note


Se **false**, la barra del titolo dovrebbe invece visualizzare il nome del file PDF contenente il documento.

Questo flag è richiesto per la conformità PDF/UA. Il valore **true** verrà utilizzato automaticamente durante il salvataggio in PDF/UA.

Il valore predefinito è **false**.
