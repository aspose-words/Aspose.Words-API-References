## PdfSaveOptions::get_AdditionalTextPositioning method


Un flag che indica se scrivere o meno operatori aggiuntivi di posizionamento del testo.

```cpp
bool Aspose::Words::Saving::PdfSaveOptions::get_AdditionalTextPositioning() const
```

## Note


Se **true**, gli operatori aggiuntivi di posizionamento del testo vengono scritti nel PDF di output. Questo può aiutare a superare problemi di posizionamento impreciso del testo con alcune stampanti. L'aspetto negativo è l'aumento delle dimensioni del documento PDF.

Il valore predefinito è **false**.
