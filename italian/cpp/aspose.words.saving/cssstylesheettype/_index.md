## CssStyleSheetType enum


Specifica come gli stili CSS (Cascading [Stile](../../aspose.words/style/) Sheet) vengono esportati in HTML.

```cpp
enum class CssStyleSheetType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Inline | 0 | Gli stili CSS sono scritti inline (come valore dell'attributo **style** su ogni elemento). |
| Incorporato | 1 | Gli stili CSS sono scritti separatamente dal contenuto in un foglio di stile incorporato nel file HTML. |
| Esterno | 2 | Gli stili CSS sono scritti separatamente dal contenuto in un foglio di stile in un file esterno. Il file HTML collega il foglio di stile. |
