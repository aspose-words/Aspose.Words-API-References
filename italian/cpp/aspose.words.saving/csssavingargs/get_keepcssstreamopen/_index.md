## CssSavingArgs::get_KeepCssStreamOpen method


Specifica se Aspose.Words deve mantenere lo stream aperto o chiuderlo dopo aver salvato le informazioni CSS.

```cpp
bool Aspose::Words::Saving::CssSavingArgs::get_KeepCssStreamOpen() const
```

## Note


Il valore predefinito è **false** e Aspose.Words chiuderà il flusso fornito nella proprietà [CssStream](../get_cssstream/) dopo aver scritto le informazioni CSS al suo interno. Specifica **true** per mantenere il flusso aperto.
