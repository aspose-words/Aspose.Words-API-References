## Document::get_GlossaryDocument method


Ottiene o imposta il documento glossario all'interno di questo documento o modello. Un documento glossario è un archivio per le voci AutoText, AutoCorrect e Building Block definite in un documento.

```cpp
System::SharedPtr<Aspose::Words::BuildingBlocks::GlossaryDocument> Aspose::Words::Document::get_GlossaryDocument() const
```

## Note


Questa proprietà restituisce **null** se il documento non ha un documento glossario.

È possibile aggiungere un documento glossario a un documento creando un oggetto [GlossaryDocument](../../../aspose.words.buildingblocks/glossarydocument/) e assegnandolo a questa proprietà.
