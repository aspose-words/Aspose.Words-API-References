## FieldOptions::get_UserPromptRespondent method


Ottiene o imposta il rispondente alle richieste dell'utente durante l'aggiornamento del campo.

```cpp
const System::SharedPtr<Aspose::Words::Fields::IFieldUserPromptRespondent> & Aspose::Words::Fields::FieldOptions::get_UserPromptRespondent() const
```

## Note


Se il valore di questa proprietà è impostato su **null**, i campi che richiedono una risposta dell'utente al prompt (come [FieldAsk](../../fieldask/) o [FieldFillIn](../../fieldfillin/)) non vengono aggiornati.

Il valore predefinito è **null**.
