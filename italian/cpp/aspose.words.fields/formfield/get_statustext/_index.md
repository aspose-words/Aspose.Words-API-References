## FormField::get_StatusText method


Restituisce o imposta il testo visualizzato nella barra di stato quando un campo modulo ha il focus.

```cpp
System::String Aspose::Words::Fields::FormField::get_StatusText()
```

## Note


Se la proprietà [OwnStatus](../get_ownstatus/) è impostata su **true**, la proprietà [StatusText](./) specifica il testo della barra di stato. Se la proprietà [OwnStatus](../get_ownstatus/) è impostata su **false**, la proprietà [StatusText](./) specifica il nome di una voce AutoText che contiene il testo della barra di stato per il campo modulo.

Microsoft Word consente stringhe di al massimo 138 caratteri.
