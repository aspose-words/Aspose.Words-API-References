## FormField::get_TextInputFormat method


Restituisce o imposta la formattazione del testo per un campo modulo di testo.

```cpp
System::String Aspose::Words::Fields::FormField::get_TextInputFormat()
```

## Note


Se il campo modulo di testo contiene testo normale, le stringhe di formato valide sono "", "UPPERCASE", "LOWERCASE", "FIRST CAPITAL" e "TITLE CASE". Le stringhe non distinguono tra maiuscole e minuscole.

Se il campo modulo di testo contiene un numero o un valore data/ora, le stringhe di formato valide sono stringhe di formato numerico o di data e ora.

Microsoft Word consente stringhe con al massimo 64 caratteri.
