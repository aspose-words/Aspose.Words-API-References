## LoadOptions::get_UseSystemLcid method


Ottiene o imposta se utilizzare il valore LCID ottenuto dal registro di Windows per determinare i margini predefiniti dell'impostazione della pagina.

```cpp
bool Aspose::Words::Loading::LoadOptions::get_UseSystemLcid() const
```

## Note


Se impostato su **true**, viene emulato il comportamento di MS Word che prende il valore LCID dal registro di Windows.

Il valore predefinito è **false**.
