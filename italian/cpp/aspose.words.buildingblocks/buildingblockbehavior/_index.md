## BuildingBlockBehavior enum


Specifica il comportamento che deve essere applicato al contenuto del building block quando viene inserito nel documento principale.

```cpp
enum class BuildingBlockBehavior
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Content | 0 | Specifica che il blocco di costruzione deve essere inserito come contenuto inline. |
| Paragraph | 1 | Specifica che il blocco di costruzione deve essere inserito nel proprio paragrafo. |
| Page | 2 | Specifica che il blocco di costruzione deve essere aggiunto nella propria pagina. |
| Default | n/a | Stesso di [Content](./). |

## Note


Corrisponde al tipo **ST_DocPartBehavior** in OOXML.
