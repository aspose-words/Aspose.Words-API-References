Il namespace **Aspose.Words.Bibliography** fornisce classi che consentono di accedere a un elenco di fonti bibliografiche disponibili in un documento.

## Classi

| Classe | Descrizione |
| --- | --- |
| [Bibliography](./bibliography/) | Rappresenta l'elenco delle fonti bibliografiche disponibili nel documento. |
| [Contributor](./contributor/) | Rappresenta un contributore di una fonte bibliografica. Può essere sia un soggetto aziendale (un'organizzazione) sia un elenco di persone. |
| [ContributorCollection](./contributorcollection/) | Rappresenta i contributori di fonti bibliografiche. |
| [Corporate](./corporate/) | Rappresenta un contributore aziendale (un'organizzazione) di una fonte bibliografica. |
| [Person](./person/) | Rappresenta un contributore individuale (una persona) di una fonte bibliografica. |
| [PersonCollection](./personcollection/) | Rappresenta un elenco di persone che sono contributori di fonti bibliografiche. |
| [Source](./source/) | Rappresenta una fonte individuale, come un libro, un articolo di rivista o un'intervista. |
## Enums

| Enum | Descrizione |
| --- | --- |
| [SourceType](./sourcetype/) | Rappresenta i tipi di fonti bibliografiche. |
