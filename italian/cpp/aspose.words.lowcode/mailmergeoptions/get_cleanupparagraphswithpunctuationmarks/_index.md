## MailMergeOptions::get_CleanupParagraphsWithPunctuationMarks method


Ottiene o imposta un valore che indica se i paragrafi con segni di punteggiatura sono considerati vuoti e devono essere rimossi se l'opzione [RemoveEmptyParagraphs](../../../aspose.words.mailmerging/mailmergecleanupoptions/) è specificata.

```cpp
bool Aspose::Words::LowCode::MailMergeOptions::get_CleanupParagraphsWithPunctuationMarks() const
```

## Note


Il valore predefinito è **true**. Ecco l'elenco completo dei segni di punteggiatura rimovibili:

* !
* ,
* .
* :
* ;
* ?
* ¡
* ¿
