Il namespace **Aspose.Words.Settings** contiene classi ed enum che vengono utilizzati quando si specificano varie impostazioni e opzioni memorizzate in un documento. Queste includono la stampa unione, la protezione in scrittura, la compatibilità e altre impostazioni.

## Classi

| Classe | Descrizione |
| --- | --- |
| [CompatibilityOptions](./compatibilityoptions/) | Contiene opzioni di compatibilità (cioè le preferenze dell'utente inserite nella scheda **Compatibility** della finestra di dialogo **Options** in Microsoft Word). Per saperne di più, visita l'articolo di documentazione [Rileva formato file e verifica compatibilità formato](https://docs.aspose.com/words/cpp/detect-file-format-and-check-format-compatibility/). |
| [HyphenationOptions](./hyphenationoptions/) | Consente di configurare le opzioni di sillabazione del documento. Per saperne di più, visita l'articolo di documentazione [Lavorare con la sillabazione](https://docs.aspose.com/words/cpp/working-with-hyphenation/). |
| [MailMergeSettings](./mailmergesettings/) | Specifica tutte le informazioni di unione di posta per un documento. Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [Odso](./odso/) | Specifica le impostazioni dell'Office Data Source Object (ODSO) per una fonte dati di unione di posta. Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapData](./odsofieldmapdata/) | Specifica come una colonna nella fonte dati esterna deve essere mappata ai campi di unione predefiniti all'interno del documento. Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoFieldMapDataCollection](./odsofieldmapdatacollection/) | Una raccolta tipizzata degli oggetti [OdsoFieldMapData](./odsofieldmapdata/). Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientData](./odsorecipientdata/) | Rappresenta le informazioni su un singolo record in una fonte dati esterna che deve essere escluso dall'unione di posta. Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [OdsoRecipientDataCollection](./odsorecipientdatacollection/) | Una raccolta tipizzata di [OdsoRecipientData](./odsorecipientdata/). Per saperne di più, visita l'articolo di documentazione [Unione di posta e reportistica](https://docs.aspose.com/words/cpp/mail-merge-and-reporting/). |
| [ViewOptions](./viewoptions/) | Fornisce varie opzioni che controllano come un documento viene visualizzato in Microsoft Word. Per saperne di più, visita l'articolo di documentazione [Lavorare con le opzioni e l'aspetto dei documenti Word](https://docs.aspose.com/words/cpp/work-with-word-document-options-and-appearance/). |
| [WriteProtection](./writeprotection/) | Specifica le impostazioni di protezione in scrittura per un documento. Per saperne di più, visita l'articolo di documentazione [Protect or Encrypt a Document](https://docs.aspose.com/words/cpp/protect-or-encrypt-a-document/). |
