## MailMergeDataType enum


Specifica il tipo di una fonte dati esterna per l'unione dei documenti.

```cpp
enum class MailMergeDataType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | -1 | Nessuna fonte dati di stampa unione è specificata. |
| TextFile | 0 | Specifica che un determinato documento è stato collegato a un file di testo tramite il sistema Dynamic Data Exchange (DDE). |
| Database | 1 | Specifica che un determinato documento è stato collegato a un database Access tramite il sistema Dynamic Data Exchange (DDE). |
| Spreadsheet | 2 | Specifica che un determinato documento è stato collegato a un foglio di calcolo Excel tramite il sistema Dynamic Data Exchange (DDE). |
| Query | 3 | Specifica che un determinato documento è stato collegato a una fonte dati esterna utilizzando uno strumento di query esterno. |
| Odbc | 4 | Specifica che un determinato documento è stato collegato a una fonte dati esterna tramite l'interfaccia Open Database Connectivity. |
| Native | 5 | Specifica che un determinato documento è stato collegato a una fonte dati esterna tramite l'interfaccia Office Data Source Object (ODSO). |
| Default | n/a | Uguale a [None](./). |
