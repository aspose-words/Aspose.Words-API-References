## MailMergeDestination enum


Specifica i possibili risultati che possono essere generati quando si esegue un'unione dei documenti su un documento.

```cpp
enum class MailMergeDestination
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| NewDocument | 0 | Specifica che le applicazioni host conformi devono generare nuovi documenti popolando i campi all'interno di un documento dato con i dati dalla sorgente dati esterna specificata. |
| Printer | 1 | Specifica che le applicazioni host conformi devono stampare i documenti risultanti dal popolamento dei campi all'interno di un documento dato con dati esterni dalla sorgente dati esterna specificata. |
| Email | 2 | Specifica che le applicazioni host conformi devono generare email utilizzando i documenti risultanti dal popolamento dei campi all'interno di un documento dato con i dati dalla sorgente dati esterna specificata. |
| Fax | 4 | Specifica che le applicazioni host conformi devono generare fax utilizzando i documenti risultanti dal popolamento dei campi all'interno di un documento dato con i dati dalla sorgente dati esterna specificata. |
| Default | n/a | Uguale al valore [NewDocument](./). |
