## OdsoFieldMappingType enum

```cpp
enum class OdsoFieldMappingType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Colonna | 0 | Specifica che il campo di stampa unione è stato mappato a una colonna nella sorgente dati esterna specificata. |
| Null | 1 | Specifica che il campo di stampa unione non è stato mappato a una colonna nella sorgente dati esterna specificata. |
| Default | n/a | Uguale a [Null](./). |
