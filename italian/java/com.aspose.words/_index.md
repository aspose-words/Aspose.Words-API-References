Il pacchetto **com.aspose.words** fornisce classi per generare, convertire, modificare, renderizzare e stampare documenti Microsoft Word senza utilizzare Microsoft Word.

Aspose.Words è scritto interamente in Java. Microsoft Word non è necessario per utilizzare Aspose.Words.

Le classi nel pacchetto **com.aspose.words** prendono le migliori pratiche da due framework ben noti: Microsoft Word Automation e System.Xml. Un documento in Aspose.Words è rappresentato da un albero di nodi, molto simile al DOM XML. Quando possibile, i nomi di classi, metodi e proprietà corrispondono a quelli trovati in Microsoft Word Automation.

Le classi principali in questo spazio dei nomi sono:

 *  **Document** is the main class of the object model that represents a Microsoft Word document.
 *  **DocumentBuilder** provides an easy way to insert content and formatting into a document.
 *  **Node** is the base class for all nodes in the document.
 *  **CompositeNode** is the base class for all nodes of the document that can contain other nodes, for example **Paragraph**, **Section** and **Table** and .

Il pacchetto **com.aspose.words** contiene anche classi che costituiscono il motore di reporting di Aspose.Words. Il motore di reporting consente di popolare rapidamente e facilmente documenti progettati in Microsoft Word con dati provenienti da varie origini dati, come **java.sql.ResultSet**, **array of ResultSets**, **com.aspose.words.net.System.Data.DataSet** o un **array of values**.

L'oggetto **MailMerge** che fornisce l'accesso alla funzionalità di reporting è disponibile tramite la proprietà **Document.MailMerge**.
